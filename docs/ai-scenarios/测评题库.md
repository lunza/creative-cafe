## D-01 角色扮演对话

### 能力范围与评估重点

**能力范围**：基于角色设定（性格、背景、说话方式）生成符合角色身份的自然对话回复，保持角色一致性，遵循格式要求（引号包裹对话、星号包裹动作）。

**评估重点**：
- 角色一致性：回复是否符合角色性格、身份和背景设定
- 格式遵循：对话用双引号" "、动作用星号\* \*包裹
- 剧情理解：回复是否基于给定的上下文情境
- 语言风格：是否符合角色卡描述的说话风格

### 差异化评分标准

| 等级 | 评分细则 |
|------|---------|
| S | 完全符合角色设定，格式完美（引号+星号正确使用），语言风格与角色一致，剧情理解准确，回复自然流畅 |
| A | 基本符合角色设定，格式正确，少量语言偏差但不影响角色感，剧情理解基本正确 |
| B | 部分符合角色设定，格式有少量错误（如漏用星号），语言风格有偏差但角色可辨识 |
| C | 角色设定把握不足，格式多处错误，语言风格与角色有明显差异 |
| D | 角色设定严重偏离，格式混乱，回复与原角色几乎无关 |
| E | 完全不符合角色设定，无格式，回复不相关或无法理解 |

## D-02 视觉特征标签提取

### 能力范围与评估重点

**能力范围**：基于角色描述文本，提取适用于 Stable Diffusion 图像生成的特征标签，遵循 Danbooru/e621 标签库规范（英文、下划线分隔）。

**评估重点**：
- 标签准确性：提取的标签是否准确反映角色描述中的视觉特征
- 标签规范性：是否符合 Danbooru/e621 风格（下划线分隔、英文）
- 视觉导向：是否提取可视觉呈现的特征（外貌、服装、配饰），排除抽象概念
- 格式遵循：每行一个标签的输出格式
- 分类意识：困难题需将标签按身体/眼睛/服装/配饰/种族等分类

### 差异化评分标准

| 等级 | 评分细则 |

## D-05 文本润色与改写

### 能力范围与评估重点

**能力范围**：基于用户草稿/描述进行润色优化，保持原始意图与核心信息，提升表达精准度与场景适配度，严格遵循"仅输出润色文本"的指令。

**评估重点**：
- 语义保持：润色后是否保留原意与关键信息
- 表达优化：语句是否更流畅、精准、富有表现力
- 场景适配：是否符合目标场景（角色对话/描述润色）
- 指令遵循：是否只输出润色文本（不添加解释、不生成额外内容）
- 长度控制：润色后长度是否合理控制在原文 ±50% 内

### 差异化评分标准

| 等级 | 评分细则 |
|------|---------|
| S | 完全保持原意，表达显著提升，场景适配准确，严格只输出润色文本，长度控制得当 |
| A | 基本保持原意，表达有所提升，少量场景不匹配或格式瑕疵，基本只输出润色文本 |
| B | 部分保持原意，表达提升有限，存在明显偏差或增删了关键信息 |
| C | 原意有较多改变，关键信息丢失或曲解，表达反而变差 |
| D | 原意严重偏离，或增加了大量无关内容 |
| E | 输出完全无关或未按指令润色（如直接回答问题） |

## D-06 逻辑推理与检查

### 能力范围与评估重点

**能力范围**：对章节/证言内容进行逻辑检查，识别设定不一致、情节矛盾、逻辑错误，并输出结构化 JSON 检查报告。同时具备纯逻辑推理能力（如狼人杀推理）。

**评估重点**：
- 矛盾识别：能否发现内容中的逻辑矛盾（物品状态、经济、角色状态、物理规律、剧情设定、数学）
- 推理准确性：推理结论是否正确，无过度推理
- 结构化输出：输出是否为有效 JSON（overall_score / dimension_scores / logic_issues）
- 快速修正：quickFixSuggestion 的 originalText 是否与原文精确匹配
- 严重程度判断：severity 分级是否合理

### 差异化评分标准

| 等级 | 评分细则 |
|------|---------|
| S | 准确识别全部矛盾点，推理严谨，JSON 完全有效，quickFix 原文匹配精确，严重程度判断合理 |
| A | 识别大部分矛盾点，推理基本严谨，JSON 有效，quickFix 基本匹配，严重程度基本合理 |
| B | 识别部分矛盾点，有少量误报或漏报，JSON 有小错误但可解析，quickFix 有偏差 |
| C | 识别少量矛盾点，存在较多误报漏报，JSON 有明显错误，quickFix 不精确 |
| D | 几乎未识别矛盾，或推理错误，JSON 无法解析 |
| E | 输出无关内容或完全错误 |

## D-07 信息提取与结构化

### 能力范围与评估重点

**能力范围**：从对话/聊天记录中提取实体信息，识别同一实体的不同称呼（变体称呼），生成结构化表格操作指令（insert/update/delete），保持唯一 ID 一致性。

**评估重点**：
- 实体识别：能否提取关键实体（角色、物品、地点、事件、社交关系）
- 变体称呼链接：能否识别"朱迪/Judy/兔警官"为同一实体
- 唯一 ID 一致性：同一实体是否保持相同唯一 ID
- 操作指令有效性：insert/update/delete 的选择是否正确
- JSON 输出格式：是否严格符合表格操作指令格式

### 差异化评分标准

| 等级 | 评分细则 |
|------|---------|
| S | 实体识别完整准确，变体称呼全部正确链接，唯一 ID 一致，操作指令正确，JSON 完全有效 |
| A | 实体识别基本完整，变体称呼大多正确，唯一 ID 基本一致，操作指令基本正确，JSON 有效 |
| B | 实体识别部分完整，部分变体称呼未链接，唯一 ID 有少量不一致，操作指令部分错误 |
| C | 实体识别有明显遗漏，变体称呼多未链接，唯一 ID 混乱，操作指令错误较多 |
| D | 实体识别严重不足，唯一 ID 大量重复或错误，操作指令大部分错误 |
| E | 输出无法解析或与表格指令完全无关 |

## D-08 指令遵循与约束执行

### 能力范围与评估重点

**能力范围**：严格遵循系统提示词中的指令约束——格式要求（引号/星号）、输出限制（仅输出 XX）、禁止事项（不回答、不扮演、不解释）、特定标签生成（HTML 注释、tableEdit 命令、禁词规避）。

**评估重点**：
- 指令理解：是否准确理解指令意图
- 格式遵循：是否严格遵守输出格式（引号、星号、JSON、标签）
- 约束执行：是否拒绝执行禁令（不扮演角色、不回答问题、不暴露身份）
- 输出纯净度：是否只输出要求内容而不添加解释/前缀/多余内容
- 特殊格式：是否正确生成系统要求的特殊标签（如 HTML 注释暗码、tableEdit 命令）

### 差异化评分标准

| 等级 | 评分细则 |
|------|---------|
| S | 完全遵循所有指令，格式精准，不违反任何禁令，输出纯净无多余内容，特殊标签正确生成 |
| A | 基本遵循指令，少量格式瑕疵或输出略有冗余，无实质禁令违反 |
| B | 部分遵循指令，存在明显格式偏差或输出含多余内容，轻微违反禁令 |
| C | 指令遵循不足，格式多处错误，违反部分禁令，输出大量无关内容 |
| D | 严重违反指令，格式混乱，有明显禁止行为（如扮演角色、回答问题） |
| E | 完全无视指令，输出不相关内容 |

## D-09 多轮对话与长上下文保持

### 能力范围与评估重点

**能力范围**：在长文本对话（多轮交互）中保持角色一致性、剧情连贯性与跨轮次信息记忆能力。动态参数的核心是**对话历史轮次数量与跨轮次信息引用距离**——难度随"需记住并正确引用的早期信息跨轮距离"递增，同时保持单轮输入参数数量一致。

**评估重点**：
- 跨轮次记忆：能否正确记住并引用早期轮次出现的信息（姓名、物品、事件、承诺）
- 角色一致性长期维持：多轮之后说话风格、性格、口吻是否发生漂移
- 剧情连贯性：新回合是否与之前剧情发展一致，不重复、不矛盾
- 信息积累与复用：后轮回复是否基于前轮积累的信息做合理推进
- 格式保持一致：跨轮次持续使用引号+星号格式，不退化

### 差异化评分标准

| 等级 | 评分细则 |
|------|---------|
| S | 全部早期关键信息被准确记忆并自然引用，角色风格跨轮零漂移，剧情完全连贯，格式全程一致 |
| A | 大部分早期信息被正确引用，角色风格基本稳定，剧情无明显矛盾，少量格式瑕疵 |
| B | 部分早期信息被记住，有 1-2 处记忆遗漏或角色口吻偏差，剧情有小矛盾但可自洽 |
| C | 关键早期信息较多遗忘，角色风格出现明显漂移，剧情出现事实性矛盾 |
| D | 早期信息大量遗忘或张冠李戴，角色前后判若两人，剧情严重矛盾 |
| E | 无跨轮记忆，每轮独立生成，或完全无法进行多轮对话 |

> 难度分级说明（参数数量一致的"长对话"测试）：
> - L1：对话历史 **3 轮**，需引用 **1 轮前**（最近一轮）的信息
> - L2：对话历史 **6 轮**，需引用 **3-4 轮前**的中期信息，并整合多项细节
> - L3：对话历史 **10+ 轮**，需引用 **7+ 轮前**的早期伏笔，并处理跨轮累积的角色关系演变
