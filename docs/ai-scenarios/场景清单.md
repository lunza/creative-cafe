### S-01 角色扮演对话生成

#### 1. 功能描述与精确定位

**用途**：角色扮演对话的核心功能。用户与 AI 角色进行自然语言对话，AI 以角色身份生成回复。这是整个应用最核心、调用量最大的 AI 场景。

**业务价值**：应用的核心价值功能，用户与角色互动的主要方式，直接影响用户体验和留存。

**代码位置**：
- 对话管线入口：`[PromptBuilder.ts](file:///g:\AI\creative-cafe\src\renderer\components\character\characterdialoguechat\PromptBuilder.ts)` - `buildDialoguePrompt()` 第 955-1025 行、`buildContinuationPrompt()` 第 1027-1108 行、`buildFinalSystemPrompt()` 第 1142-1235 行
- 引擎调用：`[ChatEngine.ts](file:///g:\AI\creative-cafe\src\renderer\components\Common\ChatEngine\ChatEngine.ts)` - `sendMessage()` 第 42-200 行
- 管线 AIService：`[pipeline/AIService.ts](file:///g:\AI\creative-cafe\src\renderer\components\character\characterdialoguechat\pipeline\AIService.ts)` - `sendMessage()` 第 80-125 行
- 14 个 PromptProvider 组装系统提示词：`[providers/index.ts](file:///g:\AI\creative-cafe\src\renderer\components\character\characterdialoguechat\pipeline\providers\index.ts)` 第 49-69 行

**使用样例**：
```typescript
// ChatEngine.ts -> sendMessage()
const response = await engine.sendMessage(
  messages, // 对话历史 messages[]
  systemPrompt, // 由 PromptBuilder 构建的完整系统提示词
  {
    api_url: 'http://localhost:1234',
    api_key: '...',
    model_name: 'model-name',
    temperature: 0.8,
    max_tokens: 4096,
    stopSequences: ['User:', 'You:'],
    capabilities: { supportsStopArray: true, ... }
  }
);
```

#### 2. 系统提示词样例

系统提示词由 14 个 PromptProvider 按 section/priority 组装，最终结构如下：

```
${characterContext}  — CharacterContextProvider (section=context, priority=100)
  角色卡上下文（description / personality / scenario / mes_example / creator_notes）

${personaSection}  — PersonaProvider (section=context, priority=200)
  用户人设信息

${vectorContextItems}  — KnowledgeContextProvider (section=context, priority=210)
  向量检索到的相关背景知识（区域 1）

${chatHistoryItems}  — ChatHistoryProvider (section=context, priority=220)
  本会话相关历史片段（区域 2）

${memoryTableData}  — MemoryTableProvider (section=context, priority=230)
  记忆表格数据（区域 3）

【主要任务类型：角色扮演对话】
${dialogueInstruction}  — DialogueInstructionProvider (section=instruction, priority=300)
  对话任务说明与约束规则

【输出格式要求】
${formatInstruction}  — FormatInstructionProvider (section=suffix, priority=450)
  对话用双引号，动作用星号

【续写指令（仅续写模式）】
${nudgePrompt}  — ContinuationInstructionProvider (section=instruction, priority=310)
  继续上一条消息，不要重复已有内容

${lengthGuidance}  — LengthGuidanceProvider (section=suffix, priority=400)
  回复长度引导

${languageConstraint}  — LanguageProvider (section=suffix, priority=410)
  语言约束（中文/英文/日文）

${assistModePrompt}  — AssistModeProvider (section=suffix, priority=420)
  辅助模式提示

${expressionDirective}  — ExpressionProvider (section=suffix, priority=430)
  表情标记指令

${asyncTableInstructions}  — AsyncTableOrganizeProvider (section=suffix, priority=440)
  异步表格整理指令（仅 async 模式）

${forbiddenWordsPrompt}  — ForbiddenWordsPromptProvider (section=suffix, priority=460)
  禁词约束指令

【区域 4：记忆表格异步整理指令】（仅 async 模式）
```

**动态占位符说明**：
- `${characterContext}` — 角色卡上下文（角色名、性格、描述、场景、对话示例等）
- `${personaSection}` — 用户人设信息（用户名、描述）
- `${vectorContextItems}` — 向量检索到的相关背景知识
- `${chatHistoryItems}` — 本会话历史片段（RAG 检索）
- `${memoryTableData}` — 记忆表格当前数据
- `${dialogueInstruction}` — 对话任务类型说明（对话/续写）
- `${forbiddenWordsPrompt}` — 用户配置的禁词列表

#### 5. 调用频率统计与重要程度分级

- **重要性**：P0（最高优先级）
- **频率估算**：高频。根据聊天记录分析（兽娘餐厅 16 个版本/天、克拉拉 15 个版本/天），日均 50-200+ 次调用
- **每次对话包含多轮次 message 交互**，实际 API 调用次数 = 对话轮次数
- **模型要求**：需要较强的角色扮演理解能力、长上下文支持（4K-8K+ tokens）、格式遵循能力

### S-02 角色视觉特征 tag 生成

#### 1. 功能描述与精确定位

**用途**：基于角色卡的 description / personality / scenario 字段，调用 AI 引擎自动提取视觉特征 tag 列表（如 `white fur, dog girl, blue eyes, black shirt`），用于 SD 图像生成时保证角色一致性。这是**图片提示词 tag 生成**的核心场景。

**业务价值**：直接影响 SD 图像生成的角色一致性，是用户最常使用的 AI 辅助功能之一。用户反馈"部分 AI 模型输出准确率未达预期"即主要针对此场景。

**代码位置**：
- [characterTraitAIService.ts](file:///g:\AI\creative-cafe\src\main\services\characterTraitAIService.ts) - `generateCharacterTraits()` 第 500-750 行
- `callTraitAI()` 内部方法 第 661 行（非流式 POST /v1/chat/completions）
- `buildDynamicTraitSystemPrompt()` 动态系统提示词构建
- IPC 入口：`[characterTraitAIHandlers.ts](file:///g:\AI\creative-cafe\src\main\ipc\handlers\characterTraitAIHandlers.ts)`

**使用样例**：
```typescript
// characterTraitAIService.ts
const result = await characterTraitAIService.generateCharacterTraits({
  characterCardId: 'path/to/character.png',
  description: 'A white-furred dog girl with blue eyes, wearing a black shirt',
  personality: 'Friendly, energetic, a bit naive',
  scenario: 'Living in a small town, working as a waitress',
  includeImage: false // 是否附带角色卡图片（多模态）
});
// result.traits: [{text: "white_fur", categoryId: "body"}, {text: "blue_eyes", categoryId: "eyes"}, ...]
```

#### 2. 系统提示词样例

```
你是一个 Stable Diffusion 角色特征提取专家。你的任务是根据角色描述，提取适用于 Stable Diffusion 图像生成的特征标签（tags）。

【角色信息】
担任角色：${characterName}
角色描述：${description}
${personality ? `角色性格：${personality}` : ''}
${scenario ? `角色场景：${scenario}` : ''}

【提取规则】
1. 提取的标签必须是英文，使用下划线分隔（如 grey_hair, blue_eyes）
2. 标签风格遵循 Danbooru/e621 标签库规范
3. 优先提取视觉可呈现的特征（外貌、服装、配饰、体型等）
4. 避免提取抽象概念（如"善良"、"勇敢"）
5. 每个标签应具体明确，避免模糊描述
6. 输出格式：每个标签独立一行，如需要分类前缀使用 分类名:标签 格式

${ragReferenceSection}

【输出格式】
直接输出标签列表，每行一个标签。示例：
body:white_fur
body:tail
eyes:blue_eyes
clothing:black_shirt
```

**占位符说明**：
- `${characterName}` — 角色名称
- `${description}` — 角色描述文本
- `${personality}` — 角色性格（可选）
- `${scenario}` — 角色场景（可选）
- `${ragReferenceSection}` — RAG 标签库参考段落（可选，从标签库检索的 top-K 参考标签）

#### 3. 输入 AI 引擎的参数说明

| 参数 | 类型 | 取值范围 | 必填 | 示例 |
|------|------|---------|------|------|
| `model` | string | 任意模型名称 | 是 | `"qwen2.5-14b-instruct"` |
| `messages` | array | system + user 消息 | 是 | `[{role:"system",content:"..."}, {role:"user",content:"..."}]` |
| `temperature` | number | 0.0-2.0（建议 0.3-0.7） | 是 | `0.5` |
| `max_tokens` | number | 1-模型上限 | 否 | `1024` |
| `stream` | boolean | false（非流式） | 是 | `false` |

#### 4. 期望 AI 输出参数定义

**输出格式**：纯文本，每行一个标签（可选加分类前缀）

```
# 示例输出
body:white_fur
body:dog_ears
body:tail
eyes:blue_eyes
clothing:black_shirt
clothing:skirt
accessories:bow
```

#### 5. 调用频率统计与重要程度分级

- **重要性**：P0（图片提示词 tag 生成核心场景）

- **模型要求**：需要较强的文本理解能力、英文标签库知识、格式遵循能力
