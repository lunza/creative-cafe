# Creative Café 创想咖啡厅 · 用户手册

> 欢迎使用 **创想咖啡厅（Creative Café）**！这是一款基于 Electron 构建的桌面端 AI 创意工坊，专为 SillyTavern 角色卡、世界书创作与 AI 对话而设计。
>
> 本手册将带你从零开始，逐步了解每一个功能模块。如果你是第一次接触 AI 类工具，请先阅读下方的「新用户上手指南」。

---

## 新用户上手指南（首次使用必读）

如果你从来没有配置过 AI 模型，也不用担心。请按照下面的清单，一步一步完成初始设置：

- [ ] **第一步：获取一个 AI 引擎地址和密钥。** 创想咖啡厅支持所有 OpenAI 兼容的 API。你可以使用本地部署的推理服务（如 Ollama、vLLM、text-generation-webui），也可以使用云端服务（如 OpenAI 官方、各类中转站）。你需要准备三样东西：API 地址、API 密钥、模型名称。
- [ ] **第二步：打开「设置」页面。** 点击左侧边栏最下方的「设置」按钮，切换到「AI 引擎」标签页。
- [ ] **第三步：填写引擎信息并测试。** 依次填入 API 地址、API 密钥和模型名称，点击「测试连通性」。看到绿色成功提示后，说明 AI 引擎已经可以正常工作了。
- [ ] **第四步：保存设置。** 点击页面底部的「保存设置」按钮。
- [ ] **第五步：（可选）配置向量模型。** 如果你希望使用知识库、世界书智能检索等高级功能，需要在「设置 → 向量与 RAG」中配置嵌入模型（可选择远程 API 或本地模型）。
- [ ] **第六步：开始创作。** 前往「角色卡」创建一个角色，或前往「创作中心」直接与 AI 对话。

> 💡 **小提示**：术语不懂没关系！本手册在首次出现专业术语时都会给出通俗解释。遇到不认识的词，可以翻到本手册末尾的「常见问题（FAQ）」查找。

### 术语速查表

| 术语 | 通俗解释 |
|------|---------|
| AI 引擎 | 提供人工智能能力的"服务器地址"，类似你给应用配一个"大脑"的网址 |
| API 密钥（API Key） | 一串密码，用来证明你有权使用这个 AI 服务 |
| 模型（Model） | AI 的具体型号，不同模型擅长不同任务 |
| Token（令牌） | AI 处理文字的最小单位，大约 1 个汉字 ≈ 1-2 个 token |
| Temperature（温度） | 控制 AI 回答的"随机程度"，越高越有创意，越低越稳定 |
| 嵌入模型（Embedding） | 把文字变成数字向量的模型，用于"语义搜索" |
| 向量化 | 将文字内容转换为数字向量，方便 AI 理解和检索 |
| RAG | 检索增强生成，让 AI 先"查资料"再"回答"，回答更准确 |
| 角色卡 | 描述一个虚拟角色的完整档案文件 |
| 世界书 | 给 AI 提供背景知识的关键词条目集合 |
| 智能体（Agent） | 能自主调用工具、多步思考的 AI 模式 |

## 二、AI 引擎设置（核心配置）

AI 引擎是整个应用的核心。创想咖啡厅支持配置多个引擎，并随时切换。

![AI 引擎设置界面](截图占位)

### 引擎选择与管理

页面顶部提供引擎选择下拉框和「管理引擎」按钮：

- **引擎选择**：从已配置的引擎列表中选择当前使用的引擎。下拉项旁边会显示该引擎的能力图标。
- **管理引擎**：打开引擎管理弹窗，可以添加、编辑、复制、删除引擎，以及设置默认引擎。

#### 添加新引擎的步骤

1. 点击「管理引擎」按钮，打开引擎管理弹窗。
2. 点击「添加新引擎」按钮。
3. 填写引擎名称（例如"我的本地模型"）。
4. 填写 API 地址、API 密钥和模型名称（详见下表）。
5. 点击「添加引擎」保存。

#### 引擎管理弹窗操作

| 操作 | 说明 |
|------|------|
| 复制 | 基于现有引擎创建副本，需输入新名称 |
| 编辑 | 修改引擎的所有配置参数 |
| 删除 | 删除该引擎（不可恢复） |
| 设置默认 | 将该引擎设为默认引擎 |

### 引擎配置参数详解

以下是每个引擎可配置的全部参数。**标注「重要」的参数请务必正确填写**：

#### 基础连接参数

| 参数 | 说明 | 示例 | 重要程度 |
|------|------|------|---------|
| API 地址（api_url） | AI 服务的接口地址 | `http://127.0.0.1:5000` | ⭐⭐⭐⭐⭐ |
| API 密钥（api_key） | 访问 AI 服务的密码，本地部署可留空 | `sk-xxxxxxxx` | ⭐⭐⭐⭐ |
| 模型名称（model_name） | 要使用的具体模型名 | `qwen3.5-27b-heretic-v3` | ⭐⭐⭐⭐⭐ |
| API 密钥传输方式 | 密钥的传递方式 | 请求头 / 请求体 | ⭐⭐⭐ |

> 💡 **获取模型名称**：填写好 API 地址和密钥后，可以点击「获取模型列表」按钮，系统会自动从 AI 服务获取可用模型列表供你选择。

#### 智能体模式

| 参数 | 说明 |
|------|------|
| 智能体模式（agentModeOverride） | 控制该引擎是否启用智能体（Agent）模式 |

可选值：
- **自动**：根据模型能力自动判断（推荐）
- **强制开启**：无论模型是否支持工具调用，都启用智能体模式
- **强制关闭**：始终使用普通对话模式

> ⚠️ **注意**：智能体模式需要模型支持「工具调用」能力。如果模型不支持，强制开启可能导致功能异常。建议使用「自动」模式。

#### 生成参数

这些参数控制 AI 生成文本的方式，是影响生成质量的关键：

| 参数 | 范围 | 默认值 | 说明 | 推荐值 |
|------|------|--------|------|--------|
| 温度（temperature） | 0 - 2 | 0.7 | 控制 randomness（随机性）。值越高回答越有创意但可能跑题；值越低越稳定保守 | 角色对话：0.7-0.9；翻译润色：0.3-0.5；创意写作：0.8-1.2 |
| 最大令牌数（max_tokens） | 1 - 1000000 | 10240 | AI 单次回复的最大长度上限。值越大回复越长，但也会消耗更多资源 | 日常使用：8192-16384；长文写作：32768+ |
| Top P（top_p） | 0 - 1 | — | 核采样，与温度类似控制多样性。只从概率累计前 P 的词中选择 | 0.9-0.95（与温度二选一调整即可） |
| Top K（top_k） | 0 - 200 | — | 只从概率最高的 K 个词中选择，进一步限制选择范围 | 40（部分模型支持） |
| Min P（min_p） | 0 - 1 | — | 最低概率阈值，过滤掉概率过低的词 | 0.05-0.1（部分模型支持） |
| 频率惩罚（frequency_penalty） | -2 到 2 | 0 | 正值减少重复用词，负值增加重复 | 0-0.5（减少复读时使用） |
| 存在惩罚（presence_penalty） | -2 到 2 | 0 | 正值鼓励引入新话题，负值鼓励延续话题 | 0-0.5 |
| 生成数量（n） | 1 - 10 | 1 | 一次生成几条回复 | 通常保持 1 |

> 💡 **温度和 Top P 怎么选？**
> - **温度（Temperature）**：适合需要"调创意旋钮"的场景。0 = 完全确定（每次回答一样），2 = 非常随机。
> - **Top P**：适合需要"控制质量下限"的场景。0.9 表示只在概率前 90% 的词里选。
> - 一般情况下，调整其中一个即可，不需要两个都调。

#### 超时参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 连接超时（connection_timeout） | 120000ms（120秒） | 等待 AI 服务器返回第一个字的最大时间。深度思考模型首字延迟较长，可适当调大。0 表示不限制 |
| 请求超时（request_timeout） | 300000ms（300秒） | 整个 AI 请求的最大时长。0 表示不限制 |

> ⚠️ **注意**：如果你使用的是带"思维链"的深度思考模型（如 o1、DeepSeek-R1），首字响应可能需要 30-60 秒。如果频繁超时，请将「连接超时」调大到 180000（180秒）或更高。

#### 系统提示词

| 参数 | 说明 |
|------|------|
| 系统提示词（system_prompt） | 全局系统提示词，会自动拼接到所有 AI 请求的任务提示词前面。用于设定 AI 的全局行为规范 |

> 💡 **提示**：系统提示词是可选的。如果你不确定它的作用，可以先留空。它会在角色对话、世界书生成、翻译润色等所有 AI 功能中生效。

### 测试连通性

填写完引擎参数后，点击「测试连通性」按钮验证配置是否正确。测试结果会显示：

- 连接是否成功
- API 地址和模型名称
- 响应时间（毫秒）
- **模型能力检测结果**：自动检测模型是否支持以下能力
  - ✏️ **文本生成**：基础文本生成能力（所有模型都支持）
  - 👁️ **视觉/图片识别**：能否理解和分析图片
  - 💡 **思维链/推理**：是否支持深度思考推理
  - 🔧 **工具调用**：是否支持智能体模式的工具调用

![连通性测试结果](截图占位)

> ⚠️ **重要**：模型能力图标在测试连通性后才会更新。如果顶部的图标是灰色的，请先测试连通性。

## 三、图像生成设置

用于配置 Stable Diffusion WebUI，支持在角色对话中生成角色立绘、表情图等。

![图像生成设置界面](截图占位)

### 基础配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| WebUI 地址（endpoint） | `http://localhost:7860` | SD WebUI 的 API 地址 |
| 模型（model） | — | 使用的 SD 模型文件名 |
| 模型类型（modelType） | sdxl | 模型架构类型（SDXL/SD1.5 等），影响提示词模板 |
| 降噪强度（denoisingStrength） | 0.55 | 图生图的修改幅度 |
| 采样步数（steps） | 28 | 生成步数，越多越精细但越慢 |
| CFG 比例（cfgScale） | 7 | 提示词引导强度 |
| 采样器（sampler） | DPM++ 3M SDE | 采样算法 |
| 调度器（scheduler） | Karras | 采样调度策略 |
| CLIP 跳过层（clipSkip） | 2 | 跳过的 CLIP 层数 |

### 正向提示词模板

支持占位符 `{traits}`（角色特征）和 `{emotion}`（表情），系统会自动替换为角色卡中的实际内容。

### ADetailer 面部修复

默认开启，用于自动修复生成图片中的面部细节。可配置模型、置信度、降噪强度、蒙版模糊等参数。

### 高清修复（Hires.fix）

默认开启修复与放大，使用 4x-AnimeSharp 放大器，2 倍放大。

> 💡 **提示**：图像生成功能是可选的。如果你只使用文字对话，可以不配置此项。

## 四、向量与 RAG 设置

向量模型用于将文字转化为数字向量，支撑知识库检索、世界书智能匹配、聊天历史向量化等高级功能。

![向量配置界面](截图占位)

### Embedding 模式选择

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| 远程 API 模式 | 使用云端嵌入 API | 网络好、不想下载模型、追求速度 |
| 本地模型模式 | 使用本地 ONNX 模型 | 无网络或网络不稳定、注重隐私、免费 |
| 禁用 | 完全关闭向量化功能 | 不使用知识库/智能检索等功能时 |

> ⚠️ **注意**：选择「禁用」后，世界书/知识库自动向量化、聊天历史向量化检索、RAG 上下文注入等功能均会停止。已存储的向量数据会保留，重新启用后可继续使用。

### 远程 API 配置

| 参数 | 说明 | 示例 |
|------|------|------|
| 远程 API 地址 | 嵌入模型 API 地址 | `https://api.openai.com/v1/embeddings` |
| 远程模型名称 | 嵌入模型名 | `text-embedding-3-small` |
| 远程 API 密钥 | 访问密钥 | `sk-...` |
| API 密钥传输方式 | Header 或 Body | Header（Authorization） |

### 本地模型配置

本地模式使用 Qwen3-Embedding 系列 ONNX 模型，首次使用需从 ModelScope 下载：

| 模型 | 维度 | 大小 | 显存要求 | 说明 |
|------|------|------|---------|------|
| qwen3-emb-0.6b | 1024 维 | ~250MB | 4GB+ | 轻量首选，速度快 |
| qwen3-emb-4b | 2560 维 | ~2GB | 8GB+ | 平衡方案，精度与速度兼顾 |
| qwen3-emb-8b | 4096 维 | ~4GB | 16GB+ | 最高精度，与远程 8B 同维度 |

> 💡 **提示**：选择本地模型时，向量维度会自动联动。不同维度的向量数据独立存储，切换维度不会丢失旧数据。

> ⚠️ **下载失败怎么办？** 本地模型需要从 HuggingFace/ModelScope 下载，请确保网络畅通。如果下载失败，建议：
> - 开启 VPN 或代理后重试
> - 设置环境变量 `HTTPS_PROXY=http://127.0.0.1:7890`
> - 或切换为远程 API 模式

### 通用配置（存储与缓存）

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 向量维度 | 需与所选嵌入模型一致 | 远程 4096 / 本地按模型 |
| 启用缓存 | 加速向量检索（L1 内存 + L2 磁盘） | 开 |
| L1 缓存大小 | 内存缓存最大条目数 | 远程 1000 / 本地 2000 |
| L1 缓存 TTL | 内存缓存过期时间（秒） | 远程 300 / 本地 600 |
| L2 缓存 TTL | 磁盘缓存过期时间（秒） | 远程 3600 / 本地 7200 |

### 检索参数（高级配置）

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 默认检索数量（Top K） | 语义搜索返回的结果数量 | 远程 5 / 本地 8 |
| 最低相似度阈值 | 低于此值的结果将被过滤 | 远程 0.7 / 本地 0.6 |

# 世界书

## 概述

世界书（World Book / Lorebook）是一种给 AI 提供"背景知识"的机制。它由多个条目组成，每个条目包含关键词和内容。当对话中出现匹配的关键词时，对应的条目内容会自动注入到 AI 的上下文中，让 AI "知道"这些背景设定。

![世界书管理界面](截图占位)

## 关键概念

| 术语 | 说明 |
|------|------|
| 世界书（World Book） | 一组背景知识条目的集合 |
| 条目（Entry） | 世界书中的一个知识单元，包含关键词和内容 |
| 关键词（Keyword） | 触发条目激活的词语，对话中出现时自动注入 |
| 主关键词 / 次关键词 | 主关键词是核心触发词，次关键词是辅助触发词 |
| 常驻条目 | 始终注入上下文的条目，不需要关键词触发 |
| 向量化 | 将条目内容转为向量，支持语义匹配（不仅限于精确关键词匹配） |

## 世界书列表

世界书管理页面左侧展示所有世界书的列表，显示名称、文件大小和修改时间。

### 创建世界书

1. 点击「创建世界书」按钮。
2. 输入世界书名称。
3. 点击确认，进入条目编辑界面。

### 导入世界书

支持导入 SillyTavern 格式的世界书文件（JSON）。

## 条目管理

### 添加条目

1. 选中一个世界书后，在条目表格中点击「添加条目」。
2. 在弹出的编辑器中填写：
   - **关键词**：触发此条目的词语（多个用逗号分隔）
   - **内容**：条目的正文内容
   - **注释**：对该条目的说明备注
   - **触发设置**：是否常驻、触发优先级等
3. 点击保存。

![世界书条目编辑](截图占位)

### 编辑条目

点击条目的「编辑」按钮，修改内容后保存。

### AI 辅助功能

创想咖啡厅为世界书提供了丰富的 AI 辅助功能：

| 功能 | 说明 |
|------|------|
| 翻译 | 将条目内容翻译为中文 |
| 关键词润色 | 优化关键词的表达 |
| 注释润色 | 优化条目注释 |
| 内容润色 | 优化条目正文内容 |
| 关键词生成 | 为条目自动生成主/次关键词 |
| 标签生成 | 为条目自动生成分类标签 |
| 关键词扩写 | 扩写关键词的同义词和相关词 |
| 描述生成 | 根据关键词和主题生成条目内容 |
| AI 排序 | 智能排序世界书条目 |
| 条目生成 | 根据主题描述生成完整世界书 |
| 新条目生成 | 生成指定数量的新条目 |
| 角色卡生成 | 基于角色卡信息生成配套世界书 |

> 💡 **提示**：AI 功能会使用当前设置的 AI 引擎。生成的内容会进入"待审阅"区域，你可以确认后再正式添加。

### AI 审核

世界书支持 AI 审核功能，可以检查条目内容的合理性、一致性和质量：

1. 点击「AI 审核」按钮。
2. 选择审核范围（单个条目或全部条目）。
3. AI 会分析每个条目并给出审核意见。
4. 根据审核意见修改或保留条目。

### 世界书编写智能体

创想咖啡厅内置了世界书编写智能体（Authoring Agent），可以：

- 根据你的需求规划世界书结构
- 自动生成和补充条目
- 进行多轮迭代优化
- 集成网络搜索获取参考资料（需配置）

![世界书编写智能体](截图占位)

### 标签管理

每个世界书可以管理自己的标签体系，用于条目分类和组织。标签可以建立关联关系，方便批量管理。

### 向量化

启用向量模型后，世界书条目可以自动向量化，支持语义级别的智能匹配——即使对话中没有出现精确关键词，只要语义相近也能激活相关条目。

2. 点击上传区域或拖拽文件到上传区。
3. 选择要上传的文档（支持 PDF/Word/Excel/TXT 格式）。
4. 系统会自动处理文档：解析内容 → 分块 → 向量化。
5. 处理完成后，文档出现在已处理列表中。

![文档上传界面](截图占位)

#### 文档处理说明

| 阶段 | 说明 |
|------|------|
| 解析 | 提取文档中的文字内容 |
| 分块 | 将长文本切分为合适大小的段落 |
| 向量化 | 将每个段落转换为向量并存储 |

> 💡 **提示**：大文件处理可能需要一些时间，请耐心等待。处理进度会实时显示。

### 3. 向量测试

测试向量检索效果的工具。

1. 切换到「向量测试」标签页。
2. 在搜索框中输入查询文本。
3. 系统会返回语义最相关的知识条目。
4. 查看匹配结果和相似度分数。

> 💡 **提示**：向量测试是验证知识库效果的好工具。如果检索结果不理想，可以尝试调整「设置 → 向量与 RAG」中的 Top K 和相似度阈值。

## 在对话中使用知识库

在角色对话界面中，可以通过「知识库绑定」功能将知识库绑定到当前对话。绑定后，AI 会在每次回复前自动检索相关知识，让回答更加准确。

## 版本管理

提示词管理提供历史版本功能：

- **查看历史**：查看提示词的修改历史记录
- **版本对比**：对比不同版本之间的差异
- **回退版本**：恢复到之前的版本
- **保存新版本**：保存当前编辑为新版本

> 💡 **提示**：修改提示词前，建议先保存当前版本。如果修改后效果不理想，可以随时回退。

## 使用建议

1. **先理解再修改**：仔细阅读原始提示词，理解每个部分的作用。
2. **小步迭代**：每次只修改一小部分，测试效果后再继续。
3. **保留备份**：利用版本管理功能保留可用的历史版本。
4. **注意变量**：提示词中的 `{变量名}` 是系统自动替换的占位符，不要删除。
5. **全局提示词**：设置中的「系统提示词」会拼接到所有模块提示词前面，注意避免冲突。

## 常见问题（FAQ）

### 配置与连接问题

**Q：测试连通性失败，提示"连接超时"怎么办？**

A：请按以下步骤排查：
1. 检查 API 地址是否正确，能否在浏览器中访问。
2. 如果使用本地部署的模型，确认服务已启动。
3. 尝试调大「设置 → AI 引擎」中的「连接超时」参数（如 180000 毫秒）。
4. 检查防火墙是否阻止了连接。

**Q：API 密钥应该填在哪里？**

A：在「设置 → AI 引擎 → API 密钥」中填写。如果你的 AI 服务不需要密钥（如本地部署的 Ollama），可以留空。同时注意「API 密钥传输方式」要与服务端一致，通常选「请求头」。

**Q：模型能力图标一直是灰色的，怎么激活？**

A：模型能力是在「测试连通性」时自动检测的。请前往「设置 → AI 引擎」，点击「测试连通性」按钮，检测完成后图标会更新。

**Q：支持哪些 AI 服务？**

A：创想咖啡厅支持所有 OpenAI 兼容的 API，包括但不限于：OpenAI 官方、本地 Ollama、vLLM、text-generation-webui、各类 API 中转站等。

### 向量与知识库问题

**Q：本地嵌入模型下载失败怎么办？**

A：本地模型需要从 HuggingFace/ModelScope 下载，建议：
1. 开启 VPN 或代理后重试。
2. 设置环境变量 `HTTPS_PROXY=http://127.0.0.1:7890`（端口号换成你的代理端口）。
3. 或切换为「远程 API 模式」，使用云端嵌入服务。

**Q：知识库检索结果不准确怎么办？**

A：尝试以下调整（在「设置 → 向量与 RAG」中）：
1. 调低「最低相似度阈值」（如从 0.7 降到 0.5），获取更多结果。
2. 增加「默认检索数量（Top K）」（如从 5 增加到 10）。
3. 确保文档已经完整向量化（在「知识库 → 文档上传」中检查处理状态）。

**Q：可以不配置向量模型吗？**

A：可以。将 Embedding 模式设为「禁用」即可。但知识库、世界书语义检索、聊天历史向量化等功能将不可用。基础的文字对话和角色卡功能不受影响。

### 角色卡与世界书问题

**Q：导入的角色卡显示不完整？**

A：可能是卡片版本不兼容。创想咖啡厅支持 v1/v2/v3 三个版本，较旧的 v1 卡片部分字段可能无法识别。建议使用 v2 或 v3 格式的角色卡。

**Q：世界书条目没有在对话中生效？**

A：请检查：
1. 条目的关键词是否与对话内容匹配。
2. 条目是否被设为「禁用」状态。
3. 世界书是否已关联到当前角色卡。
4. 如果使用语义匹配，确认向量模型已正常连接。

**Q：AI 生成的世界书内容质量不好？**

A：尝试以下方法：
1. 提供更详细的主题描述和背景设定。
2. 使用世界书编写智能体进行多轮迭代优化。
3. 调整 AI 引擎的温度参数（0.7-0.9 通常效果较好）。
4. 生成后手动修改和完善条目内容。

### 对话与创作问题

**Q：AI 回复突然变短了？**

A：可能是「最大令牌数」设置过小。前往「设置 → AI 引擎」，将 max_tokens 调大（如 16384 或更大）。也可以在对话的参数面板中临时调大。

**Q：对话中 AI 总是"忘记"之前说过的话？**

A：这是上下文长度限制导致的。尝试以下方法：
1. 在对话的「Token 管理」面板中查看上下文使用情况。
2. 启用记忆表格功能，让 AI 自动记录关键信息。
3. 使用续写功能而非重新开始。
4. 调大 max_tokens 参数。

**Q：智能体模式（Agent）和普通模式有什么区别？**

A：智能体模式下，AI 可以自主调用工具（如网络搜索、世界书编辑、表格更新等），进行多步推理和操作。普通模式下，AI 只是简单地回复消息。智能体模式需要模型支持「工具调用」能力。

### 其他问题

**Q：数据存储在哪里？可以备份吗？**

A：所有数据存储在应用的用户数据目录中。你可以在仪表盘点击统计卡片直接打开对应的存储文件夹进行备份。也可以在「设置」中点击「打开配置文件」查看配置。

**Q：如何切换深色模式？**

A：点击顶部栏右侧的主题切换按钮，可在「亮色 → 暗色 → 跟随系统」之间循环切换。也可以在「设置 → 通用 → 主题」中直接选择。

**Q：智能体中心菜单不见了？**

A：「智能体中心」菜单仅在智能体模式激活时显示。请前往「设置 → AI 引擎」，将「智能体模式」设为「强制开启」，或确保当前模型支持工具调用（测试连通性后会自动检测）。

**Q：修改了设置但没有生效？**

A：修改设置后，必须点击页面底部的「保存设置」按钮才会生效。如果仍然没有生效，尝试点击顶部栏的「刷新」按钮重新加载页面。
