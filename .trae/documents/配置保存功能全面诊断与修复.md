# 配置保存功能全面诊断与修复计划

## 现状分析

### 保存流程
1. 用户点击 "保存配置" 按钮 → 触发 `handleSaveConfig`
2. `form.validateFields()` 验证必填字段（creativeDescription、novelType、narrativePerspective）
3. 验证通过后弹出保存弹窗，用户输入配置名称
4. 点击弹窗 "保存" 按钮 → 触发 `handleConfirmSave`
5. `handleConfirmSave` 调用 `form.getFieldsValue()` 获取数据 → 构建 config 对象 → 调用 `saveConfigToStorage`
6. `saveConfigToStorage` 写入 localStorage → 显示成功/失败提示

### 当前存在的问题

**问题 1：`handleConfirmSave` 缺少错误处理**
- `form.getFieldsValue()` 可能抛出异常（如表单中有隐藏必填字段未填写），但没有任何 try-catch 包裹
- 异常会导致函数静默失败，用户看不到任何反馈

**问题 2：`saveConfigToStorage` 错误处理不完整**
- catch 块中只有 console.error 和 message.error，但没有显示具体错误信息
- localStorage 写入失败时用户不知道具体原因（如 quota exceeded）

**问题 3：保存弹窗缺少加载状态**
- `handleConfirmSave` 执行期间没有 loading 状态，用户可能重复点击

**问题 4：表单验证规则不完整**
- 仅有 3 个字段设置了 required 规则，但 `targetWordCount`、`chapterCount` 等核心参数没有验证
- 验证失败时错误信息可能未正确展示

**问题 5：WritingConfigPanel.tsx 存在完全相同的问题**
- 该文件是另一个配置入口，代码逻辑与 WritingConfigModal 完全一致，需要同步修复

## 修复步骤

### 步骤 1：增强 handleConfirmSave 错误处理
在 `WritingConfigModal.tsx` 和 `WritingConfigPanel.tsx` 的 `handleConfirmSave` 函数中：
- 用 try-catch 包裹整个函数体
- 捕获 `form.getFieldsValue()` 和 `saveConfigToStorage` 可能抛出的异常
- 异常时调用 `message.error` 显示明确的错误信息

### 步骤 2：增强 saveConfigToStorage 错误处理
在两个文件的 `saveConfigToStorage` 函数中：
- 在 catch 块中显示具体的错误信息（`e.message` 或 `String(e)`）
- 添加针对 localStorage quota exceeded 的特殊提示

### 步骤 3：为保存弹窗添加 loading 状态
在 `WritingConfigModal.tsx` 和 `WritingConfigModal.tsx` 中：
- 添加 `saving` state（已有此 state，但未被使用于配置保存）
- 在 `handleConfirmSave` 开始时设置 `setSaving(true)`，结束时设置 `setSaving(false)`
- 将 Modal 的 `confirmLoading` 属性绑定到 `saving` state
- 将保存按钮绑定 `loading={saving}`

### 步骤 4：补充表单验证规则
检查 `WritingConfigModal.tsx` 和 `WritingConfigPanel.tsx` 中以下字段是否需要添加验证：
- `targetWordCount`：确保为数字且大于 0
- `chapterCount`：确保为数字且大于 0
- 如有必要，为这些字段添加 `rules` 属性

### 步骤 5：验证修复效果
- 确保保存按钮点击后有明确的 loading 反馈
- 确保保存成功时显示成功提示
- 确保保存失败时显示明确的错误信息（包含具体原因）
- 确保表单验证失败时有明确的提示

## 影响范围

- `src/renderer/components/Creative/WritingMode/WritingConfigModal.tsx` — 主要修复目标
- `src/renderer/components/Creative/WritingMode/WritingConfigPanel.tsx` — 同步修复
- 不涉及后端 API（配置保存使用 localStorage，无网络请求）
