# 创作中心聊天模式 - 喜爱功能实施计划

## 功能概述

为创作中心聊天模式添加角色卡"喜爱"功能，包括：
1. 在ChatHeader添加心形喜爱按钮
2. 角色选择面板中喜爱角色卡优先排序
3. 角色卡头像右上角显示粉色爱心标记
4. 快捷喜爱角色栏展示
5. 数据持久化存储

## 技术架构

### 数据存储方案
- 使用 localStorage 进行喜爱状态持久化
- 存储结构：`{ path: string, timestamp: number }[]`
- 按添加时间排序，支持快速查询和更新

## 技术要点

### localStorage 持久化
```typescript
const FAVORITES_STORAGE_KEY = 'creative-cafe-character-favorites';

// 读取
const loadFavorites = (): FavoriteCharacter[] => {
  try {
    const data = localStorage.getItem(FAVORITES_STORAGE_KEY);
    return data ? JSON.parse(data) : [];
  } catch {
    return [];
  }
};

// 保存
const saveFavorites = (favorites: FavoriteCharacter[]) => {
  try {
    localStorage.setItem(FAVORITES_STORAGE_KEY, JSON.stringify(favorites));
  } catch (error) {
    console.error('[FavoritesStore] 保存喜爱列表失败:', error);
  }
};
```

### 角色排序逻辑
```typescript
const getSortedCharacters = (
  characters: Character[], 
  favorites: FavoriteCharacter[]
): Character[] => {
  const favoritePaths = new Set(favorites.map(f => f.path));
  
  const favoriteCharacters = characters
    .filter(c => favoritePaths.has(c.path))
    .sort((a, b) => {
      const aTime = favorites.find(f => f.path === a.path)?.addedAt || 0;
      const bTime = favorites.find(f => f.path === b.path)?.addedAt || 0;
      return aTime - bTime;
    });
  
  const nonFavoriteCharacters = characters
    .filter(c => !favoritePaths.has(c.path));
  
  return [...favoriteCharacters, ...nonFavoriteCharacters];
};
```

## 注意事项

1. **性能优化**：
   - 使用 React.memo 优化组件渲染
   - favoritesStore 使用 zustand 状态管理
   - 避免不必要的重渲染

2. **用户体验**：
   - 点击喜爱按钮时提供即时反馈
   - 添加过渡动画使交互更流畅
   - 空状态提供友好的提示信息

3. **兼容性**：
   - 确保与现有角色切换逻辑兼容
   - 与 avatarCache 逻辑兼容
   - 不影响现有的选择面板功能

4. **边界情况**：
   - 角色被删除后清理喜爱列表
   - localStorage 不可用时的降级处理
   - 喜爱列表超长时的滚动处理
