# 修复页面切换动画提前刷新问题

## 问题分析

经过详细分析 `PageTransition.tsx` 组件代码，发现以下问题导致动画未播完就提前刷新：

### 问题 1: `childrenRef` 同步时机错误

```javascript
// 当前的代码
useEffect(() => {
    childrenRef.current = children;  // 这个 effect 在 key 变化时也会执行
}, [children]);

useEffect(() => {
    if (activeKey !== displayKey) {
      // ... 播放出场动画
      timerRef.current = setTimeout(() => {
        setDisplayKey(activeKey);
        setDisplayChildren(childrenRef.current);  // 使用 childrenRef
        setAnimClass('page-enter');
      }, 200);
    }
  }, [activeKey, displayKey, animationEnabled]);
```

当 `activeKey` 改变时：
1. `children` prop 改变 → 触发第一个 `useEffect` → `childrenRef.current` **立即**更新为新 children
2. `activeKey` 改变 → 触发第二个 `useEffect` → 播放出场动画
3. 200ms 后使用 `childrenRef.current`（**已经是新的 children**）切换内容

这意味着虽然动画还在播放，但 `childrenRef` 已经更新。如果第二个 `useEffect` 的执行时机出现问题，可能导致内容提前切换。

### 问题 2: `key={displayKey}` 导致组件被销毁

```javascript
// 当前的代码
<div key={displayKey} className={`page-transition-wrapper ${animClass}`}>
    {displayChildren}
</div>
```

当 `displayKey` 改变时，React 会完全销毁旧的 DOM 节点并创建新的 DOM 节点。这会导致：
- 如果动画尚未结束就更新了 `displayKey`，用户会看到页面突然"闪烁"或"刷新"
- CSS 动画依赖于 DOM 节点的存在，节点被销毁后动画自然中断

### 问题 3: CSS 动画时间不匹配

```css
.page-transition-wrapper.page-exit {
  animation: pageExit var(--duration-normal) var(--ease-in);
}
```

`--duration-normal` 是 `0.3s`，但 JavaScript 中的定时器是 `200ms`。如果定时器在动画结束前触发，用户会看到切换效果。

## 解决方案

### 步骤 1: 修复 children 同步时机

将 `children` 保存到本地状态中，确保只在动画切换时才更新，避免 `childrenRef` 被外部 prop 变化干扰：

```javascript
const [pendingChildren, setPendingChildren] = useState(children);

// 只在 activeKey 真正变化时，才更新 pendingChildren
useEffect(() => {
    if (activeKey !== displayKey) {
      setPendingChildren(children);
      // ... 播放动画
    }
  }, [activeKey]);
```

### 步骤 2: 使用稳定的 key 避免 DOM 销毁

将 `key={displayKey}` 改为使用一个永不改变的 key，只通过 `displayChildren` 来控制显示内容：

```javascript
<div key="page-content" className={`page-transition-wrapper ${animClass}`}>
    {displayChildren}
</div>
```

这样可以避免 React 在切换内容时销毁和重建 DOM 节点，确保 CSS 动画能够完整播放。

### 步骤 3: 统一动画时间

确保 JavaScript 定时器时间与 CSS 动画时间一致：
- 出场动画使用 `--duration-normal` (0.3s)
- 定时器也使用 300ms
- 入场动画使用 `--duration-slower` (0.45s)

### 步骤 4: 添加动画完成检测

使用 CSS 动画的 `animationend` 事件来精确控制内容切换时机，而不是依赖定时器：

```javascript
const handleAnimationEnd = useCallback((e: React.AnimationEvent) => {
    if (e.animationName === 'pageExit') {
      // 出场动画结束，切换内容
      setDisplayKey(activeKey);
      setDisplayChildren(pendingChildren);
      setAnimClass('page-enter');
    } else if (e.animationName === 'pageEnter') {
      // 入场动画结束，清除动画类
      setAnimClass('');
    }
  }, [activeKey, pendingChildren]);
```

### 步骤 5: 修复组件挂载时的问题

当组件首次挂载时，不应该播放入场动画，应该直接显示内容：

```javascript
const [isFirstRender, setIsFirstRender] = useState(true);

useEffect(() => {
    if (isFirstRender) {
      setIsFirstRender(false);
      setAnimClass('');
      return;
    }
    // ... 正常的动画逻辑
  }, [activeKey, displayKey]);
```

## 文件修改清单

1. **PageTransition.tsx** - 核心修改
   - 移除 `children` 从 useEffect 依赖数组
   - 使用 `animationend` 事件替代定时器
   - 统一动画时间
   - 处理首次渲染问题

2. **animations.css** - 可选优化
   - 添加 `animation-fill-mode` 确保动画结束后状态保持

## 验收标准

1. 模块切换时，出场动画完整播放（淡出 + 上移）
2. 内容切换后，入场动画完整播放（淡入 + 上移）
3. 整个切换过程流畅，无闪烁、无刷新感
4. 首次加载时不播放入场动画
5. 禁用动画模式下立即切换内容
6. 快速连续切换模块时，动画不会被打断或产生异常
