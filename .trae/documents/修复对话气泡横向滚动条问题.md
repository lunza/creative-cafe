# 修复对话气泡横向滚动条问题

## 摘要

对话模式下，AI 回复内容较长（尤其是含代码块、表格、长 URL 时）会出现横向滚动条，影响阅读体验。根因是 Flexbox 子元素缺少 `minWidth: 0` 约束，导致宽内容撑破气泡容器。需在气泡组件层级链路上补充宽度约束，使文本自动换行、代码块/表格在气泡内部滚动而非撑破外层。

## 当前状态分析

### 问题复现路径

消息渲染层级（从外到内）：

```
chat-messages（容器，overflowY:auto → overflowX 被计算为 auto）
  └─ chat-message-bubble-wrapper（flex，无宽度约束）
       └─ chat-message-bubble-inner（flex，maxWidth:75%，但子元素无 minWidth:0）  ← 问题核心
            ├─ 头像（flexShrink:0，36px，正常）
            └─ 内容列容器（flex column，无 minWidth:0）  ← 问题核心
                 ├─ 角色名标签
                 └─ 气泡本体（wordBreak:break-word，无 overflow 约束）
                      └─ MessageRenderer（.message-renderer-content，无 overflow 约束）
                           ├─ 普通文本（可换行，正常）
                           ├─ pre 代码块（overflowX:auto）  ← 撑破元凶
                           └─ table 表格（overflowX:auto）  ← 撑破元凶
```

### 根因

1. **Flexbox `min-width: auto` 默认值**（核心）：`chat-message-bubble-inner` 和内容列容器都是 flex 容器，其子元素默认 `min-width: auto`，不会缩小到小于内容固有宽度。当内容含宽元素（代码块/表格/长 URL）时，子元素撑破 `maxWidth: 75%` 约束。

2. **`overflow-x: auto` 元素在无约束父级中膨胀**：代码块 `pre` 和表格 `tableContainer` 设置了 `overflowX: 'auto'`，本意是内部滚动，但因父级无 `minWidth: 0`，它们不会触发内部滚动，反而撑大父级宽度。

3. **`chat-messages` 容器 `overflowX` 被计算为 `auto`**：只设了 `overflowY: 'auto'`，按 CSS 规范 `overflow-x` 会从 `visible` 计算为 `auto`，因此撑破的内容在此容器上产生横向滚动条。

4. **气泡本体和 MessageRenderer 容器缺少 `overflow` 兜底**：气泡本体只有 `wordBreak`，无 `overflow` 约束；`.message-renderer-content` 也无宽度约束。

## 修改方案

### 修改文件 1：`src/renderer/components/Character/CharacterDialogueChat/ChatMessageBubble.tsx`

**改动 1**：`chat-message-bubble-inner`（L304-309）添加 `minWidth: 0`

```tsx
// L304-309，修改前：
style={{
  display: 'flex',
  gap: '12px',
  maxWidth: '75%',
  flexDirection: isUser ? 'row-reverse' : 'row',
}}

// 修改后：
style={{
  display: 'flex',
  gap: '12px',
  maxWidth: '75%',
  minWidth: 0,  // 新增：允许 flex 子元素缩小，防止宽内容撑破
  flexDirection: isUser ? 'row-reverse' : 'row',
}}
```

**改动 2**：内容列容器（L337）添加 `minWidth: 0` 和 `flex: 1`

```tsx
// L337，修改前：
<div style={{ display: 'flex', flexDirection: 'column', gap: '6px' }}>

// 修改后：
<div style={{ display: 'flex', flexDirection: 'column', gap: '6px', minWidth: 0, flex: 1 }}>
```

**改动 3**：气泡本体（L346-362）添加 `overflow: 'hidden'` 和 `overflowWrap: 'break-word'`

```tsx
// L346-362，在现有 style 对象中新增：
style={{
  // ...现有属性保持不变...
  wordBreak: 'break-word',
  overflowWrap: 'break-word',  // 新增：兜底换行
  overflow: 'hidden',          // 新增：防止子元素溢出气泡边界
  // ...其余属性...
}}
```

### 修改文件 2：`src/renderer/components/Character/CharacterDialogueChat/MessageRenderer/MessageRenderer.styles.css`

**改动 4**：`.message-renderer-content`（L26-28）添加 `overflow: hidden` 和 `minWidth: 0`

```css
/* L26-28，修改前：*/
.message-renderer-content {
  position: relative;
}

/* 修改后：*/
.message-renderer-content {
  position: relative;
  overflow: hidden;
  min-width: 0;
  max-width: 100%;
}
```

**改动 5**：`.message-renderer`（L1-24）添加 `max-width: 100%` 和 `overflow: hidden`

```css
/* L18-24，在现有规则中追加：*/
.message-renderer {
  /* ...现有变量和属性... */
  word-wrap: break-word;
  overflow-wrap: break-word;
  max-width: 100%;    /* 新增 */
  overflow: hidden;   /* 新增 */
}
```

### 修改文件 3：`src/renderer/components/Character/CharacterDialogueChat/CharacterDialogueChat.tsx`

**改动 6**：`chat-messages` 容器（L384-389）显式添加 `overflowX: 'hidden'`

```tsx
// L384-389，修改前：
style={{
  flex: 1,
  overflowY: 'auto',
  padding: isFullscreen ? '32px 40px' : '20px',
  position: 'relative',
}}

// 修改后：
style={{
  flex: 1,
  overflowY: 'auto',
  overflowX: 'hidden',  // 新增：显式隐藏横向滚动，避免被计算为 auto
  padding: isFullscreen ? '32px 40px' : '20px',
  position: 'relative',
}}
```

## 不修改的部分（保持原样）

- 代码块 `pre` 的 `overflowX: 'auto'`（MessageRenderer.tsx L39 和 MessageRenderer.styles.css L152）——保持不变，修复父级约束后，代码块会在气泡内部横向滚动，这是正确行为
- 表格 `tableContainer` 的 `overflowX: 'auto'`（MessageRenderer.tsx L46 和 MessageRenderer.styles.css L183）——同上，保持内部滚动
- `maxWidth: '75%'`——保持不变，气泡最大宽度限制不变
- 所有现有交互逻辑（hover、编辑、复制按钮等）——不受影响

## 修复效果说明

修复后的行为：
1. **普通长文本**：按气泡宽度自动换行（`wordBreak` + `overflowWrap`），无横向滚动
2. **代码块**：在气泡内部横向滚动（`pre` 的 `overflowX: auto` 生效），不撑破气泡
3. **表格**：在气泡内部横向滚动（`tableContainer` 的 `overflowX: auto` 生效），不撑破气泡
4. **长 URL**：自动断行（`overflowWrap: break-word`），不撑破气泡
5. **不同屏幕尺寸**：`maxWidth: 75%` 保持响应式，`minWidth: 0` 确保灵活收缩

## 假设与决策

1. **假设**：横向滚动条仅在 AI 回复（含 Markdown 渲染）时出现，用户消息（纯文本）不易触发——但修复对两者都适用
2. **决策**：保留代码块和表格的内部横向滚动（`overflowX: auto`），而非强制换行——因为代码换行会破坏可读性，内部滚动是更合理的 UX
3. **决策**：`chat-messages` 容器用 `overflowX: 'hidden'` 而非 `overflowX: 'auto'`——横向滚动条不应出现在消息列表层级，应在气泡内部处理

   - 用户消息（短文本/长文本）→ 显示正常，交互不受影响
3. 确认 hover、编辑、复制按钮等交互功能正常
