# 操作按钮区域两行布局优化方案

## 问题分析

当前 ContentWorkspace 组件中，操作按钮区域所有按钮集中在一个 `display: 'flex'` 容器中（第845-966行），导致按钮数量过多时单行拥挤，影响美观和可用性。

## 当前布局结构

```
Card.extra ── div (display: flex, gap: 8)
  ├── 生成 | 连续生成 | 重新生成 | 清空 | 分解 | 合并 | AI历史 | 导出
  ├── 暂停/继续 | 停止
  └── 保存 | 版本 | 调整参数
```

## 目标布局结构

```
Card.extra ── div (display: flex, flexDirection: column, gap: 8)
  ├── 第一行: div (display: flex, gap: 8, flexWrap: wrap)
  │   ├── 生成 | 连续生成 | 重新生成 | 清空 | 分解 | 合并 | AI历史 | 导出
  │   └── 暂停/继续 | 停止 (生成中状态)
  ── 第二行: div (display: flex, gap: 8, flexWrap: wrap)
      └── 保存 | 版本 | 调整参数
```

## 修改方案

### 步骤1：修改 Card.extra 容器结构

将当前单一的 `flex` 容器拆分为两行布局：

**原结构（第844-966行）：**
```tsx
extra={
  <div style={{ display: 'flex', gap: 8 }}>
    {!isGenerating ? (
      <>
        <Button ...>生成</Button>
        <Button ...>连续生成</Button>
        ...
      </>
    ) : (
      <>
        <Button ...>继续/暂停</Button>
        <Button ...>停止</Button>
      </>
    )}
    <Button ...>保存</Button>
    <Dropdown ...>版本</Dropdown>
    <Button ...>调整参数</Button>
  </div>
}
```

**新结构：**
```tsx
extra={
  <div style={{ display: 'flex', flexDirection: 'column', gap: 8 }}>
    <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
      {!isGenerating ? (
        <>
          <Button ...>生成</Button>
          <Button ...>连续生成</Button>
          ...
        </>
      ) : (
        <>
          <Button ...>继续/暂停</Button>
          <Button ...>停止</Button>
        </>
      )}
    </div>
    <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
      <Button ...>保存</Button>
      <Dropdown ...>版本</Dropdown>
      <Button ...>调整参数</Button>
    </div>
  </div>
}
```

### 步骤2：保持原有功能不变

- 所有按钮的样式（尺寸、颜色、图标、文字）完全保留
- 所有按钮的事件处理函数保持不变
- 字数统计显示位置保持不变（仍在 Card.title 中）
- 章节标题显示位置保持不变（仍在 Card.title 中）

### 步骤3：响应式适配

添加 `flexWrap: 'wrap'` 确保在窄屏幕下按钮自动换行，保持良好的显示效果。

## 涉及文件

1. `src/renderer/components/Creative/WritingMode/ContentWorkspace.tsx` — 唯一需要修改的文件

## 验证要点

1. 非生成状态下，操作按钮分为两行显示
2. 生成状态下，暂停/停止按钮在第一行，保存/版本/调整参数在第二行
3. 章节标题和字数统计不受影响
4. 所有按钮功能正常
5. 在不同窗口大小下测试布局表现
