# 小说写作模式自定义设置功能开发计划

## 总结

为小说写作模式开发自定义设置功能，允许用户对小说类型和写作风格进行个性化配置。核心功能包括：从零创建全新定义、提供预置模板、基于预置模板修改定制、保存/加载/管理功能。

UI 入口嵌入在现有 [WritingConfigPanel.tsx](file:///g:/AI/creative-cafe/src/renderer/components/Creative/WritingMode/WritingConfigPanel.tsx) 的小说类型/写作风格选择器旁，通过"管理"按钮打开模板管理弹窗。

## 当前状态分析

### 现有架构

1. **类型定义**：`NovelType`（12种）和 `WritingStyle`（7种）是硬编码枚举，定义在 [writing.types.ts](file:///g:/AI/creative-cafe/src/shared/types/writing.types.ts) 第9-40行

2. **预置模板**：[NovelTypeTemplates.ts](file:///g:/AI/creative-cafe/src/main/services/writing/NovelTypeTemplates.ts) 导出三个静态对象：
   - `NovelTypeTemplates: Record<NovelType, NovelTypeTemplate>` — 每种类型含 name、systemPrompt、outlineStructure、writingStyle、typicalChapterLength
   - `StyleGuidance: Record<WritingStyle, string>` — 每种风格一段详细描述
   - `PerspectiveGuidance: Record<NarrativePerspective, string>` — 视角指导（本次不涉及自定义）

3. **提示词构建**：[PromptBuilder.ts](file:///g:/AI/creative-cafe/src/main/services/writing/PromptBuilder.ts) 直接通过 `NovelTypeTemplates[type]` 和 `StyleGuidance[style]` 索引获取模板内容，拼接进系统提示词和大纲提示词

4. **配置面板**：[WritingConfigPanel.tsx](file:///g:/AI/creative-cafe/src/renderer/components/Creative/WritingMode/WritingConfigPanel.tsx) 使用 `NOVEL_TYPE_OPTIONS` 和 `WRITING_STYLE_OPTIONS`（来自 [writing.constants.ts](file:///g:/AI/creative-cafe/src/shared/constants/writing.constants.ts)）填充下拉选择器

5. **配置保存**：当前仅用 `localStorage`（key: `writing-config-saved`）保存表单参数，不含模板定义

6. **IPC 架构**：通过 `preload.ts` 暴露 `window.electronAPI.writing.*` API，主进程 `ipcMain.handle` 注册处理器，写作相关处理器在 `src/main/ipc/handlers/writing/` 目录下

7. **存储架构**：文件系统持久化，数据存储在 `{userData}/creative-cafe/data/` 下各子目录，使用安全写入（先写 .tmp 再 rename）

### 现有局限

- 小说类型和写作风格是枚举，无法动态扩展
- 预置模板只读，用户无法修改
- 无法创建全新的类型/风格定义
- 模板定义没有持久化机制

### 2. 预置模板转换层 — 将静态模板转为统一格式

**文件**：[src/main/services/writing/NovelTypeTemplates.ts](file:///g:/AI/creative-cafe/src/main/services/writing/NovelTypeTemplates.ts)

在文件末尾新增两个函数，将预置模板转换为统一格式：

```typescript
import { CustomNovelTypeTemplate, CustomWritingStyleTemplate } from '../../../shared/types/writing.types';

// 获取所有预置小说类型模板（统一格式）
export function getPresetNovelTypeTemplates(): CustomNovelTypeTemplate[] {
  return Object.entries(NovelTypeTemplates).map(([type, template]) => ({
    id: type,  // 预置模板使用枚举值作为ID
    name: template.name,
    systemPrompt: template.systemPrompt,
    outlineStructure: template.outlineStructure,
    writingStyle: template.writingStyle,
    typicalChapterLength: template.typicalChapterLength,
    isPreset: true,
    createdAt: 0,
    updatedAt: 0
  }));
}

// 获取所有预置写作风格模板（统一格式）
export function getPresetWritingStyleTemplates(): CustomWritingStyleTemplate[] {
  return Object.entries(StyleGuidance).map(([style, description]) => ({
    id: style,  // 预置模板使用枚举值作为ID
    name: WRITING_STYLE_LABELS_MAP[style] || style,
    description,
    isPreset: true,
    createdAt: 0,
    updatedAt: 0
  }));
}
```

需要引入 `WRITING_STYLE_LABELS` 来获取风格中文名称，或直接内联映射。

## 假设与决策

1. **向后兼容**：保留现有 `NovelType` 和 `WritingStyle` 枚举及预置模板，自定义模板通过新增可选字段引用，不破坏现有项目数据

2. **预置模板只读**：预置模板不可编辑/删除，用户"基于预置模板修改"时创建副本（`isPreset=false`）

3. **全局共享**：自定义模板全局可用，所有写作项目共享同一套模板库

4. **存储位置**：使用文件系统持久化（`{userData}/creative-cafe/data/writing-templates/`），与写作项目存储一致，不使用 localStorage

5. **ID 规范**：预置模板使用枚举值作为 ID（如 `'web_novel'`），自定义模板使用 `custom_` 前缀 + 时间戳 + 随机串（如 `'custom_1700000000000_abc123'`）

6. **风格模板字段**：采用基础字段方案，仅包含 name 和 description，与现有 `StyleGuidance` 结构一致

7. **UI 入口**：嵌入在 `WritingConfigPanel` 的选择器旁，通过"管理"按钮打开弹窗
