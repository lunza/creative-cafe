# 简化章节索引机制实施计划

## 目标
将 `index` 字段统一设计为兼具唯一标识与排序功能的核心属性，index值从1开始计数，在整个项目范围内保持全局唯一性，简化写作模式的复杂逻辑。

## 当前问题
1. **索引语义不一致**：
   - OutlineGenerator: `index` = 数组位置（0-based）
   - ContentWorkspace: `index` = 1-based ID + 0.1层级
   - ManualOutlineEditor: 混用两种语义
2. **状态管理混乱**：使用 `selectedChapterIndex`（数组位置）和 `chapterContents[index]`（1-based ID）混合
3. **清空/保存按钮失效**：key不匹配导致无法正确读取章节内容

## 设计方案

### 核心原则
- **index = 全局唯一标识**：从1开始，整数或小数（用于拆分子章节）
- **数组位置用于状态管理**：React state、UI渲染等使用数组索引
- **清晰分离**：index仅用于标识和排序，不用于状态管理

### 具体实施步骤

#### 步骤1：修改 OutlineGenerator.ts
- 将生成的章节index改为从1开始（1-based）
- 保持AI返回的index优先使用逻辑

```typescript
// 修改前
chapters: data.chapters.map((ch: any, idx: number) => ({
  index: ch.index || idx + 1,
  ...
}))

// 修改后
chapters: data.chapters.map((ch: any, idx: number) => ({
  index: ch.index || (idx + 1),  // 确保从1开始
  ...
}))
```

#### 步骤2：修改 ContentWorkspace.tsx - 状态管理重构

**2.1 重新生成按钮 disabled 条件**
```typescript
// 修改前

// 修改后 - 使用 ch.index 作为key
```

**2.2 清空按钮逻辑**
```typescript

  }}

// 修改后 - 移除disabled校验，始终可清空
<Button
  onClick={() => {
    if (!ch) return
    setChapterContents(prev => ({ ...prev, [ch.index]: '' }))
    message.success('章节内容已清空')
  }}
>
```

**2.3 handleSaveChapter 函数**
```typescript
// 修改前 - 使用 selectedChapterIndex 匹配
const ch = outline?.chapters[selectedChapterIndex]

// 修改后 - 使用当前选中章节的index
const ch = outline?.chapters.find(c => c.index === currentChapterIndex)
```

#### 步骤3：修复章节拆分索引生成

```typescript
// 修改前
const chapterIndex = baseIndex + i * 0.1  // 导致 1 和 1.1

// 修改后
const chapterIndex = baseIndex + (i + 1) * 0.1  // 生成 1.1 和 1.2
```

**拆分逻辑完整流程**：
1. 获取当前章节的index作为baseIndex
2. 生成子章节index: baseIndex + 0.1, baseIndex + 0.2, ...
3. 更新outline.chapters数组，替换原章节为子章节数组
4. 更新chapterContents和chapterStatuses，使用新index作为key

#### 步骤4：修改 ManualOutlineEditor.tsx

**4.1 章节列表渲染**
- 使用数组索引进行渲染和交互
- 保持ch.index用于数据标识

```typescript
// 修改前
const moveChapter = (fromIndex: number, toIndex: number) => {
  // 使用 ch.index 进行匹配
}

// 修改后
const moveChapter = (fromArrayIndex: number, toArrayIndex: number) => {
  // 使用数组位置进行拖拽排序
  const chapters = [...outline.chapters]
  const [moved] = chapters.splice(fromArrayIndex, 1)
  chapters.splice(toArrayIndex, 0, moved)
  // 重新编号index以保持连续性
  chapters.forEach((ch, idx) => {
    ch.index = idx + 1
  })
}
```

**4.2 删除章节**
```typescript
// 修改后
const deleteChapter = (arrayIndex: number) => {
  const chapters = outline.chapters.filter((_, idx) => idx !== arrayIndex)
  // 重新编号
  chapters.forEach((ch, idx) => {
    ch.index = idx + 1
  })
  setOutline({ ...outline, chapters })
}
```

#### 步骤6：数据迁移策略

**对于现有项目**：
1. 加载项目时检测index格式
2. 如果index是0-based，自动转换为1-based
3. 在WritingStorageService中添加迁移逻辑

```typescript
// 迁移函数
const migrateProjectIndices = (project: WritingProject): WritingProject => {
  const firstChapter = project.chapters[0]
  if (firstChapter && firstChapter.index === 0) {
    // 0-based，需要迁移
    return {
      ...project,
      chapters: project.chapters.map((ch, idx) => ({
        ...ch,
        index: idx + 1
      }))
    }
  }
  return project
}
```
