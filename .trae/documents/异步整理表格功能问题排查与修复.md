# 异步整理表格功能问题排查与修复方案

## 问题分析

### 问题1：表格整理提示词未正确拼接到对话提示词末尾

**根本原因**：在 `PromptBuilder.ts` 第359行，异步整理指令的追加条件为：
```typescript
if (organizeMode === 'async' && memoryTableData && memoryTableData.trim()) {
```

这里要求 `memoryTableData` 必须非空才会追加异步整理指令。但实际上存在以下场景会导致提示词缺失：
- 当表格文件不存在或为空时，`memoryTableData` 为空字符串，异步整理指令不会被追加
- 即使启用了异步整理模式，AI也收不到整理指令，自然不会在回复中输出 tableEdit 标签

**修复方案**：将异步整理指令的追加条件改为仅依赖 `organizeMode === 'async'`，不强制要求 `memoryTableData` 存在。当表格数据为空时，提示AI创建新的表格条目。

### 问题2：函数执行后表格更新机制未被触发

**可能原因分析**：
1. 由于问题1导致AI没有收到整理指令，因此回复中没有 tableEdit 标签，正则匹配失败
2. 正则表达式 `/<!--\s*<tableEdit>([\s\S]*?)<\/tableEdit>\s*-->/gi` 与提示词中要求的格式 `<!--  <tableEdit>` 存在细微差异（提示词中 `<!--` 后有两个空格，而正则中的 `\s*` 应该能匹配，但需要确认AI是否严格按照格式输出）
3. 在 `CharacterDialogueChat.hooks.ts` 第721行，触发条件为 `memoryTableAutoOrganizeRef.current && memoryTableOrganizeModeRef.current === 'async'`，需要确认这两个ref的值是否正确

**修复方案**：
1. 修复问题1后，AI会收到指令并输出标签
2. 增强日志记录，记录解析过程的详细信息
3. 确保正则表达式能兼容AI可能的输出变体
