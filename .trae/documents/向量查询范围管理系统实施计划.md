# 向量查询范围管理系统实施计划

## 📋 需求概述

基于 `vector_registry.json` 配置文件，实现向量查询范围管理系统，包含以下核心功能：

1. **向量测试功能** - 多选界面选择查询范围
2. **向量化数据利用功能** - 对话模块、数据查询模块等集成范围选择
3. **知识库显示增强** - 按文档名称分组显示，点击后懒加载详情

---

## 🏗️ 架构设计

### 数据流

```
vector_registry.json (后端)
       ↓
VectorRegistryService.getAvailableScopes()
       ↓
IPC: vector:getAvailableScopes
       ↓
前端 VectorScopeSelector 组件 (多选)
       ↓
选中范围: scopeIds[]
       ↓
IPC: vector:search({ scopeIds })
       ↓
VectorStoreService.search(query, topK, filter, { scopeIds })
       ↓
搜索结果 (仅包含选中范围内的向量)
```

```typescript
  id: string;
  label: string;
  sourceType: string;
  sourceId: string;
  sourceName: string;
  vectorCount: number;
  description?: string;
}

interface VectorState {
  // ... 现有字段
  availableScopes: VectorScope[];

  scopesLoading: boolean;
  
  // 新增方法

  toggleScope: (scopeId: string) => void;

}
```
