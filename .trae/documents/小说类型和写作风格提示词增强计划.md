# 小说类型和写作风格提示词增强计划

## 目标

为 `NovelTypeTemplates.ts` 中的所有小说类型和写作风格创建专业性强、内容详实的提示词，每段提示词字数严格控制在200字以上。

## 当前状态分析

- 文件位置：`src/main/services/writing/NovelTypeTemplates.ts`
- 现有小说类型：网文、言情、武侠、玄幻、奇幻、悬疑、科幻、历史、都市、其他（10种）
- 新增小说类型：纪实、色情文学（待添加）
- 现有写作风格：轻松、严肃、幽默、悬疑、浪漫、史诗（6种）
- 新增写作风格：细节（待添加）
- 当前提示词问题：字数较短（约50-80字），缺乏详细指导

## 实施步骤

### 第一步：增强现有10种小说类型的 systemPrompt

为每种类型重写 systemPrompt，确保包含以下要素（每段200+字）：
1. 核心特征定义
2. 典型叙事结构
3. 人物塑造要求
4. 语言风格特点
5. 情感表达方向
6. 情节设置指导
7. 冲突节点安排

涉及类型：
- WEB_NOVEL（网文）
- ROMANCE（言情）
- MARTIAL_ARTS（武侠）
- FANTASY（玄幻）
- FANTASY_MAGIC（奇幻）
- MYSTERY（悬疑）
- SCI_FI（科幻）
- HISTORICAL（历史）
- URBAN（都市）
- OTHER（其他）

### 第二步：添加新增2种小说类型的完整模板

创建 DOCUMENTARY（纪实）和 EROTIC（色情文学）的完整模板，包含：
- name（中文名称）
- systemPrompt（200+字专业提示词）
- outlineStructure（大纲结构数组）
- writingStyle（写作风格描述）
- typicalChapterLength（典型章节长度）

### 第三步：增强现有6种写作风格的 StyleGuidance

为每种风格重写指导词，确保包含以下要素（每段200+字）：
1. 整体基调描述
2. 语言运用特点
3. 节奏控制方法
4. 情感渲染技巧
5. 场景描写要求
6. 对话风格指导

涉及风格：
- RELAXED（轻松）
- SERIOUS（严肃）
- HUMOROUS（幽默）
- SUSPENSEFUL（悬疑）
- ROMANTIC（浪漫）
- EPIC（史诗）

### 第四步：添加新增1种写作风格的完整指导

创建 DETAILED（细节）风格的完整指导词（200+字），包含上述6个要素。

### 第五步：同步更新 writing.constants.ts

确保 NOVEL_TYPE_LABELS 和 WRITING_STYLE_LABELS 包含所有新增类型和风格的中文标签（此步骤已在之前完成，需验证）。

## 质量标准

1. 每段 systemPrompt 和 StyleGuidance 必须严格达到200字以上（中文字符计数）
2. 内容必须专业、具体、可操作
3. 必须涵盖用户要求的所有关键要素
4. 保持与现有代码结构的一致性
5. 不影响其他功能的正常运行

## 验证方式

1. 使用 TypeScript 类型检查确保无编译错误
2. 手动计数验证每段提示词字数
3. 检查所有枚举值是否都有对应的模板和指导
