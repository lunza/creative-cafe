# 修复写作模式章节内容丢失问题

## 问题根因
`WritingStorageService.loadProject()` 中的正则表达式无法匹配浮点数索引的章节文件（如 `chapter-1.1.md`），导致章节拆分/AI子章节生成后的内容在重新加载项目时丢失。

## 修复步骤

### 1. 修复 `WritingStorageService.ts` 中的正则表达式
**文件**: `d:\AI\creative-cafe\src\main\services\WritingStorageService.ts`
**位置**: 第 239 行

**修改前**:
```typescript
const match = file.match(/^chapter-(\d+)\.md$/);
```

**修改后**:
```typescript
const match = file.match(/^chapter-(\d+(?:\.\d+)?)\.md$/);
```

**说明**: 
- `\d+` 只匹配整数（如 `1`, `2`）
- `\d+(?:\.\d+)?` 匹配整数或浮点数（如 `1`, `1.1`, `1.2000000000000002`）

### 2. 修改章节索引解析方式
**文件**: `d:\AI\creative-cafe\src\main\services\WritingStorageService.ts`
**位置**: 第 241 行

**修改前**:
```typescript
const chapterIndex = parseInt(match[1], 10);
```

**修改后**:
```typescript
const chapterIndex = parseFloat(match[1]);
```

**说明**: 使用 `parseFloat` 正确解析浮点数索引

### 3. 重新编译项目
运行 `npm run build` 重新编译

### 4. 验证修复
1. 创建一个写作项目
2. 生成章节内容并保存
3. 进行章节拆分，生成子章节（索引如 1.1, 1.2）
4. 退出并重新加载项目
5. 验证所有章节内容正确显示

## 受影响的代码路径
- `loadProject()` - 加载项目时读取章节内容
- `autoSaveChapter()` - 自动保存章节内容
- `saveProject()` - 保存整个项目（包括章节）

## 风险评估
- **低风险**: 仅修改正则表达式和解析方式
- **向后兼容**: 新正则同时匹配整数和浮点数，不影响现有项目
