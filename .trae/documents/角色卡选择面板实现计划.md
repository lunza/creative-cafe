# 角色卡选择面板实现计划

## 需求概述
在聊天对话框（CharacterDialogueChat）的左侧区域实现一个垂直的角色卡选择面板，用户可以通过鼠标滚轮滚动浏览并选择角色卡，选择后执行与点击"对话"按钮相同的操作流程。

## 当前结构分析
- CharacterDialogueChat 组件目前由两部分组成：聊天区域（左侧 flex: 1）和配置面板（ConfigPanel，右侧）
- 角色卡数据来自 CharacterManager 中的 Character 接口，包含 name、path 等信息
- handleTestCharacter 函数负责：读取角色卡内容 → 设置 characterInfo → 加载头像 → 打开对话框
- 角色卡列表可通过 useDataStore 的 characters 获取

## 实施步骤

### 步骤 1：创建角色卡选择面板组件
**文件**: `src/renderer/components/Character/CharacterDialogueChat/CharacterSelectorPanel.tsx`

创建新组件 CharacterSelectorPanel，包含以下功能：
- 垂直长条型布局，固定在对话框左侧
- 使用 useDataStore 获取所有角色卡列表
- 显示每个角色卡的头像（使用已有的 ThumbnailImage 组件或类似方式加载 base64 图片）和名称
- 实现鼠标滚轮滚动选择功能（onWheel 事件处理）
- 选中状态高亮显示（使用边框、背景色或渐变效果）
- 暴露 onSelect 回调，传递选中的角色卡信息

**关键实现细节**:
- 面板宽度约 120-150px
- 每个角色卡项目高度约 80-100px
- 使用 overflow-y: auto 支持滚动
- onWheel 事件阻止默认行为，实现平滑滚动
- 选中项自动滚动到可见区域
- 使用虚拟滚动优化性能（如果角色卡数量较多）

**类型定义**:
```typescript
interface CharacterSelectorPanelProps {
  characters: Character[];
  selectedCharacterPath?: string;
  onSelect: (character: Character) => void;
}
```

### 步骤 5：实现滚轮滚动选择交互

在 CharacterSelectorPanel 中实现滚轮交互：
1. 添加 onWheel 事件处理器
2. 计算滚动增量（每次滚轮滚动移动 1-2 个角色卡项目）
3. 使用 ref 获取容器 DOM 元素
4. 通过 scrollTo 或修改 scrollTop 实现平滑滚动
5. 实现惯性滚动效果（可选，提升用户体验）

**关键代码逻辑**:
```typescript
const handleWheel = (e: React.WheelEvent) => {
  e.preventDefault();
  const scrollAmount = e.deltaY > 0 ? ITEM_HEIGHT : -ITEM_HEIGHT;
  containerRef.current?.scrollBy({ top: scrollAmount, behavior: 'smooth' });
};
```

## 技术要点

### 图片加载优化
- 复用现有的 thumbnailCache 缓存机制
- 使用 IntersectionObserver 实现懒加载（仅加载可见区域的图片）
- 图片加载失败时显示默认头像图标

### 性能优化
- 使用 React.memo 优化角色卡项目渲染
- 虚拟滚动（如果角色卡数量 > 50）
- 防抖处理快速滚轮事件

### 用户体验
- 选中状态清晰可见（高亮、边框、背景色）
- 平滑滚动动画
- 键盘导航支持（上下箭头键）
- 加载状态指示器
