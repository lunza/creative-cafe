# 世界书内容拼接修复计划

## 问题分析

在章节生成流程中，世界书内容拼接存在以下问题：

1. **数据提取错误**：在 `writingHandlers.ts:L386-389` 中，世界书加载后只提取了 `wb.content`（世界书顶层内容字段），而实际条目内容存储在 `wb.entries` 数组中每个条目的 `content` 字段里。顶层 `content` 通常是空或描述性文字，不是条目正文。

2. **缺少向量化检索**：当前实现直接加载所有世界书数据，没有基于章节大纲内容进行向量搜索来匹配相关条目。

3. **缺少关键词信息**：世界书条目的 `keywords` 字段没有提取和拼接。

**当前错误链路**：
```
writingHandlers.ts:
  worldBooks.map(wb => ({
    entryName: wb.name,
    content: wb.content || wb.summary || ''  // ❌ 只取了顶层 content，丢失了 entries 数据
  }))
```

**正确链路应该是**：
```
writingHandlers.ts:
  1. 获取章节大纲内容 (request.chapterInfo.outline)
  2. 对每个世界书调用 searchWorldBookEntriesByVector(worldBookPath, outlineQuery, topK)
  3. 从检索结果中提取条目原文 (entry.content) 和关键词 (entry.keywords)
  4. 构建 worldBookContext 包含条目名称、关键词、原文内容
```

## 实施步骤

### 步骤1：修改 writingHandlers.ts 的 worldBookContext 构建逻辑

在 `writingHandlers.ts` 的 `writing:generateChapter` handler 中，替换当前的 worldBook 加载逻辑：

**原代码**（`writingHandlers.ts:L386-389`）：
```typescript
if (worldBooks.length > 0) {
  addLog(`[Resources] 加载世界书: ${worldBooks.length}个`, 'debug');
  request.worldBookContext = worldBooks.map(wb => ({
    entryName: wb.name || wb.entryName || '未知',
    content: wb.content || wb.summary || '',
    relevance: 1.0
  }));
}
```

**修改为**：
```typescript
if (worldBooks.length > 0) {
  addLog(`[Resources] 加载世界书: ${worldBooks.length}个`, 'debug');
  
  // 基于章节大纲进行向量检索
  const chapterOutline = request.chapterInfo?.outline || '';
  const worldBookEntries: WorldBookContext[] = [];
  
  for (const wb of worldBooks) {
    try {
      // 对每个世界书执行向量检索
      const searchResults = await worldBookService.searchWorldBookEntriesByVector(
        wb.id, // worldBook file path or id
        chapterOutline,
        5 // topK
      );
      
      if (searchResults.length > 0) {
        addLog(`[WorldBook] 世界书"${wb.name}" 检索到 ${searchResults.length} 个相关条目`, 'debug');
        
        for (const result of searchResults) {
          const entry = result.metadata as any;
          worldBookEntries.push({
            entryName: entry.name || wb.name,
            content: entry.content || '',
            keywords: entry.keywords || [],
            relevance: result.score
          });
        }
      }
    } catch (error) {
      addLog(`[WorldBook] 世界书"${wb.name}" 向量检索失败: ${error}`, 'warn');
    }
  }
  
  request.worldBookContext = worldBookEntries;
}
```

### 步骤2：扩展 WorldBookContext 类型支持 keywords 字段

在 `writing.types.ts` 中，`WorldBookContext` 需要支持 `keywords` 字段：

```typescript
worldBookContext: {
  entryName: string;
  content: string;
  keywords?: string[]; // 新增
  relevance: number;
}[];
```

### 步骤3：修改 ContentGenerator.ts 的 buildResourceContext 方法

在 `ContentGenerator.ts` 中，更新世界书的格式化输出，包含关键词：

```typescript
if (hasWorldBooks) {
  parts.push('## 世界观设定');
  for (const wb of request.worldBookContext) {
    parts.push(`### ${wb.entryName}`);
    if (wb.keywords && wb.keywords.length > 0) {
      parts.push(`关键词: ${wb.keywords.join('、')}`);
    }
    parts.push(wb.content);
  }
}
```

### 步骤4：添加 worldBookService 导入到 writingHandlers.ts

确保 `writingHandlers.ts` 正确导入 `worldBookService`。

## 涉及修改的文件

1. `src/main/ipc/handlers/writingHandlers.ts` - 核心修复：添加世界书向量检索逻辑

3. `src/main/services/writing/ContentGenerator.ts` - buildResourceContext 添加关键词输出
