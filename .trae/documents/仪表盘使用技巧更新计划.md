# 仪表盘使用技巧更新计划

> 基于系统技术文档，为仪表盘首页的"使用技巧"轮播区更新清晰、简洁、实用的系统使用指南

---

## 一、背景

### 当前状态
- 仪表盘 Tips 区域通过 `window.electronAPI.file.readJson('tips')` 异步读取 JSON 文件
- Tips 文件存储在 `data/` 目录下（相对于项目根目录）
- 当前 Tips 文件不存在，使用硬编码默认内容：`"欢迎使用 Creative-Cafe！这是一个强大的角色卡和世界书管理工具。"`
- Tips 通过 Ant Design Carousel 组件轮播展示，5 秒自动播放，支持左右手动切换

### 更新目标
将 Tips 内容替换为基于技术文档的完整系统使用指南，覆盖：
1. 系统导航说明
2. 核心功能亮点
3. 常见工作流指导
4. 效率提升技巧

---

## 三、Tips 内容设计说明

### 内容覆盖范围
| 编号 | 类别 | 覆盖内容 |
|------|------|---------|
| 1 | 导航说明 | 系统整体架构、11 个核心模块功能概览 |
| 2 | 关键配置 | AI 引擎配置（系统运行的前提条件） |
| 3 | 功能亮点 | 世界书 AI 辅助功能（翻译/润色/生成/排序/向量化） |
| 4 | 工作流 | 角色卡创作→测试→优化的完整闭环 |
| 5 | 功能亮点 | 角色对话测试高级功能（流式/续写/重试/参数调节） |
| 6 | 功能亮点 | 知识库语义检索与对话上下文增强 |
| 7 | 导航说明 | 用户人设管理功能与使用场景 |
| 8 | 效率技巧 | 5 条实用效率提升技巧 |
| 9 | 安全说明 | 数据持久化机制与 API 密钥安全 |
| 10 | 工作流 | 推荐完整工作流程（从配置到验证） |

### 设计原则
- **简洁清晰**: 每条 Tips 控制在 100-150 字以内，便于快速阅读
- **用户导向**: 从用户实际使用场景出发，避免技术术语堆砌
- **可操作性**: 包含明确的导航路径和操作步骤
- **渐进式学习**: 从基础导航到高级功能再到完整工作流，由浅入深

## 四、风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| Tips 文件路径解析失败 | 显示默认内容 | 现有代码已有 try-catch 保护，会降级使用默认 Tips |
| 内容过长导致显示异常 | 轮播卡片高度不足 | 内容控制在合理范围内，Carousel 组件自动适配 |
| JSON 格式错误 | 解析失败 | 创建前使用 JSON Lint 验证格式 |

## 五、后续维护建议

1. **版本更新时同步更新 Tips**: 新增功能模块或重大改动时，及时补充/修改对应 Tips
2. **用户反馈收集**: 根据用户实际使用情况，补充常见问题的解决方案到 Tips
3. **多语言支持**: 未来可考虑根据系统语言切换加载对应的 tips.json（如 `tips-zh.json`、`tips-en.json`）
4. **动态更新**: 可通过远程配置或插件机制实现 Tips 的动态更新，无需发布新版本
