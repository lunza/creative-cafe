# 修复章节合并连续性校验逻辑计划

## 问题描述
当前 `ChapterMergeModal.tsx` 中的 `isConsecutive` 校验使用 `sorted[i] !== sorted[i - 1] + 1` 判断连续性，这只适用于整数索引（如 1, 2, 3），对于小数索引（如 1.1, 1.2）会失败，因为 1.1 + 1 = 2.1 ≠ 1.2。

## 根本原因
章节的"连续性"应该是指它们在 `outline.chapters` 数组中的**位置连续**，而不是 index 值相差 1。

## 解决方案

### 修改位置
`src/renderer/components/Creative/WritingMode/ChapterMergeModal.tsx` 第 45-51 行

### 修改前代码
```typescript
const isConsecutive = selectedIndices.length >= 2 && (() => {
  const sorted = [...selectedIndices].sort((a, b) => a - b);
  for (let i = 1; i < sorted.length; i++) {
    if (sorted[i] !== sorted[i - 1] + 1) return false;
  }
  return true;
})();
```

### 修改后代码
```typescript
const isConsecutive = selectedIndices.length >= 2 && (() => {
  const sortedIndices = [...selectedIndices].sort((a, b) => a - b);
  const arrayPositions = sortedIndices.map(idx =>
    chapters.findIndex(ch => ch.index === idx)
  );
  for (let i = 1; i < arrayPositions.length; i++) {
    if (arrayPositions[i] !== arrayPositions[i - 1] + 1) return false;
  }
  return true;
})();
```

### 逻辑说明
1. 将用户选择的 `selectedIndices`（章节 index 值）转换为在 `chapters` 数组中的位置
2. 对这些数组位置排序
3. 检查相邻位置是否连续（相差 1）

### 示例
- 选择 index 为 1.1 和 1.2 的章节
- 它们在数组中的位置可能是 3 和 4
- `arrayPositions = [3, 4]` → 连续 → 允许合并

- 选择 index 为 1.1 和 2 的章节
- 它们在数组中的位置可能是 3 和 6
- `arrayPositions = [3, 6]` → 不连续 → 禁止合并
