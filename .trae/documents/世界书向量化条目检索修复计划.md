# 世界书向量化条目检索修复计划

## 问题分析

根据用户反馈，当前实现只检索到了世界书的"描述"chunk（chunk 0），而没有检索到实际的条目内容。日志显示：

```
## 世界观设定 
### 世界书描述 
世界书名称: 西雅图沿海兽人小镇 
描述: 记录了美国西雅图沿海小镇的世界观...
```

**问题根因**：

1. **向量检索没有过滤掉描述chunk**：在 `searchWorldBookEntriesByVector` 中，向量存储包含了两种类型的chunk：
   - Chunk 0 (`sourceType: 'description'`, `isDescriptionChunk: true`)：世界书名称和描述
   - Chunks 1+ (`sourceType: 'entry'`, `isEntry: true`)：实际条目内容

   当前向量检索没有过滤掉描述chunk，导致返回的是描述信息而非条目内容。

2. **worldBookPath 过滤可能无效**：`wb.id` 可能与向量存储中使用的 `worldBookPath` 格式不一致。

3. **搜索范围限制**：当前方法接收 `worldBookPath` 参数进行过滤，但如果过滤条件不匹配，可能检索不到条目；如果过滤条件匹配但包含描述chunk，则检索到的是描述信息。

## 实施步骤

### 步骤1：修改 worldBookService.searchWorldBookEntriesByVector 方法

**目标**：移除 `worldBookPath` 参数，在向量搜索中添加 `sourceType: 'entry'` 过滤条件，排除描述chunk。

**修改位置**：`src/main/services/worldBookService.ts:L437-L452`

**修改内容**：
- 移除 `worldBookPath` 参数
- 在向量搜索中添加 `sourceType: 'entry'` 过滤条件，排除描述chunk
- 如果搜索结果为空，尝试不使用 `sourceType` 过滤再次搜索，然后过滤掉描述chunk

```typescript
async searchWorldBookEntriesByVector(query: string, topK: number = 5): Promise<Array<{ id: string; score: number; metadata: Record<string, any> }>> {
  try {
    console.log(`[WorldBookService] 开始搜索条目: query="${query?.substring(0, 50)}...", topK=${topK}`);
    
    const embedResult = await embeddingService.generateEmbedding(query);
    if (!embedResult.success || !embedResult.vector) {
      console.log(`[WorldBookService] 向量嵌入失败: ${embedResult.error}`);
      return [];
    }
    console.log(`[WorldBookService] 向量嵌入成功，维度=${embedResult.vector.length}`);
    
    // 只搜索条目类型，排除描述chunk
    const results = await vectorStoreService.search(embedResult.vector, topK, {
      source: VectorSourceType.WORLDBOOK,
      sourceType: 'entry'
    });
    console.log(`[WorldBookService] 搜索到 ${results.length} 个条目`);
    
    return results;
  } catch (error) {
    console.error('Failed to search world book entries:', error);
    return [];
  }
}
```

### 步骤2：修改 writingHandlers.ts 中的调用方式

**目标**：移除 `wb.id` 参数，直接搜索所有世界书条目，然后根据 `worldBookName` 过滤到当前世界书，并过滤掉描述chunk。

**修改位置**：`src/main/ipc/handlers/writingHandlers.ts:L392-L453`

**修改内容**：
```typescript
for (const wb of worldBooks) {
  try {
    addLog(`[WorldBook] 开始检索世界书"${wb.name}"的条目`, 'debug');
    
    // 直接搜索所有世界书条目，不限制 worldBookPath
    const searchResults = await worldBookService.searchWorldBookEntriesByVector(
      chapterOutline,
      5
    );
    
    addLog(`[WorldBook] 搜索到 ${searchResults.length} 个结果`, 'debug');
    
    if (searchResults.length > 0) {
      for (const result of searchResults) {
        const meta = result.metadata as any;
        
        addLog(`[WorldBook] 结果chunk: sourceType=${meta.sourceType}, isDescriptionChunk=${meta.isDescriptionChunk}, isEntry=${meta.isEntry}, entryName=${meta.entryName}, worldBookName=${meta.worldBookName}`, 'debug');
        
        // 过滤掉描述chunk（双重保险）
        if (meta.isDescriptionChunk || meta.sourceType === 'description') {
          addLog(`[WorldBook] 跳过描述chunk: ${meta.entryName}`, 'debug');
          continue;
        }
        
        // 验证条目属于当前世界书
        if (meta.worldBookName && meta.worldBookName !== wb.name) {
          addLog(`[WorldBook] 条目属于其他世界书: ${meta.worldBookName}`, 'debug');
          continue;
        }
        
        // 提取条目信息
        const entryName = meta.entryName || meta.name || '未命名';
        const entryContent = meta.entryContent || meta.content || '';
        const entryKeywords = meta.entryKeys || meta.entryKey || meta.keywords || [];
        
        addLog(`[WorldBook] 条目"${entryName}" 内容长度: ${entryContent.length}, 关键词数: ${entryKeywords.length}`, 'debug');
        
        if (!entryContent || !entryContent.trim()) {
          addLog(`[WorldBook] 跳过无内容的条目: ${entryName}`, 'debug');
          continue;
        }
        
        worldBookEntries.push({
          entryName,
          content: entryContent,
          keywords: Array.isArray(entryKeywords) ? entryKeywords : (entryKeywords ? [entryKeywords] : []),
          relevance: result.score
        });
      }
    }
    
    if (worldBookEntries.length === 0) {
      addLog(`[WorldBook] 世界书"${wb.name}" 未检索到相关条目，回退使用原始数据`, 'warn');
      // 回退：使用原始数据中的 entries
      if (wb.entries && wb.entries.length > 0) {
        for (const entry of wb.entries) {
          if (entry.content && entry.content.trim()) {
            worldBookEntries.push({
              entryName: entry.name || '未命名',
              content: entry.content,
              keywords: entry.keywords || [],
              relevance: 0.5
            });
          }
        }
      }
    }
  } catch (error) {
    addLog(`[WorldBook] 世界书"${wb.name}" 向量检索失败: ${error instanceof Error ? error.message : String(error)}，回退使用原始数据`, 'warn');
    // 回退：使用原始数据
    if (wb.entries && wb.entries.length > 0) {
      for (const entry of wb.entries) {
        if (entry.content && entry.content.trim()) {
          worldBookEntries.push({
            entryName: entry.name || '未命名',
            content: entry.content,
            keywords: entry.keywords || [],
            relevance: 0.5
          });
        }
      }
    }
  }
}
```
