# 章节分解功能方案

## 需求描述

在内容创作功能中，添加一个"分解"按钮，允许用户将当前章节拆解成 N 个子章节。

## 功能设计

### UI 交互

1. 在操作按钮栏添加"分解"按钮（位于"清空"和"导出"之间）
2. 点击后弹出模态框，用户可以：
   - 输入要分解成的子章节数量（默认 2，范围 2-10）
   - 可选：为每个子章节自定义标题
   - 选择分解模式：
     - **按内容均分**：将当前章节内容平均分配给各子章节
     - **仅创建空章节**：仅创建大纲条目，不拆分内容
3. 确认后，在当前章节位置后插入子章节

### 数据流程

1. 用户点击"分解"按钮
2. 弹出分解配置模态框
3. 用户配置后确认
4. 系统在当前章节后插入新的子章节（index 依次递增）
5. 更新 outline.chapters 数组
6. 更新 project.chapters
7. 刷新 UI（章节导航列表、当前选中状态）

### 实现细节

**新增文件/修改文件**：
- `ContentWorkspace.tsx`：添加分解按钮、分解配置模态框、分解逻辑

**分解逻辑**：
1. 获取当前章节内容
2. 按用户指定的数量，将内容均匀分段
3. 为每个子章节创建新的 chapter 对象
4. 更新 index 编号（当前章节保持原 index，子章节 index 依次 +0.1, +0.2... 或使用浮点数表示层级关系）
5. 将子章节插入到 outline.chapters 中当前章节之后
6. 同步更新 project.chapters

## 影响范围

- 仅影响 ContentWorkspace.tsx
- 不影响大纲设计、AI 生成等其他功能
