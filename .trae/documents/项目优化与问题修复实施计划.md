## 一、总体策略

### 1.1 修复优先级
按照问题严重性分级处理：
1. **P0 级**（8个）：直接影响功能可用性和数据完整性，必须优先修复
2. **P1 级**（15个）：影响用户体验和代码质量，第二阶段修复
3. **P2 级**（12个）：代码规范和优化，按需进行

### 1.2 实施原则
- 每个修复都要验证是否影响现有功能
- 涉及数据结构变更的，提供向后兼容
- 清理死代码前确认无其他模块依赖
- 关键修复添加必要的错误处理和日志

### P1-7: 缓存无容量限制

**问题**：`thumbnailCache`/`avatarCache` 等 Map 缓存无容量上限，存在 OOM 风险

**修复方案**：
- 文件：`src/renderer/components/Character/CharacterManager.tsx`
- 方案 A：使用 `lru-cache` 库
  ```typescript
  import { LRUCache } from 'lru-cache';
  
  const thumbnailCache = new LRUCache<string, string>({ max: 200 });
  const avatarCache = new LRUCache<string, string>({ max: 50 });
  ```
- 方案 B：实现简易 LRU
  ```typescript
  class SimpleLRU<K, V> {
    private cache = new Map<K, V>();
    private maxSize: number;
    
    constructor(maxSize: number) {
      this.maxSize = maxSize;
    }
    
    get(key: K): V | undefined {
      if (!this.cache.has(key)) return undefined;
      const value = this.cache.get(key)!;
      this.cache.delete(key);
      this.cache.set(key, value);
      return value;
    }
    
    set(key: K, value: V): void {
      if (this.cache.size >= this.maxSize) {
        const firstKey = this.cache.keys().next().value;
        this.cache.delete(firstKey);
      }
      this.cache.set(key, value);
    }
  }
  ```

**影响范围**：Character Manager 性能

**风险**：低
