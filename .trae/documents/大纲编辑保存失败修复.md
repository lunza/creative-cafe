# 大纲编辑保存失败修复方案

## 问题分析

### 根因

在 `OutlineEditor.tsx` 中点击"确认大纲"按钮后，系统仅执行了面板切换（`setActivePanel(ActivePanel.CONTENT)`），**没有将编辑后的大纲内容持久化到项目存储**。

### 数据流断裂点

```
用户编辑大纲 → editedOutline (本地state) → 点击"确认大纲" → 仅切换面板 ❌
                                                     ↓
                                             未更新 writingProjectStore ❌
                                                     ↓
                                             未调用 saveProject ❌
                                                     ↓
                                             刷新后数据丢失 ❌
```

### 具体场景

**场景1：AI生成模式（ai tab）**
- 用户在 `editedOutline` 本地state中编辑章节（`handleChapterEdit`）
- `handleSaveChapter` 仅关闭编辑模式，不保存
- `onConfirm` → 仅切换面板，未持久化

**场景2：手动编辑模式（manual tab）**
- `handleManualChaptersChange` 更新 `writingModeStore.setOutline()`
- 但这只是UI状态store，不是项目持久化store
- `onConfirm` → 仅切换面板，未同步到 `writingProjectStore`

## 修复方案

### 步骤1：修改 OutlineEditor.tsx 的 onConfirm 处理

在 OutlineEditor 组件内部，创建一个新的 `handleConfirmOutline` 函数，在切换面板前将编辑后的大纲内容同步到 `writingProjectStore`：

```typescript
const handleConfirmOutline = async () => {
  const { updateProject, getCurrentProject } = useWritingProjectStore.getState();
  const project = getCurrentProject();
  if (!project) return;

  // 根据当前模式获取最新的大纲数据
  const finalOutline = currentMode === 'manual' 
    ? buildManualOutline(manualChapters)
    : editedOutline;

  if (!finalOutline) return;

  // 更新项目的大纲数据
  await updateProject(project.id, {
    outline: finalOutline,
    outlineRaw: currentMode === 'ai' ? JSON.stringify(finalOutline, null, 2) : '',
    status: ProjectStatus.OUTLINING,
    chapters: finalOutline.chapters.map(ch => ({
      ...ch,
      content: project.chapters.find(c => c.index === ch.index)?.content || '',
      status: ChapterStatus.PENDING,
      wordCount: 0,
      versions: project.chapters.find(c => c.index === ch.index)?.versions || [],
      lastModified: Date.now()
    }))
  });

  onConfirm();
};
```

### 步骤2：构建手动模式大纲的辅助函数

添加 `buildManualOutline` 函数，将 `manualChapters` 转换为 `GeneratedOutline` 格式。

### 步骤3：更新"确认大纲"按钮

将按钮的 `onClick` 从 `onConfirm` 改为 `handleConfirmOutline`。

## 涉及文件

1. `src/renderer/components/Creative/WritingMode/OutlineEditor.tsx` — 主要修复文件
2. `src/shared/types/writing.types.ts` — 确认类型定义（无需修改）
3. `src/shared/constants/writing.constants.ts` — 确认常量（无需修改）

## 验证要点

1. 在AI模式编辑章节 → 点击"保存" → 点击"确认大纲" → 刷新页面 → 大纲内容应保持
2. 在手动模式编辑章节 → 点击"确认大纲" → 刷新页面 → 大纲内容应保持
3. 确认大纲后进入内容创作页面，章节列表应与编辑后的大纲一致
4. 项目重新打开后，大纲状态应正确恢复
