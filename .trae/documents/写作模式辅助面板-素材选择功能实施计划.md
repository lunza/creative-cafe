# 写作模式辅助面板 - 素材选择功能实施计划

## 一、需求概述

实现写作模式下的辅助面板（右侧面板）的素材选择功能。当前 `WritingModeRightPanel.tsx` 中的素材库Tab仅能展示当前项目中已选中的素材，无法从系统全部素材中进行选择。本次改造需要：

1. **素材覆盖范围**：世界书、角色卡、用户人设、知识库条目
2. **交互方式**：支持分类浏览、搜索过滤、点击选中/取消
3. **实时更新**：素材选中后立即同步到项目配置并持久化
4. **界面要求**：直观的Tab分类、搜索框、已选标记

## 二、当前问题分析

### 2.1 现有 `WritingModeRightPanel.tsx` 的问题
- 仅展示项目中已选中的素材（通过 `currentProject.config.resources` 过滤）
- 搜索框无实际搜索功能（纯UI占位）
- 素材列表只读展示，无法进行添加/移除操作
- 缺少知识库（Knowledge Base）素材类型

### 2.2 数据加载链路
- 世界书: `window.electronAPI.worldBook.list()` → 返回 `{path, name, ...}` 数组
- 角色卡: `window.electronAPI.character.list()` → 返回 `{path, name, characterName, ...}` 数组
- 用户人设: `window.electronAPI.avatar.list()` → 返回 `{path, name, description, ...}` 数组
- 知识库: `window.electronAPI.knowledge.list()` → 返回 `{success, items}` 结构

### 2.3 项目配置存储链路
- 项目配置: `useWritingProjectStore` 管理
- 素材配置: `project.config.resources` → `{worldBookIds[], characterCardIds[], userPersonaIds[]}`
- 持久化: `writingProjectStore.saveProject()` → `window.electronAPI.writing.saveProject()`

## 三、实施方案

### 3.1 架构设计

```
WritingModeRightPanel
├── MaterialBrowser（新建 - 素材浏览器主组件）
│   ├── MaterialCategoryTabs（分类Tab: 世界书/角色卡/用户人设/知识库）
│   ├── MaterialSearchBar（搜索组件）
│   ├── MaterialList（素材列表 - 按分类渲染）
│   │   ├── WorldBookMaterialList
│   │   ├── CharacterMaterialList
│   │   ├── PersonaMaterialList
│   │   └── KnowledgeMaterialList
│   └── MaterialCard（单个素材卡片 - 显示名称+选中状态+描述）
└── SelectedMaterialsPanel（已选素材汇总面板）
```

### 3.2 状态管理

在 `writingModeUIStore.ts` 中新增：

```typescript
interface WritingModeUIState {
```

### 3.3 详细实施步骤

#### 步骤1: 新建素材数据加载 Hook

**文件**: `src/renderer/components/Creative/WritingMode/useWritingMaterials.ts`（新建）

功能：
- `loadAllMaterials()`: 并行加载世界书、角色卡、用户人设、知识库
- `searchMaterials(query)`: 根据搜索词过滤所有分类素材
- 返回 `{materials, loading, searchResults}`

数据格式统一：
```typescript
interface MaterialItem {
  id: string;
  name: string;
  type: 'worldbook' | 'character' | 'persona' | 'knowledge';
  description?: string;
  path: string;
  isSelected: boolean;
  metadata?: Record<string, any>;
}
```

#### 步骤2: 新建素材列表渲染组件

**文件**: `src/renderer/components/Creative/WritingMode/MaterialList.tsx`（新建）

功能：
- 接收当前分类的素材列表 + 选中状态
- 每项显示：图标 + 名称 + 描述（如有）+ 选中复选框
- 点击切换选中状态
- 已选素材显示高亮边框和对勾图标
- 支持键盘导航

#### 步骤3: 改造 WritingModeRightPanel

**文件**: `src/renderer/components/Creative/WritingMode/WritingModeRightPanel.tsx`

主要改动：
1. **素材库Tab重构**：
   - 搜索框实现真实搜索功能，过滤所有分类素材
   - 分类Tab：世界书、角色卡、用户人设、知识库
   - 每个分类展示全部可用素材（非仅已选）
   - 点击素材卡片切换选中/取消状态

2. **已选状态同步**：
   - 选中素材时更新 `useWritingProjectStore` 的当前项目配置
   - 调用 `updateProject` 更新 `config.resources`
   - 触发自动保存

3. **新增"已选素材"面板**：
   - 在素材库Tab底部或独立Tab显示已选素材汇总
   - 已选素材可快速取消
   - 显示各分类已选数量标签

4. **实时刷新**：
   - 组件挂载时加载全部素材
   - 添加刷新按钮手动触发重新加载
   - 监听项目切换事件重新加载选中状态

#### 步骤4: 更新 writingModeStore

**文件**: `src/renderer/stores/writingModeStore.ts`

新增方法：
- `toggleMaterialSelection(type, id)`: 切换素材选中状态
- `getSelectedMaterials()`: 获取当前项目已选素材列表

#### 步骤5: 知识库素材集成

知识库条目作为新增素材类型，需要：
- 通过 `window.electronAPI.knowledge.list()` 加载
- 在素材面板中增加"知识库"分类Tab
- 支持搜索知识库条目内容
- 选中后写入 `config.resources.knowledgeItemIds`（需扩展类型定义）

## 五、实施顺序

1. **类型扩展**: 更新 `writing.types.ts` 添加 `knowledgeItemIds`
2. **数据Hook**: 创建 `useWritingMaterials.ts` 实现素材加载与搜索
3. **列表组件**: 创建 `MaterialList.tsx` 实现素材卡片渲染
4. **面板改造**: 重构 `WritingModeRightPanel.tsx` 整合以上组件
5. **状态同步**: 确保选中状态与项目配置双向同步

## 六、注意事项

1. 性能考虑：素材数量可能较多，需使用虚拟列表或分页
2. 搜索性能：前端搜索需防抖处理（300ms）
3. 数据一致性：切换项目时需重置选中状态显示
4. 错误处理：加载素材失败时显示友好提示
5. 实时性：如果其他模块修改了素材（如删除世界书），面板需能感知
