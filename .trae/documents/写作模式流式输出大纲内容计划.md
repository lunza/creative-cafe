# 写作模式流式输出大纲内容计划

## 一、问题背景

当前"生成大纲"功能在 AI 返回时没有实时显示流式内容，用户只能等待完成后才看到结果。需要在配置面板中添加一个文本框，实时显示 AI 正在生成的大纲内容。

## 二、实施步骤

### 步骤 1: 在主进程 OutlineGenerator 中添加流式回调

**文件**: `src/main/services/writing/OutlineGenerator.ts`

在 `OutlineGenerator` 类中添加：
- `streamChunkCallback: ((chunk: string) => void) | null` 私有字段
- `onStreamChunk(callback: (chunk: string) => void)` 方法用于注册回调
- 在 `readStreamResponse()` 中每解析到一个 chunk 时调用回调

### 步骤 2: 在 IPC handler 中转发流式数据到渲染进程

**文件**: `src/main/ipc/handlers/writingHandlers.ts`

在 `writing:generateOutline` handler 中：
- 调用 `outlineGenerator.onStreamChunk()` 注册回调
- 回调中通过 `event.sender.send('writing:stream:chunk', { requestId, chunk })` 发送数据到渲染进程
- 完成后通过 `event.sender.send('writing:stream:complete', { requestId, outline })` 通知完成
- 出错时通过 `event.sender.send('writing:stream:error', ...)` 通知错误

注意：IPC 事件通道名需与 `preload.ts` 中已定义的 `writing:stream:chunk`、`writing:stream:complete`、`writing:stream:error` 保持一致。

### 步骤 3: 在前端配置面板中添加流式文本框

**文件**: `src/renderer/components/Creative/WritingMode/WritingConfigPanel.tsx`

修改内容：
1. 添加 `streamContent` state 和 `useRef` 用于文本框引用
2. 添加 `useEffect` 自动滚动文本框到底部
3. 在 `handleGenerateOutline` 中设置流式监听器（使用 `window.electronAPI.writing.onStreamChunk` 等）
4. 在 JSX 中的表单下方（按钮上方）添加一个只读的 `TextArea` 组件显示 `streamContent`，仅在 `loading` 且 `streamContent` 非空时显示

### 步骤 4: 验证

1. 运行 `npm run build` 确认编译通过
2. 检查 TypeScript 诊断信息

## 三、预期输出

- 点击"生成大纲"后，下方出现文本框实时显示 AI 生成的内容
- 文本框自动滚动到最新内容
- 生成完成后文本框保持显示最终内容
- 不影响现有功能
