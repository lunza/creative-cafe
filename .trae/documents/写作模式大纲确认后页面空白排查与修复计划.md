# 写作模式大纲确认后页面空白排查与修复计划

## 问题描述
用户报告：系统日志显示 `"[OutlineGenerator] JSON parsed successfully"`，但大纲解析成功后后续功能未按预期执行。当前系统既未展示任何页面，也未生成可供用户进行章节创作的解析后大纲。

## 根因分析
经过代码审查，发现以下问题：

1. **枚举缺失**：`WritingModeView` 枚举中缺少 `CONTENT_GENERATION` 值，导致 `OutlineEditor` 的 `onConfirm` 回调设置的视图值在 `WritingModeEntry` 的 switch 语句中无对应分支
2. **渲染逻辑缺失**：`WritingModeEntry.renderView()` 的 switch 语句没有 `CONTENT_GENERATION` case，返回空内容
3. **流程断裂**：大纲生成成功后的项目创建和视图切换流程不完整，`handleOutlineConfirm` 仅更新了 store 状态但未创建正式项目
4. **缺少调整参数入口**：`OutlineEditor` 中没有"调整参数"按钮，不符合 PRD 要求

## 修复方案

### 修改文件清单

| 文件 | 修改内容 |
|------|---------|
| `writing.types.ts` | 新增 `WritingModeView.CONTENT_GENERATION = 'content_generation'` 枚举值 |
| `writingModeStore.ts` | 新增 `outlineRaw` 状态和 `setOutlineRaw` 方法 |
| `WritingConfigPanel.tsx` | 修改大纲生成成功后的逻辑：仅保存 outline 到 store，不立即创建 project |
| `WritingModeEntry.tsx` | 1. 添加 CONTENT_GENERATION 视图渲染分支<br>2. 重写 handleOutlineConfirm 创建项目并切换视图<br>3. 更新 handleBack 处理 CONTENT_GENERATION 视图 |
| `OutlineEditor.tsx` | 添加"调整参数"按钮 |

### 修复后的完整流程

```
配置页面 (CONFIG)
    ↓ 点击"生成大纲"
大纲编辑页面 (OUTLINE_EDITING) ← [新增：调整参数按钮可返回配置页面]
    ↓ 点击"确认大纲"
    ↓ 1. 创建 WritingProject
    ↓ 2. 保存 outline 和 outlineRaw
    ↓ 3. 更新项目状态为 IN_PROGRESS
内容生成页面 (CONTENT_GENERATION) ← [新增：渲染 ContentWorkspace]
    ↓ 用户可进行章节创作
```

### 关键代码变更

#### 1. WritingModeView 枚举
```typescript
export enum WritingModeView {
  // ... existing
  CONTENT_GENERATION = 'content_generation'  // 新增
}
```

#### 2. WritingModeEntry.handleOutlineConfirm
```typescript
const handleOutlineConfirm = async () => {
  if (!config || !outline) return;
  
  const projectId = await useWritingProjectStore.getState().createProject(config);
  if (projectId) {
    useWritingProjectStore.getState().setCurrentProject(projectId);
    await useWritingProjectStore.getState().updateProject(projectId, {
      outline,
      outlineRaw: useWritingModeStore.getState().outlineRaw || null,
      status: ProjectStatus.IN_PROGRESS
    });
  }
  setCurrentView(WritingModeView.CONTENT_GENERATION);
};
```

#### 3. WritingModeEntry.renderView switch 分支
```typescript
case WritingModeView.CONTENT_GENERATING:
case WritingModeView.CONTENT_GENERATION:  // 新增
case WritingModeView.CONTENT_EDITING:
  return (
    <ContentWorkspace
      outline={outline}
      projectId={currentProjectId || 'current'}
      onBack={handleBack}
    />
  );
```

#### 4. WritingConfigPanel 大纲生成成功后的逻辑
```typescript
if (result.success && result.outline) {
  useWritingModeStore.getState().setOutline(result.outline);
  useWritingModeStore.getState().setConfig(config);
  if (result.outlineRaw) {
    useWritingModeStore.getState().setOutlineRaw(result.outlineRaw);
  }
  onConfirm(config);
}
```

#### 5. OutlineEditor 调整参数按钮
```typescript
<Button icon={<EditOutlined />} onClick={onBack}>调整参数</Button>
```

## 验收标准

- [x] 大纲生成成功后能正确显示 OutlineEditor 页面
- [x] 点击"确认大纲"后能切换到 ContentWorkspace 页面
- [x] 项目状态正确更新为 IN_PROGRESS
- [x] outlineRaw 内容正确保存到项目
- [x] "调整参数"按钮能返回配置页面
- [x] 构建通过，无 TypeScript 错误

## 备注

此问题源于前一个会话中实现流式输出和内容保留功能时，视图枚举和渲染逻辑未同步更新。建议在后续开发中，新增视图类型时务必同时更新：
1. 枚举定义
2. store 状态管理
3. 入口组件的 switch 渲染分支
4. 视图间的导航逻辑（handleBack）
