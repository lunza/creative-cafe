## 技术细节参考

### 标签格式规范
```
<!--  <tableEdit>
insertRow(1, {"3":"今天","4":"中央公园"})
updateRow(2, 1, {"4":"朱迪"})
deleteRow(1, 3)
</tableEdit> -->
```

### 解析正则表达式
```typescript
const tableEditRegex = /<!--\s*<tableEdit>([\s\S]*?)<\/tableEdit>\s*-->/gi;
```

### 提示词约束要点
- 标签必须完整，使用 `<!--  <tableEdit>` 开头，`</tableEdit> -->` 结尾
- 标签内只包含tableEdit命令，不要包含其他内容
- 若无新信息，仅输出对话，不输出标签
- 严格遵循增量更新原则

## 风险评估

### 高风险
- AI可能不严格按照标签格式输出 → 需要增强正则表达式的容错能力

### 中风险
- 大量表格命令可能导致AI回复过长 → 可能需要限制命令数量

### 低风险
- 标签解析失败影响对话显示 → 已有try-catch保护，对话内容仍可正常显示
