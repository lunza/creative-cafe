### L1 简单题

#### 题目 C-07-L1-1：城市环境质量综合评估摘要

**复杂场景特征标注**：F2（多约束条件）+ F4（多步推理）

##### 题目内容

**系统指令**：
你是一位城市环境数据分析师。请阅读以下《2025年滨海市环境质量监测年报》的节选内容，完成以下任务：

1. 提取并列出滨海市在空气质量、水质、噪声三个方面的年度关键指标数据
2. 基于数据判断：滨海市在哪个方面表现最好，哪个方面问题最突出
3. 将上述内容整合为一份 200 字以内的综合评估摘要
4. 摘要必须包含：三个方面的具体数据、优劣判断、一个改进建议

**输入信息**：

```
《2025年滨海市环境质量监测年报》（节选）

一、空气质量
2025年全年，滨海市空气质量优良天数为310天，优良率为84.9%。PM2.5年均浓度为32微克/立方米，同比下降5.9%。PM10年均浓度为58微克/立方米。二氧化硫年均浓度为9微克/立方米。全年重污染天数为4天，较去年减少2天。

二、水环境质量
全市主要河流水质监测断面中，I-III类水质断面占比为72.3%，同比上升3.5个百分点。城市集中式饮用水水源地水质达标率保持100%。近岸海域水质优良面积比例为68.5%。主要超标因子为总磷和化学需氧量。

三、声环境质量
区域环境噪声昼间平均等效声级为55.2分贝，夜间为46.8分贝，均达到国家2类标准。交通干线两侧噪声昼间平均值为68.5分贝，夜间为60.3分贝，夜间超标率约为12.5%。功能区噪声昼间达标率为91.3%，夜间达标率为82.6%。

四、年度变化趋势
与2024年相比，三项指标中空气质量改善最为显著（优良率提升2.1个百分点），水环境质量稳中向好，噪声问题改善幅度最小（夜间达标率仅提升0.8个百分点）。
```

##### 标准答案

**推理过程**：

1. **提取关键指标**：
   - 空气质量：优良天数310天，优良率84.9%，PM2.5年均32μg/m³，重污染天4天
   - 水质：I-III类断面占比72.3%，饮用水达标率100%，近岸海域优良面积68.5%
   - 噪声：昼间区域噪声55.2分贝，夜间46.8分贝，交通干线夜间超标率12.5%，夜间功能区达标率82.6%

2. **优劣判断**：
   - 表现最好方面：空气质量（优良率84.9%，且同比改善显著，重污染天减少，PM2.5下降）
   - 问题最突出方面：噪声（夜间功能区达标率仅82.6%，交通干线夜间超标率12.5%，且改善幅度最小）

3. **综合摘要**：

**期望输出**：
```
【滨海市2025年环境质量综合评估摘要】

空气质量：优良天数310天（优良率84.9%），PM2.5年均32μg/m³，同比改善显著，为三方面中表现最佳。
水环境质量：I-III类水质断面占比72.3%，饮用水达标率100%，水质稳中向好。
声环境质量：区域噪声达标，但交通干线夜间超标率达12.5%，夜间功能区达标率仅82.6%，为最突出问题。

改进建议：优先加强交通噪声治理，特别是夜间时段的路面管控与隔音设施建设。
```

##### 关键信息点

1. 空气质量优良率 84.9%（或优良天数310天）——必含
2. PM2.5 年均浓度 32μg/m³——必含
3. I-III类水质断面占比 72.3%——必含
4. 饮用水源地水质达标率 100%——重要
5. 交通干线夜间超标率 12.5%——必含
6. 夜间功能区达标率 82.6%——必含
7. 判断空气质量表现最好——必含
8. 判断噪声问题最突出——必含
9. 改进建议聚焦噪声治理——重要
10. 总字数不超过200字——约束条件

##### 维度差异化评分细则

| 等级 | 分数范围 | 评分标准 |
|------|---------|---------|
| S | 90-100 | 全部关键信息点完整无遗漏；优劣判断准确且基于数据支撑；改进建议合理具体；摘要逻辑清晰、语言精炼；字数控制在200字以内 |
| A | 80-89 | 关键信息点缺1项次要信息；优劣判断正确但论证不够充分；改进建议合理但较笼统；字数符合要求 |
| B | 70-79 | 关键信息点缺2项；优劣判断方向正确但缺乏数据支撑；改进建议不具体；格式基本符合要求 |
| C | 60-69 | 信息点遗漏较多（3项以上）；优劣判断有误或缺乏依据；改进建议不相关；字数严重超标或不足 |
| D | 50-59 | 仅提取了部分数据，无综合判断或改进建议；核心信息严重遗漏 |
| E | <50 | 回答与题目无关；提取的信息完全错误；无法解析 |

#### 题目 C-07-L1-2：智能家居产品对比导购

**复杂场景特征标注**：F2（多约束条件）+ F5（多源信息综合）

##### 题目内容

**系统指令**：
阅读以下三款智能音箱的产品信息，完成以下任务：

1. 从"音质表现"、"智能功能"、"性价比"三个维度，分别列出每款产品的关键信息
2. 综合三个维度的信息，推荐最适合以下用户场景的产品：**一位独居老人，主要使用场景是听新闻、语音拨打电话、设置提醒**
3. 推荐理由需涵盖三个维度，并说明为何其他两款不适合该用户
4. 输出格式：先给推荐结论（一句话），再给分析（200字以内）

**输入信息**：

```
产品A：智能音箱 Alpha
- 价格：599元
- 音质：2英寸全频扬声器，15W输出，支持DTS音效
- 智能功能：支持语音助手，可控制500+品牌智能家居设备，支持多轮对话，具备声纹识别
- 特色功能：支持蓝牙5.2、Wi-Fi 6、可组建立体声对
- 用户评价：音质优秀，适合音乐爱好者；功能丰富但设置复杂；老年人反映语音识别对方言支持不佳
- 尺寸：150×80×80mm

产品B：智能音箱 Beta（长者版）
- 价格：399元
- 音质：3英寸全频扬声器，10W输出
- 智能功能：支持语音助手，大字版界面，一键呼叫联系人，语音拨号，用药提醒，支持多种方言
- 特色功能：配备物理按键（音量、静音、呼叫），紧急联系人一键拨通，支持FM收音机
- 用户评价：音质一般但够用；操作简单适合老人；子女可通过APP远程协助设置
- 尺寸：120×120×100mm

产品C：智能音箱 Gamma
- 价格：899元
- 音质：2个高音单元+1个低音单元，40W输出，支持杜比全景声
- 智能功能：支持语音助手，集成智能家居中枢，支持触屏（7英寸），可视频通话
- 特色功能：配备7英寸屏幕，支持视频播放、可视门铃联动、安防监控
- 用户评价：音质极佳，屏幕实用；价格较高；功能太多对不熟悉科技产品的用户有学习成本
- 尺寸：200×100×100mm
```

##### 标准答案

**推理过程**：

1. **三维度信息提取**：

   | 维度 | 产品A（Alpha） | 产品B（Beta长者版） | 产品C（Gamma） |
   |------|---------------|-------------------|---------------|
   | 音质表现 | 15W输出，DTS音效，音质优秀 | 10W输出，音质一般但够用 | 40W输出，杜比全景声，音质极佳 |
   | 智能功能 | 功能丰富，声纹识别，控制500+设备，但设置复杂，方言支持不佳 | 大字版界面，一键呼叫，语音拨号，用药提醒，方言支持，紧急联系人 | 触屏，视频通话，可视门铃联动，功能丰富但学习成本高 |
   | 性价比 | 599元，功能多但目标用户不匹配 | 399元，功能精准匹配需求 | 899元，价格最高，功能过剩 |

2. **用户需求匹配分析**：
   - 用户特征：独居老人
   - 核心需求：听新闻、语音拨打电话、设置提醒
   - 关键考量：操作简单、方言支持、紧急联系功能、价格适中

3. **推荐结论**：产品B最适合。

**期望输出**：
```
推荐结论：产品B（智能音箱 Beta 长者版）是最适合该独居老人的选择。

分析：
1. 音质方面：虽然Beta的10W输出和音质不如A和C，但老人主要听新闻而非音乐，够用即可。
2. 智能功能方面：Beta专为长者设计——大字版界面、方言支持、一键呼叫、用药提醒和紧急联系人功能精准匹配用户需求。A的方言支持不佳，C的功能虽多但学习成本高，均不适合老人。
3. 性价比方面：399元价格最低，且功能完全覆盖用户需求，无需为用不到的功能付费。

产品A设置复杂且方言支持差，产品C价格高且功能过剩，均不推荐。
```

##### 关键信息点

1. 三款产品的价格分别为599/399/899元——重要
2. 产品B有方言支持、一键呼叫、用药提醒等适老化功能——必含
3. 产品A方言支持不佳、设置复杂——必含
4. 产品C价格高、功能过剩、学习成本高——必含
5. 推荐结论为产品B——必含
6. 推荐理由需涵盖三个维度（音质/智能功能/性价比）——必含
7. 说明其他两款不适合的原因——重要
8. 输出格式：先结论再分析——格式约束

##### 维度差异化评分细则

| 等级 | 分数范围 | 评分标准 |
|------|---------|---------|
| S | 90-100 | 三维度信息提取完整准确；推荐结论正确；分析全面覆盖三个维度及排除理由；逻辑清晰、语言精炼；格式完全符合要求 |
| A | 80-89 | 推荐结论正确；三维度均有分析但某个维度分析不够深入；排除理由基本合理；格式基本符合 |

| D | 50-59 | 仅列出产品信息未做综合判断；或推荐结论与分析之间缺乏逻辑关联 |
| E | <50 | 回答与题目无关；信息提取完全错误；无法解析 |

### L2 中等题

#### 题目 C-07-L2-1：新能源汽车市场趋势分析

**复杂场景特征标注**：F4（多步推理）+ F5（多源信息综合）+ F6（角色/立场多视角）

##### 题目内容

**系统指令**：
你是一位市场研究分析师。请阅读以下两份来自不同机构关于2025年新能源汽车市场的分析报告摘要，完成以下任务：

1. 分别概括两份报告的核心观点和关键数据
2. 对比分析两份报告在以下三个方面的共识与分歧：市场增长率、技术路线走向、消费者购买驱动因素
3. 基于两者的共识和分歧，撰写一份综合研判报告（300字以内），需包含：共识要点、分歧分析、你的综合判断

**输入信息**：

```
【报告一：东方咨询《2025年中国新能源汽车市场展望》】
- 预计2025年新能源汽车销量达1200万辆，同比增长25%，渗透率突破45%
- 认为插电混动（PHEV）将保持30%以上的市场份额，是过渡期的重要技术路线
- 消费者购买驱动因素排序：使用成本（42%）> 政策补贴（28%）> 智能化体验（20%）> 品牌（10%）
- 特别指出：下沉市场（三四线城市及农村）将成为新增量的主要来源，占比预计达45%
- 担忧：充电基础设施在三四线城市的覆盖不足可能制约增长
- 方法说明：基于2000份消费者问卷+50家车企调研

【报告二：经纬研究《2025年新能源汽车产业趋势报告》】
- 预计2025年新能源汽车销量达1100万辆，同比增长18%，渗透率约42%
- 认为纯电动（BEV）将占据绝对主导地位，市场份额超过75%，PHEV将逐步退坡至20%以下
- 消费者购买驱动因素排序：智能化体验（45%）> 使用成本（30%）> 品牌信任（15%）> 政策补贴（10%）
- 特别指出：一二线城市仍是主力市场，占比约60%，但增速放缓
- 担忧：电池原材料价格波动和产能过剩风险
- 方法说明：基于行业专家访谈（30位）+ 对50家经销商的门店数据统计
```

##### 标准答案

**推理过程**：

1. **各自核心观点**：
   - 东方咨询：乐观预期（1200万辆，+25%），PHEV重要，消费重成本驱动，下沉市场是增量主力
   - 经纬研究：谨慎预期（1100万辆，+18%），BEV主导，消费重智能化体验，一二线仍是主力

2. **共识与分歧**：

   | 方面 | 共识 | 分歧 |
   |------|------|------|
   | 市场增长率 | 均认为增长但增速放缓 | 东方25% vs 经纬18%；东方1200万 vs 经纬1100万 |
   | 技术路线 | 均认为新能源是主流方向 | 东方支持PHEV占30%+；经纬认为BEV占75%+，PHEV退坡 |
   | 消费驱动因素 | 使用成本和智能化体验均重要 | 东方认为成本第一（42%）；经纬认为智能化第一（45%） |

3. **综合研判**：

**期望输出**：
```
【新能源汽车市场综合研判报告】

共识要点：双方一致认为2025年新能源汽车市场将继续增长，渗透率将突破40%。使用成本和智能化体验是消费者最关注的两大因素。充电/电池相关基础设施是行业共同关注的风险点。

分歧分析：在市场增速上，东方咨询（25%）比经纬研究（18%）更乐观，差异源于双方调研对象的差异——东方侧重消费者问卷，经纬侧重行业专家和经销商。技术路线方面，分歧最大：PHEV占比的预测相差15个百分点以上，这反映了对政策走向和消费者偏好的不同判断。消费驱动因素方面，东方认为成本优先，经纬认为智能化优先，这与双方调研样本的地域分布有关（东方覆盖下沉市场，经纬聚焦一二线）。

综合判断：综合来看，2025年新能源汽车市场大概率在中性偏乐观区间（增长18%-22%）。技术路线方面，PHEV在三四线市场仍有较大空间，但一二线城市BEV主导地位不可撼动。建议关注不同层级市场的差异化需求，在产品和营销策略上因地制宜。
```

##### 关键信息点

1. 东方咨询核心观点：1200万辆，+25%，渗透率45%，PHEV占30%+，成本驱动，下沉市场——必含
2. 经纬研究核心观点：1100万辆，+18%，渗透率42%，BEV占75%+，智能化驱动，一二线为主——必含
3. 增长率方面的共识与分歧——必含
4. 技术路线方面的共识与分歧——必含
5. 消费驱动因素方面的共识与分歧——必含
6. 综合判断需体现对分歧原因的分析（调研方法差异）——重要
7. 综合判断需给出倾向性结论——重要
8. 字数控制在300字以内——约束条件

- 减重目标：建议每月减重2-4kg，6个月内减重5-10%
- 适用人群：超重/肥胖人群，代谢综合征患者
- 注意事项：低碳水饮食初期可能有乏力、头晕等适应期反应
- 数据来源：大规模人群队列研究（n=100,000+）

【资料二：《国际运动医学杂志》— 高强度间歇训练（HIIT）对中年人群的影响（2024）】
- 核心建议：高蛋白饮食（蛋白质供能比25-30%），配合低碳水（碳水供能比35-40%）
- 运动建议：每周3次HIIT（每次20分钟），效果优于150分钟中等强度有氧
- 研究发现：HIIT组12周后内脏脂肪减少15%，而中等强度有氧组仅减少8%
- 适用人群：健康成年人，需排除心血管疾病风险
- 注意事项：HIIT对膝关节有较高冲击，肥胖人群需谨慎

【资料三：《预防医学前沿》— 中年人群健康管理的综合干预研究（2025）】

#### 题目 C-08-L3-2：含隐含违规陷阱的数据清洗与格式化输出

**复杂场景特征标注**：F2（多约束条件）+ F3（信息冲突/缺失）+ F4（多步推理）+ F8（反事实/假设推理）

##### 题目内容

**系统指令**：
你是一位数据审核员。请处理以下一批用户提交的"一周运动打卡"数据，按规则进行验证、清洗和格式化输出。

**处理规则**：

规则1：数据有效性验证
- 日期格式必须为 YYYY-MM-DD
- 运动时长必须在 10-180 分钟之间（含边界）
- 步数必须在 0-100000 之间（含边界）
- 心率必须在 40-200 bpm 之间（含边界）
- 任意字段不满足以上条件，该条记录标记为"无效"并标注原因

规则2：运动类型分类
- 如果 `type` 为 "run" 或 "walk" → 有氧运动
- 如果 `type` 为 "swim" 或 "cycle" → 综合运动
- 如果 `type` 为 "yoga" 或 "strength" → 无氧/柔韧运动
- 其他 type → 标记为"未知类型"

规则3：输出格式
- 分两个表格输出："有效记录"和"无效记录"
- 有效记录表格列：日期、运动类型、运动分类、时长（分钟）、步数、心率
- 无效记录表格列：日期、运动类型、原因
- 有效记录按日期升序排列
- 无效记录按日期降序排列

规则4：自检报告
- 在表格后输出自检报告，包含：数据总数、有效数、无效数、发现的问题类型总结
- 额外要求：如果存在"隐含违规"情况（数据格式看似正确但存在逻辑矛盾），需在自检报告中特别指出
