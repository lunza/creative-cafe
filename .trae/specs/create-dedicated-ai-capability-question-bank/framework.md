# 综合能力测评题库 — 框架概述

> **版本声明**：本文档定义的是**独立于基础题库**（`docs/ai-scenarios/测评题库.md`）的综合能力测评题库框架。基础题库聚焦于项目特定场景（角色扮演、标签提取、小说生成等），本题库聚焦于 AI 的**通用综合能力**评估，不依赖任何项目特定素材，可独立使用。

---

## 1. 维度概述总览

题库涵盖 **8 大通用综合能力维度**（编码 C-01 至 C-08），与基础题库的 8 个场景维度（D-01 至 D-08）无重叠，形成互补对照关系。

| 维度 | 名称 | 能力评估重点 | 与基础题库的区别 |
|------|------|-------------|----------------|
| C-01 | 深层文本理解与语义分析 | 复杂文本理解、隐含信息提取、多视角分析、情感/意图识别 | 基础题库侧重角色对话与小说生成，C-01 侧重文本理解而非生成 |
| C-02 | 逻辑推理与批判性思维 | 多步演绎推理、归纳推理、谬误识别、反事实推理、证据链分析 | 基础题库侧重剧情矛盾检测，C-02 侧重通用逻辑推理与批判性思维 |
| C-03 | 多步问题求解与规划 | 任务分解、资源约束规划、条件分支、优先级排序、计划调整 | 基础题库无此维度，全新维度 |
| C-04 | 创意生成与叙事构建 | 原创故事创作、角色塑造、世界观构建、情节编排、风格模仿 | 基础题库侧重小说生成（大纲遵循），C-04 侧重无约束的原创创意 |
| C-05 | 代码编写与程序理解 | 代码生成、Bug 修复、算法设计、代码理解、多语言编程 | 全新维度 |
| C-06 | 数学推理与定量分析 | 应用题建模、概率/统计推理、数据分析、优化问题、图表解读 | 全新维度 |
| C-07 | 知识整合与多源信息融合 | 跨文档信息综合、冲突信息调和、证据整合、跨领域知识迁移 | 基础题库侧重表格操作指令，C-07 侧重非结构化知识整合 |
| C-08 | 复杂指令遵循与输出控制 | 多约束指令遵循、嵌套条件执行、格式严格遵循、自检与纠错 | 基础题库侧重项目特定格式，C-08 侧重通用复杂指令 |

### 关键设计原则

1. **完全独立**：所有题目不依赖项目特定素材（角色卡、世界书、项目功能等），确保题库可脱离项目独立使用
2. **通用场景**：题目题材为通用场景，涵盖生活、科技、学术、商业、文化等广泛领域
3. **难度递进**：每个维度内按场景复杂度和推理深度分为三级，难度递进可量化
4. **特征标注**：每道题明确标注覆盖的复杂场景特征及数量，便于评估维度覆盖度

## 2. 难度分级标准

按**场景复杂度和推理深度**将题目分为三级，难度区分基于可量化指标：

| 难度 | 编码 | 标准 | 推理步数 | 约束条件 | 信息完整性 |
|------|------|------|---------|---------|-----------|
| 简单 | L1 | 单一场景，直接约束，单步推理，信息完整无歧义，无需外部知识 | 1 步 | ≤2 个 | 完整无歧义 |
| 中等 | L2 | 多条件组合，需 2-3 步推理，信息部分隐含或需整合，存在有限选择 | 2-3 步 | 3-4 个 | 部分隐含，需整合 |
| 困难 | L3 | 多场景嵌套，需 4+ 步推理，信息冲突/缺失/冗余，需多角度分析和判断 | 4+ 步 | 5+ 个 | 冲突/缺失/冗余 |

### 难度区分示例说明

| 维度 | L1 简单 | L2 中等 | L3 困难 |
|------|---------|---------|---------|
| C-01 文本理解 | 单篇短文，直接提取事实信息 | 多篇文本对比，提取隐含观点 | 长文本的多视角深层分析，消歧与意图识别 |
| C-02 逻辑推理 | 单步演绎推理，前提明确 | 多步推理链，条件组合 | 证据链分析，反事实推理，谬误识别 |
| C-03 问题求解 | 单任务规划，步骤直给 | 资源约束规划，条件分支 | 多资源多约束复杂规划，冲突取舍 |
| C-04 创意生成 | 命题创意写作，单一风格约束 | 多角色叙事，世界观构建要求 | 复杂叙事结构，伏笔与反转，类型融合 |
| C-05 代码编写 | 单函数实现，常见场景 | 多模块协作，错误处理 | 算法设计/优化，Bug 修复与边界条件 |
| C-06 数学推理 | 真实场景应用题，单步计算 | 多步数学建模，概率/统计推理 | 优化问题，数据分析解读，跨知识综合 |
| C-07 知识整合 | 单一来源信息提取，直接综合 | 多来源对比综合，异同识别 | 冲突信息调和，证据链构建，跨领域推断 |
| C-08 指令遵循 | 单一格式约束，单一输出要求 | 多约束并存，格式+内容+长度限制 | 嵌套条件指令，自检纠错要求，隐含违规陷阱 |

## 3. 复杂场景特征定义清单

所有题目必须结合 **8 种复杂场景特征** 进行设计，每道题在题目内容中明确标注所覆盖的特征及数量。

### 特征清单

| 编号 | 特征名称 | 定义 | 设计要求 |
|------|---------|------|---------|
| F1 | 多轮上下文依赖 | 题目理解依赖前序上下文，非孤立问题，需结合多轮交互信息 | 上下文信息必须是解题的必要条件，不可仅在题目中复述 |
| F2 | 多约束条件 | 同一题目包含 3+ 个并行约束条件，需同时满足 | 约束条件之间可能存在冲突或权衡关系 |
| F3 | 信息冲突/缺失 | 故意设置矛盾信息或信息缺口，需通过推理判断或合理假设填补 | 冲突信息应具有合理的迷惑性，不能过于明显 |
| F4 | 多步推理 | 需要至少 2 步以上推理链才能得出结论，中间结论为最终结论的前提 | 推理链应具有明确的逻辑递进关系 |
| F5 | 多源信息综合 | 需要从多个来源（不同段落、不同角度、不同场景）整合信息 | 信息源之间应有潜在关联，非简单拼接 |
| F6 | 角色/立场多视角 | 需要从不同角色或立场理解问题，识别不同视角的差异 | 多视角应导致结论或理解上的实质性差异 |
| F7 | 歧义消解 | 题目中存在合理歧义（一词多义、指代不明等），需通过上下文消解 | 歧义应具有合理性和迷惑性，非刻意制造 |
| F8 | 反事实/假设推理 | 需要基于假设条件（与事实相反的情况）进行推理 | 假设条件应逻辑自洽，反事实推演应有合理依据 |

### 最低特征数量要求

| 难度 | 最低特征数量 | 特征分布建议 |
|------|------------|-------------|
| L1 简单 | ≥2 个特征 | 以 F2（多约束条件）+ F4（多步推理）为主，搭配其他 1 个 |
| L2 中等 | ≥3 个特征 | 必须包含 F4（多步推理），再加 2 个其他特征 |
| L3 困难 | ≥4 个特征 | 必须包含 F3（信息冲突/缺失）+ F4（多步推理）+ F5（多源信息综合），再加 1-2 个其他特征 |

## 4. 通用评分标准体系

采用百分制六级评分体系，每个维度需基于此通用框架制定差异化的评分细则。

### 评分等级定义

| 等级 | 分数范围 | 通用标准 | 扣分典型场景 |
|------|---------|---------|-------------|
| **S** | 90-100 | 完全符合标准答案要求，推理完整准确，输出格式完美，无任何错误，超出预期 | 极少数情况下的小瑕疵 |
| **A** | 80-89 | 基本符合要求，推理正确，少量细节偏差或格式瑕疵，核心意图正确 | 遗漏 1 个次要信息点 / 格式不完美 |
| **B** | 70-79 | 部分符合要求，推理方向正确但有明显漏洞或遗漏，格式基本规范 | 遗漏关键信息点 / 推理链有 1 处断裂 |
| **C** | 60-69 | 勉强符合，推理有较多错误或缺漏，但部分内容相关 | 多处信息遗漏 / 推理方向有偏差 |
| **D** | 50-59 | 大部分不符合要求，但部分内容或思路相关 | 核心推理错误 / 输出格式严重不符 |
| **E** | <50 | 完全不相关、严重错误或无法解析 | 回答与题目无关 / 生成了有害内容 |

### 各维度评分权重框架

每个维度的评分细则需在通用框架基础上，按以下权重维度差异化制定：

| 评分维度 | 说明 | 通用权重 |
|---------|------|---------|
| 推理正确性 | 答案的推理过程是否正确、完整 | 40% |
| 信息完整性 | 是否覆盖了所有关键信息点 | 25% |
| 输出合规性 | 输出格式、约束条件是否严格遵守 | 20% |
| 表达清晰度 | 答案表述是否清晰、有条理、逻辑自洽 | 15% |

> 各维度可根据能力评估重点调整上述权重。例如 C-01 文本理解可提高"信息完整性"权重至 35%，C-08 指令遵循可提高"输出合规性"权重至 35%。

### 每道题的标准结构

每道题需包含以下完整内容：

```
## 题目 {N}（{场景特征标注}）

### 题目内容
{复杂场景提示词 + 完整上下文信息}

### 标准答案
{完整推理过程 + 最终输出 + 格式示例}

### 关键信息点
{必须包含的核心信息点清单}

### 评分标准
{维度差异化的六级评分细则}
```

### 使用说明

1. **评估方式**：建议逐维度测试，每个维度 6 题连续测试，取平均分作为该维度得分
2. **时间限制**：L1 每题建议 5-10 分钟，L2 每题建议 10-15 分钟，L3 每题建议 15-25 分钟
3. **评分流程**：先根据标准答案核对关键信息点，再参考评分细则确定等级，最后给出具体分数
4. **对比使用**：可与基础题库配合使用，评估模型在"项目特定能力"与"通用综合能力"上的表现差异
