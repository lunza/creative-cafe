- 必须使用正则表达式解析日志行
- 函数需有完整的类型注解
- 对于无法解析的日志行，应跳过而非报错
- 返回的字典格式为：{

**标准答案**：

```python
import re
from typing import List, Dict, Union


def parse_logs(log_lines: List[str]) -> Dict[str, Union[Dict[str, int], List[Dict[str, str]], float]]:
    """
    解析日志行，返回结构化统计信息。
    
    Args:
        log_lines: 日志行列表
        
    Returns:
        包含级别统计、失败详情、服务统计和金额总和的字典
    """
    # 日志行正则表达式
    # 格式: [时间] [级别] [服务名] 内容
    log_pattern = re.compile(
        r'\[(\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})\]\s+\[(INFO|WARN|ERROR)\]\s+\[(\w+)\]\s+(.+)'
    )
    # 金额提取正则
    amount_pattern = re.compile(r'￥(\d+\.?\d*)')
    # 失败原因提取正则（从 WARN/ERROR 日志中提取"原因:"后面的内容）
    reason_pattern = re.compile(r'原因:\s*(.+?)(?:，|$)')
    
    level_count: Dict[str, int] = {"INFO": 0, "WARN": 0, "ERROR": 0}
    failures: List[Dict[str, str]] = []
    service_count: Dict[str, int] = {}
    total_amount: float = 0.0
    
    for line in log_lines:
        line = line.strip()
        if not line:
            continue
        
        match = log_pattern.match(line)
        if not match:
            continue  # 跳过无法解析的行
        
        time_str, level, service, content = match.groups()
        
        # 统计级别
        level_count[level] = level_count.get(level, 0) + 1
        
        # 统计服务
        service_count[service] = service_count.get(service, 0) + 1
        
        # 提取金额
        amount_matches = amount_pattern.findall(content)
        for amount_str in amount_matches:
            total_amount += float(amount_str)
        
        # 收集失败信息
        if level in ("WARN", "ERROR"):
            reason_match = reason_pattern.search(content)
            reason = reason_match.group(1) if reason_match else content
            failures.append({
                "time": time_str,
                "level": level,
                "service": service,
                "reason": reason
            })
    
    # 保留两位小数
    total_amount = round(total_amount, 2)
    
    return {
        "level_count": level_count,
        "failures": failures,
        "service_count": service_count,
        "total_amount": total_amount
    }
```

- 总分计算方式：各科成绩之和
```

**标准答案**：

```python
from typing import List, Dict, Union


def generate_ranking(students: List[Dict[str, Union[str, Dict[str, int]]]]) -> Dict[str, Union[List[Dict], Dict[str, Dict], List[str]]]:
    """
    根据学生成绩生成排行榜和相关统计信息。
    
    Args:
        students: 学生成绩列表，每个元素包含姓名和各科成绩
        
    Returns:
        包含排行榜、各科最高分和平均分以上学生名单的字典
    """
    # 计算每个学生的总分和各科成绩
    student_totals = []
    subjects = set()
    
    for student in students:
        name = student["name"]
        scores = student["scores"]
        total = sum(scores.values())
        subjects.update(scores.keys())
        student_totals.append({
            "name": name,
            "total": total,
            "scores": scores
        })
    
    # 排序：先按总分降序，再按语文降序，再按数学降序
    student_totals.sort(key=lambda x: (-x["total"], -x["scores"].get("语文", 0), -x["scores"].get("数学", 0)))
    
    # 生成排行榜（含并列排名）
    ranking = []
    prev_total = None
    prev_rank = 0
    actual_rank = 0
    
    for i, stu in enumerate(student_totals):
        actual_rank += 1
        if stu["total"] != prev_total:
            current_rank = actual_rank
            prev_total = stu["total"]
        else:
            current_rank = prev_rank  # 与前一名并列
        
        ranking.append({
            "rank": current_rank,
            "name": stu["name"],
            "total": stu["total"],
            "details": stu["scores"]
        })
        prev_rank = current_rank
    
    # 计算各科最高分
    subject_top = {}
    for subject in sorted(subjects):
        top_student = max(students, key=lambda s: s["scores"].get(subject, 0))
        subject_top[subject] = {
            "name": top_student["name"],
            "score": top_student["scores"][subject]
        }
    
    # 平均分超过85分的学生名单
    above_average = []
    for stu in student_totals:
        avg = stu["total"] / len(stu["scores"])
        if avg > 85:
            above_average.append(stu["name"])
    
    return {
        "ranking": ranking,
        "subject_top": subject_top,
        "above_average": above_average
    }
```

#### 题目 C-05-L2-1：多模块协作——CSV 数据合并与统计报告

**复杂场景特征标注**：F2（多约束条件）+ F4（多步推理）+ F5（多源信息综合）

**题目内容**：

```

【任务要求】
请实现以下函数：

1. `merge_order_data(order_file: str, payment_file: str, refund_file: str) -> list[dict]`
   读取三个 CSV 文件，按照 order_id 进行关联合并。
   合并规则：
   - 以 order_service.csv 为主表
   - 关联 payment_service.csv 中的 payment_method、payment_status（即 status 字段重命名）、paid_at
   - 关联 refund_service.csv 中的 refund_amount、reason、refunded_at
   - 如果某订单没有支付记录或退款记录，对应字段填 None

2. `generate_report(merged_data: list[dict]) -> dict`

   - 支付成功总额、支付失败总额
   - 各支付方式的使用次数和总金额
   - 需要退款的订单列表（支付失败或已取消的订单）

3. `write_report(report: dict, output_file: str) -> None`
   将报告写入 JSON 文件，格式美观（缩进2空格）。

要求：
- 使用 Python 3.10+ 语法，完整类型注解
- 使用 csv 模块（标准库），不得使用 pandas
- 异常处理：文件不存在时抛出 FileNotFoundError，CSV 格式错误时跳过该行并记录到错误日志
- 函数之间通过参数传递数据，不使用全局变量
- 主函数（main）调用流程：读取 → 合并 → 生成报告 → 写入文件
```

**标准答案**：

```python
import csv
import json
from typing import List, Dict, Optional, Any
from pathlib import Path


def read_csv(file_path: str) -> List[Dict[str, str]]:
    """
    读取 CSV 文件，返回字典列表。
    
    Args:
        file_path: CSV 文件路径
        
    Returns:
        字典列表，每个字典代表一行
        
    Raises:
        FileNotFoundError: 文件不存在时
    """
    path = Path(file_path)
    if not path.exists():
        raise FileNotFoundError(f"文件不存在: {file_path}")
    
    rows = []
    with open(file_path, mode="r", encoding="utf-8") as f:
        reader = csv.DictReader(f)
        for row_num, row in enumerate(reader, start=2):
            if any(v is None for v in row.values()):
                # 跳过有空字段的行
                print(f"警告: {file_path} 第 {row_num} 行有空字段，已跳过")
                continue
            rows.append(row)
    return rows


def merge_order_data(
    order_file: str,
    payment_file: str,
    refund_file: str
) -> List[Dict[str, Any]]:
    """
    读取并合并三个 CSV 文件的数据。
    
    Args:
        order_file: 订单文件路径
        payment_file: 支付文件路径
        refund_file: 退款文件路径
        
    Returns:
        合并后的订单数据列表
    """
    orders = read_csv(order_file)
    payments = read_csv(payment_file)
    refunds = read_csv(refund_file)
    
    # 构建支付和退款的查找索引
    payment_index: Dict[str, Dict[str, str]] = {}
    for pay in payments:
        payment_index[pay["order_id"]] = pay
    
    refund_index: Dict[str, Dict[str, str]] = {}
    for ref in refunds:
        refund_index[ref["order_id"]] = ref
    
    # 合并数据
    merged: List[Dict[str, Any]] = []
    for order in orders:
        order_id = order["order_id"]
        pay = payment_index.get(order_id)
        ref = refund_index.get(order_id)
        
        record = {
            "order_id": order_id,
            "user_id": order["user_id"],
            "amount": float(order["amount"]),
            "order_status": order["status"],
            "created_at": order["created_at"],
            # 支付信息
            "payment_method": pay["payment_method"] if pay else None,
            "payment_status": pay["status"] if pay else None,
            "paid_at": pay["paid_at"] if pay else None,
            # 退款信息
            "refund_amount": float(ref["refund_amount"]) if ref else None,
            "refund_reason": ref["reason"] if ref else None,
            "refunded_at": ref["refunded_at"] if ref else None,
        }
        merged.append(record)
    
    return merged


def generate_report(merged_data: List[Dict[str, Any]]) -> Dict[str, Any]:
    """
    基于合并后的数据生成统计报告。
    
    Args:
        merged_data: 合并后的订单数据
        
    Returns:
        统计报告字典
    """
    total_orders = len(merged_data)
    paid_orders = sum(1 for o in merged_data if o["order_status"] == "paid")
    cancelled_orders = sum(1 for o in merged_data if o["order_status"] == "cancelled")
    
    # 支付统计
    payment_success_total = 0.0
    payment_failed_total = 0.0
    payment_method_stats: Dict[str, Dict[str, float]] = {}
    
    for order in merged_data:
        if order["payment_status"] == "success":
            payment_success_total += order["amount"]
        elif order["payment_status"] in ("failed", "refunded"):
            payment_failed_total += order["amount"]
        
        method = order["payment_method"]
        if method:
            if method not in payment_method_stats:
                payment_method_stats[method] = {"count": 0, "total_amount": 0.0}
            payment_method_stats[method]["count"] += 1
            payment_method_stats[method]["total_amount"] += order["amount"]
    
    # 需要退款的订单列表
    refund_needed = [
        {
            "order_id": o["order_id"],
            "amount": o["amount"],
            "reason": o["refund_reason"] or (
                "支付失败" if o["payment_status"] == "failed" else "订单取消"
            )
        }
        for o in merged_data
        if o["order_status"] == "cancelled" or o["payment_status"] == "failed"
    ]
    
    return {
        "order_summary": {
            "total_orders": total_orders,
            "paid_orders": paid_orders,
            "cancelled_orders": cancelled_orders
        },
        "payment_summary": {
            "success_total": round(payment_success_total, 2),
            "failed_total": round(payment_failed_total, 2)
        },
        "payment_method_breakdown": {
            method: {"count": stats["count"], "total": round(stats["total_amount"], 2)}
            for method, stats in payment_method_stats.items()
        },
        "refund_needed_orders": refund_needed
    }


def write_report(report: Dict[str, Any], output_file: str) -> None:
    """
    将报告写入 JSON 文件。
    
    Args:
        report: 报告字典
        output_file: 输出文件路径
    """
    with open(output_file, mode="w", encoding="utf-8") as f:
        json.dump(report, f, ensure_ascii=False, indent=2)


def main(order_file: str, payment_file: str, refund_file: str, output_file: str) -> None:
    """主函数：读取 → 合并 → 生成报告 → 写入文件"""
    merged = merge_order_data(order_file, payment_file, refund_file)
    report = generate_report(merged)
    write_report(report, output_file)
    print(f"报告已生成: {output_file}")

#### 题目 C-05-L2-2：网络请求重试机制实现

**复杂场景特征标注**：F2（多约束条件）+ F3（信息缺失）+ F4（多步推理）

**题目内容**：

```
【系统提示】
你是一位 Python 后端开发者。请实现一个健壮的 HTTP 请求函数，包含重试机制、超时处理和指数退避策略。

【输入信息】
你的团队正在开发一个与第三方 API 交互的服务。该第三方 API 不稳定，经常出现以下问题：
- 偶尔返回 500/502/503 服务端错误
- 偶尔超时（超过 5 秒无响应）
- 偶尔返回 429 限流错误（附有 Retry-After 头部）

你需要实现一个请求函数，在遇到这些错误时自动重试。

【任务要求】
请实现函数 resilient_request(url: str, max_retries: int = 3, timeout: int = 5) -> dict

函数行为要求：
1. 使用 Python 标准库 urllib.request 发送 HTTP GET 请求（不使用第三方库）
2. 超时设置：连接超时和读取超时均为 timeout 参数指定的秒数
3. 重试策略：
   - 遇到 500/502/503 错误时，重试最多 max_retries 次
   - 遇到 429 限流错误时，如果响应头中有 Retry-After 字段，等待该字段指定的秒数后再重试；如果没有该字段，默认等待 10 秒
   - 遇到超时异常（urllib.error.URLError），重试最多 max_retries 次
   - 遇到 4xx 错误（除 429 外），不重试，直接返回错误
   - 遇到 2xx 成功响应，直接返回结果
4. 退避策略：
   - 每次重试间隔使用指数退避：base_delay = 1 秒，每次重试延迟 = base_delay * 2^retry_count
   - 429 错误优先使用 Retry-After 字段，如果没有则使用指数退避
5. 返回格式：
   - 成功时：{"success": True, "status": int, "data": str, "attempts": int}
   - 最终失败时：{"success": False, "error": str, "attempts": int}
6. 必须在函数内部记录每次重试的日志（使用 print 输出），格式："[RETRY] 第 {n} 次重试，状态码: {code}，等待 {delay} 秒"

要求函数签名完整，有类型注解，包含详细的文档字符串。
```

**标准答案**：

```python
import urllib.request
import urllib.error
import time
from typing import Dict, Union


def resilient_request(
    url: str,
    max_retries: int = 3,
    timeout: int = 5
) -> Dict[str, Union[bool, int, str]]:
    """
    发送 HTTP GET 请求，包含自动重试、超时处理和指数退避策略。
    
    重试策略：
    - 5xx 错误：重试（服务端错误）
    - 429 限流：根据 Retry-After 头部等待后重试
    - 超时异常：重试
    - 其他 4xx 错误：不重试，直接返回
    
    Args:
        url: 请求的 URL
        max_retries: 最大重试次数（默认 3）
        timeout: 超时时间，单位秒（默认 5）
        
    Returns:
        成功时: {"success": True, "status": int, "data": str, "attempts": int}
        失败时: {"success": False, "error": str, "attempts": int}
    """
    base_delay = 1.0  # 指数退避基础延迟（秒）
    
    for attempt in range(1, max_retries + 2):  # +2 是因为第一次不算重试，还需要一次最终尝试
        if attempt > 1:
            print(f"[RETRY] 第 {attempt - 1} 次重试...")
        
        try:
            req = urllib.request.Request(url, method="GET")
            with urllib.request.urlopen(req, timeout=timeout) as response:
                status = response.status
                data = response.read().decode("utf-8")
                
                if 200 <= status < 300:
                    return {
                        "success": True,
                        "status": status,
                        "data": data,
                        "attempts": attempt
                    }
                
                elif status == 429:
                    # 限流：检查 Retry-After 头部
                    retry_after = response.headers.get("Retry-After")
                    if retry_after and retry_after.isdigit():
                        delay = int(retry_after)
                    else:
                        delay = 10  # 默认等待 10 秒
                    
                    if attempt <= max_retries:
                        print(f"[RETRY] 第 {attempt} 次重试，状态码: 429，等待 {delay} 秒")
                        time.sleep(delay)
                    else:
                        return {
                            "success": False,
                            "error": f"达到最大重试次数，最后状态码: 429",
                            "attempts": attempt
                        }
                
                elif 500 <= status < 600:
                    if attempt <= max_retries:
                        delay = base_delay * (2 ** (attempt - 1))
                        print(f"[RETRY] 第 {attempt} 次重试，状态码: {status}，等待 {delay} 秒")
                        time.sleep(delay)
                    else:
                        return {
                            "success": False,
                            "error": f"达到最大重试次数，最后状态码: {status}",
                            "attempts": attempt
                        }
                
                else:
                    # 其他 4xx 错误，不重试
                    return {
                        "success": False,
                        "error": f"客户端错误，状态码: {status}，不进行重试",
                        "attempts": attempt
                    }
        
        except urllib.error.HTTPError as e:
            status = e.code
            if status == 429:
                retry_after = e.headers.get("Retry-After")
                if retry_after and retry_after.isdigit():
                    delay = int(retry_after)
                else:
                    delay = 10
                
                if attempt <= max_retries:
                    print(f"[RETRY] 第 {attempt} 次重试，状态码: 429，等待 {delay} 秒")
                    time.sleep(delay)
                else:
                    return {
                        "success": False,
                        "error": f"达到最大重试次数，最后状态码: 429",
                        "attempts": attempt
                    }
            elif 500 <= status < 600:
                if attempt <= max_retries:
                    delay = base_delay * (2 ** (attempt - 1))
                    print(f"[RETRY] 第 {attempt} 次重试，状态码: {status}，等待 {delay} 秒")
                    time.sleep(delay)
                else:
                    return {
                        "success": False,
                        "error": f"达到最大重试次数，最后状态码: {status}",
                        "attempts": attempt
                    }
            else:
                return {
                    "success": False,
                    "error": f"HTTP 错误，状态码: {status}",
                    "attempts": attempt
                }
        
        except urllib.error.URLError as e:
            # 超时或网络错误
            if attempt <= max_retries:
                delay = base_delay * (2 ** (attempt - 1))
                print(f"[RETRY] 第 {attempt} 次重试，错误: {e.reason}，等待 {delay} 秒")
                time.sleep(delay)
            else:
                return {
                    "success": False,
                    "error": f"达到最大重试次数，最后错误: {e.reason}",
                    "attempts": attempt
                }
        
        except Exception as e:
            return {
                "success": False,
                "error": f"未知错误: {str(e)}",
                "attempts": attempt
            }
    
    # 不应到达这里
    return {
        "success": False,
        "error": "未知错误",
        "attempts": max_retries + 1
    }
```

**关键信息点**：

1. 使用 urllib.request 标准库，不使用第三方库
2. 正确区分不同 HTTP 状态码的重试策略
3. 429 错误正确处理 Retry-After 头部
4. 指数退避计算正确：base_delay * 2^retry_count
5. 其他 4xx 错误不重试，直接返回
6. 超时异常（URLError）正确处理

import threading
from collections import deque

class TaskScheduler:

    def add_task(self, func, delay=0, interval=0):
        """添加一个任务。

            delay: 延迟执行时间（秒），默认0表示立即执行
            interval: 重复执行间隔（秒），默认0表示只执行一次

        while self.running:

                    task['executed'] = True
                    
                    if task['interval'] > 0:
                        task['run_at'] = now + task['interval']
                        self.tasks.append(task)
                else:
                    self.tasks.appendleft(task)
                    time.sleep(0.1)
            else:
                time.sleep(0.1)
    
    def pending_tasks(self):
        """返回待执行任务数量。"""
        return len(self.tasks)

**标准答案**：

```python
import time
import threading
import uuid
import traceback
from typing import Callable, Optional, Dict, Any
from collections import OrderedDict


class TaskScheduler:
    """改进版任务调度器，支持定时执行和周期性任务。
    
    修复的 Bug 列表：
    1. 使用 deque.popleft() 导致优先级混乱——新任务插入到队尾，但延迟任务可能早于队首任务
    2. 使用 deque 无法高效查找和移除特定任务
    3. time.sleep(0.1) 导致 CPU 空转和响应延迟
    4. 没有处理任务执行中的异常，一个任务崩溃会导致整个调度器退出
    5. 没有使用锁保护共享数据，多线程环境下存在竞态条件
    6. stop() 只设置标志位，不中断等待，线程可能延迟退出
    7. 周期性任务重新插入队尾后，可能被延迟执行
    """
    
    def __init__(self):
        self._tasks: Dict[str, Dict[str, Any]] = {}  # task_id -> task_info
        self._ready_queue: list = []  # 按执行时间排序的待执行任务列表
        self._lock = threading.Lock()
        self._event = threading.Event()  # 替代 time.sleep 实现高效等待
        self._running = False
        self._thread: Optional[threading.Thread] = None
        self._next_id = 0
    
    def _generate_id(self) -> str:
        """生成唯一任务 ID。"""
        tid = f"task_{self._next_id}"
        self._next_id += 1
        return tid
    
    def add_task(
        self,
        func: Callable,
        delay: float = 0,
        interval: float = 0
    ) -> str:
        """添加一个任务。
        
        Args:
            func: 要执行的函数
            delay: 延迟执行时间（秒），默认0表示立即执行
            interval: 重复执行间隔（秒），默认0表示只执行一次
            
        Returns:
            任务 ID，可用于后续操作
        """
        task_id = self._generate_id()
        task = {
            'id': task_id,
            'func': func,
            'run_at': time.time() + delay,
            'interval': interval,
            'status': 'pending',  # pending / running / completed / cancelled
            'error': None
        }
        
        with self._lock:
            self._tasks[task_id] = task
            self._ready_queue.append(task)
            # 按执行时间排序（插入排序方式）
            self._ready_queue.sort(key=lambda t: t['run_at'])
        
        # 唤醒调度线程，检查是否有新任务需要立即执行
        self._event.set()
        
        return task_id
    
    def remove_task(self, task_id: str) -> bool:
        """移除尚未执行的任务。
        
        Args:
            task_id: 任务 ID
            
        Returns:
            是否成功移除（True=已移除，False=任务不存在或已执行）
        """
        with self._lock:
            task = self._tasks.get(task_id)
            if task is None:
                return False
            if task['status'] != 'pending':
                return False
            task['status'] = 'cancelled'
            # 从就绪队列中移除
            self._ready_queue = [t for t in self._ready_queue if t['id'] != task_id]
        return True
    
    def get_task_info(self, task_id: str) -> Optional[Dict[str, Any]]:
        """查询任务的状态。
        
        Args:
            task_id: 任务 ID
            
        Returns:
            任务信息字典，包含状态、执行时间等；任务不存在返回 None
        """
        with self._lock:
            task = self._tasks.get(task_id)
            if task is None:
                return None
            return {
                'id': task['id'],
                'status': task['status'],
                'run_at': task['run_at'],
                'interval': task['interval'],
                'error': task.get('error')
            }
    
    def start(self) -> None:
        """启动调度器。"""
        self._running = True
        self._thread = threading.Thread(target=self._run, daemon=True)
        self._thread.start()
    
    def stop(self) -> None:
        """停止调度器。"""
        self._running = False
        self._event.set()  # 中断等待，让线程立即退出
        if self._thread and self._thread.is_alive():
            self._thread.join(timeout=5)
    
    def _run(self) -> None:
        """调度器主循环（在独立线程中运行）。"""
        while self._running:
            now = time.time()
            tasks_to_run = []
            
            with self._lock:
                # 找出所有到期的任务
                while self._ready_queue and self._ready_queue[0]['run_at'] <= now:
                    task = self._ready_queue.pop(0)
                    if task['status'] == 'pending':
                        task['status'] = 'running'
                        tasks_to_run.append(task)
            
            # 执行到期的任务（在锁外执行，避免阻塞调度）
            for task in tasks_to_run:
                self._execute_task(task)
            
            # 计算下一次唤醒时间
            with self._lock:
                if self._ready_queue:
                    wait_time = self._ready_queue[0]['run_at'] - time.time()
                    wait_time = max(0, wait_time)
                else:
                    wait_time = None  # 无限等待
            
            # 使用 Event.wait 高效等待
            if wait_time is not None:
                self._event.wait(timeout=wait_time)
            else:
                self._event.wait(timeout=1.0)  # 无任务时每秒检查一次
            self._event.clear()
    
    def _execute_task(self, task: Dict[str, Any]) -> None:
        """执行单个任务，捕获异常并处理周期性任务。"""
        try:
            task['func']()
            task['status'] = 'completed'
        except Exception as e:
            task['status'] = 'completed'  # 标记为已完成（即使出错）
            task['error'] = {
                'type': type(e).__name__,
                'message': str(e),
                'traceback': traceback.format_exc()
            }
            print(f"[TaskScheduler] 任务 {task['id']} 执行出错: {e}")
        
        # 处理周期性任务
        if task['interval'] > 0:
            task['run_at'] = time.time() + task['interval']
            task['status'] = 'pending'
            with self._lock:
                self._ready_queue.append(task)
                self._ready_queue.sort(key=lambda t: t['run_at'])
            self._event.set()  # 唤醒调度线程处理新安排的周期任务
    
    def pending_tasks(self) -> int:
        """返回待执行任务数量。"""
        with self._lock:
            return sum(1 for t in self._tasks.values() if t['status'] == 'pending')
    
    @property
    def is_running(self) -> bool:
        return self._running

```python
from typing import List, Dict, Any, Optional
import math


def normalize_scores(scores: List[float]) -> List[float]:
    """Min-Max 归一化到 [0, 1] 区间。"""
    if not scores:
        return []
    min_s = min(scores)
    max_s = max(scores)
    if max_s == min_s:
        return [0.5] * len(scores)  # 所有值相同，返回中间值
    return [(s - min_s) / (max_s - min_s) for s in scores]


def compute_content_match(
    video: Dict[str, Any],
    user_profile: Dict[str, Any]
) -> float:
    """
    计算内容匹配度。
    
    歧义消解说明：内容匹配度中"分类匹配"和"标签匹配"的权重分配。
    选择方案：分类匹配权重 0.6，标签匹配权重 0.4。
    理由：分类是用户偏好的宏观体现，标签是微观体现，宏观应占更高权重。
    """
    # 分类匹配
    category = video["category"]
    category_score = user_profile["preferred_categories"].get(category, 0.0)
    
    # 标签匹配
    video_tags = set(video["tags"])
    user_tags = set(user_profile["preferred_tags"])
    matched_tags = video_tags & user_tags
    
    if not video_tags:
        tag_match_score = 0.0
    else:
        # 标签覆盖率：匹配标签数 / 视频标签总数
        tag_coverage = len(matched_tags) / len(video_tags)
        # 用户偏好覆盖：匹配标签数 / 用户偏好标签数
        user_coverage = len(matched_tags) / len(user_tags) if user_tags else 0
        tag_match_score = 0.5 * tag_coverage + 0.5 * user_coverage
    
    # 综合内容匹配度
    content_score = 0.6 * category_score + 0.4 * tag_match_score
    return content_score


def compute_popularity(
    video: Dict[str, Any],
    all_scores_cache: Dict[str, List[float]]
) -> float:
    """
    计算流行度。
    
    歧义消解说明："点赞率"使用 likes/views（而非 likes/(views×系数)）。
    理由：点赞率是行业标准指标，无需额外系数。views=0 时返回 0。
    """
    views = video["views"]
    likes = video["likes"]
    comments = video["comments"]
    
    # 点赞率
    like_rate = likes / views if views > 0 else 0
    # 评论率
    comment_rate = comments / views if views > 0 else 0
    
    # 缓存归一化所需数据
    all_scores_cache.setdefault("like_rates", []).append(like_rate)
    all_scores_cache.setdefault("comment_rates", []).append(comment_rate)
    all_scores_cache.setdefault("views_list", []).append(views)
    
    # 暂存原始值，后续统一归一化
    # 这里返回一个占位，实际在排名时统一计算
    return like_rate * 0.5 + comment_rate * 0.3 + (views / 1_000_000) * 0.2


def compute_engagement(
    video: Dict[str, Any],
    user_profile: Dict[str, Any],
    watched_videos: Dict[str, float]  # video_id -> watch_ratio
) -> float:
    """
    计算用户契合度。
    
    歧义消解说明："avg_watch_ratio 接近程度"使用 1 - |v_ratio - u_ratio|（绝对差值）。
    理由：绝对差值直接反映数值上的接近程度，语义直观。相对差值在比率接近 0 时会被放大。
    """
    # 观看完成率匹配度
    v_ratio = video["avg_watch_ratio"]
    u_ratio = user_profile["avg_watch_ratio"]
    watch_ratio_similarity = 1 - abs(v_ratio - u_ratio)
    
    # 分类偏好
    category = video["category"]
    category_pref = user_profile["preferred_categories"].get(category, 0.0)
    
    # 观看历史惩罚
    video_id = video["id"]
    watch_penalty = 0.0
    if video_id in watched_videos:
        watch_ratio = watched_videos[video_id]
        if watch_ratio > 0.9:
            watch_penalty = 0.15  # 减半惩罚
        else:
            watch_penalty = 0.3
    
    # 综合用户契合度
    engagement_score = 0.4 * watch_ratio_similarity + 0.6 * category_pref - watch_penalty
    return max(0, engagement_score)  # 确保非负


def compute_diversity_bonus(
    video: Dict[str, Any],
    current_selection: List[Dict[str, Any]],
    max_category_ratio: float = 0.4
) -> float:
    """
    计算多样性奖励分。
    
    当推荐列表前 N 个中某个分类占比超过阈值时，新加入该分类的视频获得负奖励（惩罚）。
    """
    if not current_selection:
        return 0.0  # 第一个视频无需多样性惩罚
    
    category = video["category"]
    total = len(current_selection) + 1
    category_count = sum(1 for v in current_selection if v["category"] == category) + 1
    category_ratio = category_count / total
    
    if category_ratio > max_category_ratio:
        # 超过阈值，给予惩罚
        return -0.1 * (category_ratio - max_category_ratio) * 10
    return 0.0


def hybrid_recommend(
    videos: List[Dict[str, Any]],
    user_profile: Dict[str, Any],
    top_n: int = 10
) -> Dict[str, Any]:
    """
    混合推荐排序算法主函数。
    
    Args:
        videos: 候选视频列表
        user_profile: 用户画像
        top_n: 返回前 N 个推荐结果
        
    Returns:
        包含推荐列表和多样性统计的字典
    """
    # 构建用户已观看视频字典
    watch_history = user_profile.get("watch_history", [])
    # 注意：这里没有每个视频的观看完成率数据，用用户平均观看完成率估算
    watched_videos = {vid: user_profile["avg_watch_ratio"] for vid in watch_history}
    
    # 计算每个视频的原始得分
    scored_videos = []
    cache: Dict[str, List[float]] = {}
    
    for video in videos:
        content_match = compute_content_match(video, user_profile)
        popularity_raw = compute_popularity(video, cache)
        engagement_raw = compute_engagement(video, user_profile, watched_videos)
        
        scored_videos.append({
            "video": video,
            "content_match": content_match,
            "popularity_raw": popularity_raw,
            "engagement_raw": engagement_raw
        })
    
    # 对流行度各维度进行归一化
    like_rates_norm = normalize_scores(cache.get("like_rates", []))
    comment_rates_norm = normalize_scores(cache.get("comment_rates", []))
    views_norm = normalize_scores(cache.get("views_list", []))
    
    # 更新归一化后的流行度得分
    for i, sv in enumerate(scored_videos):
        sv["popularity"] = (
            0.5 * like_rates_norm[i] +
            0.3 * comment_rates_norm[i] +
            0.2 * views_norm[i]
        )
    
    # 内容匹配度归一化
    content_scores = [sv["content_match"] for sv in scored_videos]
    content_norm = normalize_scores(content_scores)
    for i, sv in enumerate(scored_videos):
        sv["content_match_norm"] = content_norm[i]
    
    # 用户契合度归一化
    engagement_scores = [sv["engagement_raw"] for sv in scored_videos]
    engagement_norm = normalize_scores(engagement_scores)
    for i, sv in enumerate(scored_videos):
        sv["engagement_norm"] = engagement_norm[i]
    
    # 多样性感知的贪心排序
    # 每次选择综合得分最高的视频，同时考虑多样性奖励
    selected = []
    remaining = scored_videos.copy()
    
    # 权重配置
    W_CONTENT = 0.40
    W_POPULARITY = 0.25
    W_ENGAGEMENT = 0.20
    W_DIVERSITY = 0.15
    
    while len(selected) < top_n and remaining:
        best_idx = -1
        best_score = -float("inf")
        
        for idx, sv in enumerate(remaining):
            base_score = (
                W_CONTENT * sv["content_match_norm"] +
                W_POPULARITY * sv["popularity"] +
                W_ENGAGEMENT * sv["engagement_norm"]
            )
            
            # 多样性奖励
            diversity_bonus = compute_diversity_bonus(sv["video"], [s["video"] for s in selected])
            
            total_score = base_score + W_DIVERSITY * diversity_bonus
            
            if total_score > best_score:
                best_score = total_score
                best_idx = idx
        
        if best_idx == -1:
            break
        
        best_sv = remaining.pop(best_idx)
        selected.append({
            "rank": len(selected) + 1,
            "video_id": best_sv["video"]["id"],
            "title": best_sv["video"]["title"],
            "category": best_sv["video"]["category"],
            "score": round(best_score, 4),
            "score_breakdown": {
                "content_match": round(best_sv["content_match_norm"], 4),
                "popularity": round(best_sv["popularity"], 4),
                "engagement": round(best_sv["engagement_norm"], 4),
                "diversity_bonus": round(diversity_bonus, 4) if idx == best_idx else 0
            }
        })
    
    # 多样性统计
    category_dist = {}
    for rec in selected:
        cat = rec["category"]
        category_dist[cat] = category_dist.get(cat, 0) + 1
    
    top_category = max(category_dist.values()) if category_dist else 0
    top_category_ratio = top_category / len(selected) if selected else 0
    
    return {
        "recommendations": selected[:top_n],
        "diversity_stats": {
            "category_distribution": category_dist,
            "top_category_ratio": round(top_category_ratio, 2)
        }
    }
```

**歧义消解说明**（需在推理过程中体现）：

### L2 中等题

#### 题目 C-06-L2-1：产品质量检测概率分析

**复杂场景特征标注**：F2（多约束条件）+ F4（多步推理）+ F5（多源信息综合）

**题目内容**：

```
【系统提示】
你是一位质量工程师。某工厂生产电子元件，有三条生产线（A、B、C）同时生产同一种产品。请根据以下质检数据进行分析。

【生产数据】
| 生产线 | 日产量 | 历史次品率 | 检测准确率 |
|--------|--------|-----------|-----------|
| A 线 | 5000 件 | 2.0% | 98% |
| B 线 | 3000 件 | 3.5% | 97% |
| C 线 | 2000 件 | 1.5% | 99% |

【检测流程说明】
每条生产线生产的产品会混入同一个成品仓。质检部门从成品仓中随机抽取一件产品进行检测。检测设备并非 100% 准确——它可能将合格品误判为次品（假阳性），也可能将次品误判为合格品（假阴性）。

检测准确率定义：检测设备正确识别合格品和次品的综合概率。即：
- 真阳性率（次品被正确检测为次品）= 检测准确率
- 真阴性率（合格品被正确检测为合格品）= 检测准确率
- 假阳性率（合格品被误判为次品）= 1 - 检测准确率
- 假阴性率（次品被误判为合格品）= 1 - 检测准确率

【任务要求】
请计算以下问题，精确到小数点后四位：

1. 从成品仓中随机抽取一件产品，它是次品的概率是多少？（即整体次品率）
2. 如果抽取一件产品进行检测，检测结果显示为"次品"，它实际是次品的概率是多少？（即检测阳性时的真实次品概率）
3. 如果检测结果显示为"合格品"，它实际是次品的概率是多少？（即检测阴性时的漏检概率）
4. 如果连续检测 3 件产品都显示为"次品"，这三件产品中至少有一件是真正次品的概率是多少？

要求：列出所有计算步骤，使用贝叶斯公式，保留完整推理过程。
```

**标准答案**：

**推理过程**：

**第一步：计算整体次品率（先验概率）**

各生产线日产量占比：
- A 线：5000 / (5000 + 3000 + 2000) = 5000 / 10000 = 0.5
- B 线：3000 / 10000 = 0.3
- C 线：2000 / 10000 = 0.2

各生产线次品率：
- A 线：2.0% = 0.02
- B 线：3.5% = 0.035
- C 线：1.5% = 0.015

整体次品率 P(次品) = 0.5 × 0.02 + 0.3 × 0.035 + 0.2 × 0.015
= 0.01 + 0.0105 + 0.003
= 0.0235

**整体次品率 = 2.35%**

**第二步：计算检测阳性时真实次品概率**

已知：
- P(次品) = 0.0235
- P(合格) = 1 - 0.0235 = 0.9765

检测准确率不是单一值，我们需要考虑每条生产线的检测准确率不同，但题目说"检测设备"是同一个，但给出了每条线的检测准确率。实际上，检测准确率与生产线无关，但题目给出了不同值，说明不同生产线使用了不同的检测设备或参数。

更准确的理解：每条生产线有自己的检测设备，准确率不同。

我们需要用全概率公式计算整体检测性能。

对于"检测为次品"这个事件，有三种方式：
1. 产品来自 A 线且是次品且被正确检测（真阳性）
2. 产品来自 B 线且是次品且被正确检测（真阳性）
3. 产品来自 C 线且是次品且被正确检测（真阳性）
4. 产品来自 A 线且是合格品但被误判（假阳性）
5. 产品来自 B 线且是合格品但被误判（假阳性）
6. 产品来自 C 线且是合格品但被误判（假阳性）

P(检测为次品) = Σ P(来自 i 线) × [P(次品|i) × 准确率_i + P(合格|i) × (1 - 准确率_i)]

A 线贡献：0.5 × [0.02 × 0.98 + 0.98 × 0.02] = 0.5 × [0.0196 + 0.0196] = 0.5 × 0.0392 = 0.0196
B 线贡献：0.3 × [0.035 × 0.97 + 0.965 × 0.03] = 0.3 × [0.03395 + 0.02895] = 0.3 × 0.0629 = 0.01887
C 线贡献：0.2 × [0.015 × 0.99 + 0.985 × 0.01] = 0.2 × [0.01485 + 0.00985] = 0.2 × 0.0247 = 0.00494

P(检测为次品) = 0.0196 + 0.01887 + 0.00494 = 0.04341

P(实际是次品 | 检测为次品) = P(真阳性) / P(检测为次品)

P(真阳性) = Σ P(来自 i 线) × P(次品|i) × 准确率_i
= 0.5 × 0.02 × 0.98 + 0.3 × 0.035 × 0.97 + 0.2 × 0.015 × 0.99
= 0.5 × 0.0196 + 0.3 × 0.03395 + 0.2 × 0.01485
= 0.0098 + 0.010185 + 0.00297
= 0.022955

P(实际是次品 | 检测为次品) = 0.022955 / 0.04341 = 0.5288

**检测为次品时，实际是次品的概率 ≈ 52.88%**

**第三步：计算检测阴性时的漏检概率**

P(检测为合格) = 1 - P(检测为次品) = 1 - 0.04341 = 0.95659

P(实际是次品 | 检测为合格) = P(假阴性) / P(检测为合格)

P(假阴性) = Σ P(来自 i 线) × P(次品|i) × (1 - 准确率_i)
= 0.5 × 0.02 × 0.02 + 0.3 × 0.035 × 0.03 + 0.2 × 0.015 × 0.01
= 0.5 × 0.0004 + 0.3 × 0.00105 + 0.2 × 0.00015
= 0.0002 + 0.000315 + 0.00003
= 0.000545

P(实际是次品 | 检测为合格) = 0.000545 / 0.95659 = 0.0005697

**检测为合格时，实际是次品的概率（漏检率）≈ 0.057%**

**第四步：连续 3 次检测为次品，至少有一件是真正次品的概率**

每次检测为次品时，该产品是真正次品的概率为 52.88%（即 p = 0.5288）

3 件产品中，至少有一件是真正次品的概率：
= 1 - (全部都不是真正次品的概率)
= 1 - (1 - 0.5288)³
= 1 - 0.4712³
= 1 - 0.1046
= 0.8954

**连续 3 件检测为次品时，至少有一件是真正次品的概率 ≈ 89.54%**

**关键信息点**：

1. 整体次品率计算正确（2.35%），使用全概率公式
2. 贝叶斯公式应用正确，区分了真阳性率和假阳性率
3. 检测为次品时真实次品概率计算正确（≈52.88%）
4. 检测为合格时漏检概率计算正确（≈0.057%）
5. 连续 3 次检测的联合概率计算正确（≈89.54%）
6. 各生产线产量占比计算正确
7. 保留四位小数精度
8. 推理步骤完整清晰

需要推算出 K12 和成人教育的基准比例。假设 2025 年在线教育营收为基准值。

2025 年市场规模 680 亿元，但题目中的财务预测是目标公司的营收，不是市场规模。

从财务预测看，2026 年营收 8.0 亿元，2027 年 8.8 亿元（增长 10%），2028 年 9.5 亿元（增长 8%），2029 年 10.0 亿元（增长 5.3%），2030 年 10.5 亿元（增长 5%）。

按分析师 B 的修正，假设目标公司当前营收中 K12 占 60%，成人教育占 40%（基于行业平均）：

- 2026 年：K12 收入 = 8.0 × 0.6 × 0.95 = 4.56 亿元；成人收入 = 8.0 × 0.4 × 1.25 = 4.0 亿元；合计 = 8.56 亿元（成人占比 46.7%）
- 2027 年：K12 收入 = 4.56 × 0.95 = 4.332 亿元；成人收入 = 4.0 × 1.25 = 5.0 亿元；合计 = 9.332 亿元（成人占比 53.6%）
- 2028 年：K12 收入 = 4.332 × 0.95 = 4.115 亿元；成人收入 = 5.0 × 1.25 = 6.25 亿元；合计 = 10.365 亿元（成人占比 60.3% ✓）
- 2029 年：K12 收入 = 4.115 × 0.95 = 3.909 亿元；成人收入 = 6.25 × 1.25 = 7.813 亿元；合计 = 11.722 亿元
- 2030 年：K12 收入 = 3.909 × 0.95 = 3.714 亿元；成人收入 = 7.813 × 1.25 = 9.766 亿元；合计 = 13.480 亿元

修正后退出估值：13.48 × 3 = 40.44 亿元 → 20% = 8.088 亿元
修正后 IRR：8.088/2.0^0.2 - 1 = 4.044^0.2 - 1 = 1.322 - 1 = **32.2%**

**新能源充电修正**（分析师 C：毛利率下降，但不直接影响营收，政策利好）

分析师 C 提到毛利率从 35% 降至 28%，预计 2026 年降至 22%。这影响的是利润而非营收。

政策文件要求 2028 年车桩比达到 1.5:1（当前 2.5:1），意味着充电桩数量需要翻一番 → 这对行业是重大利好，需求将大幅增长。

但毛利率下降意味着竞争加剧，营收增长可能不如预期乐观。

考虑到政策利好（需求增长）和竞争加剧（价格战）的抵消效应，保守估计营收增长下调 10%：
- 2026：5.0 × 1.55 = 7.75 亿元（下调 10% 增长预期）
- 2027：7.75 × 1.50 = 11.625 亿元
- 2028：11.625 × 1.50 = 17.438 亿元
- 2029：17.438 × 1.40 = 24.413 亿元
- 2030：24.413 × 1.35 = 32.958 亿元

修正后退出估值：32.958 × 3 = 98.874 亿元 → 20% = 19.775 亿元
修正后 IRR：19.775/2.0^0.2 - 1 = 9.888^0.2 - 1 = 1.578 - 1 = **57.8%**

**最终投资建议**：

**推荐选择：新能源充电行业**

理由：
1. **增长趋势最强**：当前增长率（65.3%）超过历史 CAGR（58.6%），增长加速度最高，且政策利好明确（车桩比目标推动需求翻番）。
2. **IRR 最高**：修正后 IRR 达 57.8%，远超其他两个项目。
3. **政策支撑明确**：国家发改委的规划要求直接推动行业增长，需求确定性高。
4. **风险提示**：主要风险在于毛利率下降和价格战，但营收增长空间足以覆盖利润率的压缩。

**备选方案**：智能家居（修正后 IRR 49.6%），用户基础健康，但增长放缓趋势明显。

**不推荐**：在线教育（修正后 IRR 32.2%），虽然分析师修正后 IRR 有所提升，但政策风险（双减余波）和 K12 萎缩趋势依然存在，长期不确定性最大。
