# Agent 网络搜索工具（Web Search Tool）Spec

## Why

当前 Agent 模式下的智能体（对话 / 写作 / 世界书编写）只能基于模型自身知识行动，无法获取实时信息或外部资料。以世界书编写智能体为例：当用户提示"为一部以中世纪欧洲为背景的奇幻小说创建世界书"时，智能体只能凭模型记忆编造设定，无法查阅真实的欧洲中世纪历史、纹章学、封建制度等资料，导致生成内容可能存在事实性错误或缺乏深度。

本 spec 为 Agent 工具系统新增**网络搜索能力**（`webSearch` + `fetchUrl` 两个工具），借鉴 openclaw `web_search` 工具的可插拔配置模式（`codex-native-web-search.ts`），让智能体在编写世界书时能够主动上网搜索相关资源，将搜索结果作为上下文喂给 LLM，提升生成内容的事实准确性与丰富度。工具注册到 `ToolRegistry` 后，所有支持工具调用的 Agent 模式（dialogue / writing / worldbook）均可受益，本 spec 同时显式集成世界书编写智能体的 PLANNING 与 AUTHORING 阶段。

## What Changes

### 新增模块

- **`src/main/services/agent/tools/builtin/webSearchTools.ts`** — 网络搜索工具组
  - `webSearch` 工具：调用搜索引擎查询关键词，返回结果列表（标题 + 摘要 + URL）
  - `fetchUrl` 工具：抓取指定 URL 的网页正文（HTML → 纯文本，截断到合理长度）
  - 工具描述符 + 执行器 + 服务接口 `IWebSearchToolServices`
- **`src/main/services/webSearchService.ts`** — 网络搜索服务（独立于 agent 模块，可被其他模块复用）
  - `WebSearchService` 类：provider 抽象 + 结果缓存 + 速率限制
  - 内置 provider：DuckDuckGo（默认，零配置）/ Tavily（API key，AI 优化）/ SearXNG（自托管 URL）/ Custom（自定义端点）
  - `HtmlTextExtractor`：HTML → 纯文本（剥离 script/style/nav，解码实体，截断）
- **`src/main/services/webSearchProviders/`** — 搜索 provider 实现
  - `duckDuckGoProvider.ts` — DuckDuckGo HTML 端点抓取（零配置）
  - `tavilyProvider.ts` — Tavily API（需 API key）
  - `searxngProvider.ts` — SearXNG 实例（需 URL）
  - `customProvider.ts` — 自定义 HTTP 端点（用户配置 URL + 请求模板）
  - `types.ts` — provider 接口 `WebSearchProvider` + 结果类型
- **`src/renderer/components/Settings/WebSearchSettings.tsx`** — 网络搜索配置面板（provider 选择 / API key / 测试连接）

## 设计理念（借鉴 openclaw）

### 1. 可插拔 Provider 模式（借鉴 openclaw `codex-native-web-search.shared.ts`）

openclaw 的 web search 配置支持 `mode: cached | live`、`allowedDomains`、`contextSize` 等归一化参数。本 spec 采用类似的 provider 抽象：

```typescript
interface WebSearchProvider {
  readonly name: string;
  readonly requiresApiKey: boolean;
  search(query: string, options: SearchOptions): Promise<SearchResult[]>;
}
```

用户在设置中选择 provider，`WebSearchService` 根据 config 动态加载对应 provider，实现零配置（DuckDuckGo）与高质量（Tavily）的灵活切换。

### 2. 声明式可用性 Gating（复用现有 ToolAvailabilityExpression）

```typescript
availability: {
  allOf: [
    { kind: 'capability', name: 'supportsToolCalling' },
    { kind: 'config', path: ['webSearch', 'enabled'], check: 'available' },
  ],
}
```

工具对模型可见性完全由声明式表达式控制，与 dialogue/writing/worldbook 工具组的 gating 模式一致。

### 3. 搜索结果作为上下文，不直接落盘

借鉴 openclaw 的 `contextSize: low | medium | high` 设计：搜索结果按 token 预算截断，作为 LLM 上下文输入，而非直接写入世界书。这保证了：
- 生成内容仍由 LLM 组织（保持文风一致性）
- 搜索结果不会污染世界书结构
- 用户对最终内容有完整审批权（草稿区机制不变）

### 4. 速率限制与缓存（防失控）

- 单次 agent 运行内搜索结果缓存（同 query 5 分钟内复用）
- 搜索间隔钳位（min 3s，避免 API 限流）
- 单次运行搜索次数上限（默认 20 次，可配置）

## ADDED Requirements

### Requirement: 网络搜索工具

系统 SHALL 提供两个网络搜索工具注册到 ToolRegistry，对所有支持工具调用的 Agent 模式可用。

#### Scenario: webSearch 工具执行搜索
- **WHEN** 智能体调用 `webSearch` 工具，传入 `query`（搜索关键词）和可选的 `maxResults`（默认 5）
- **THEN** 工具执行器调用 `WebSearchService.search(query, options)`
- **AND** 返回结构化结果列表：`[{ title, snippet, url, source }]`
- **AND** 结果按相关性排序，每条包含标题、摘要（200 字内）、URL、来源 provider

#### Scenario: fetchUrl 工具抓取网页正文
- **WHEN** 智能体调用 `fetchUrl` 工具，传入 `url` 和可选的 `maxLength`（默认 4000 字符）
- **THEN** 工具执行器调用 `WebSearchService.fetchUrl(url, maxLength)`
- **AND** 返回网页正文纯文本（剥离 script/style/nav，解码 HTML 实体，截断到 maxLength）
- **AND** 失败时返回 `ToolExecutionResult { success: false, content: errorReason }`，不中断 agentLoop

#### Scenario: Agent 模式关闭时工具不可见
- **WHEN** `useAgent === false` 或 `supportsToolCalling === false` 或 `webSearch.enabled === false`
- **THEN** `getToolDefinitions(context)` 不返回 `webSearch` 和 `fetchUrl`
- **AND** 即使模型尝试调用，`executeTool` 返回 `Tool not available` 错误

### Requirement: 可插拔搜索 Provider

系统 SHALL 支持多种搜索 provider，用户可在设置中选择并配置。

#### Scenario: DuckDuckGo 零配置搜索
- **WHEN** 用户未配置任何 API key，provider 为 `duckduckgo`（默认）
- **THEN** `DuckDuckGoProvider` 通过 `https://html.duckduckgo.com/html/?q=QUERY` 端点抓取结果
- **AND** 解析 HTML 结果页提取标题、摘要、URL
- **AND** 无需 API key，开箱即用（但受 DDG 速率限制，适合低频使用）

#### Scenario: Tavily API 搜索
- **WHEN** 用户配置 provider 为 `tavily` 并填入 API key
- **THEN** `TavilyProvider` 调用 `https://api.tavily.com/search` 端点
- **AND** 返回 AI 优化的搜索结果（含 `content` 字段，比普通搜索更丰富的正文）
- **AND** API key 缺失时返回明确错误提示

#### Scenario: SearXNG 自托管搜索
- **WHEN** 用户配置 provider 为 `searxng` 并填入实例 URL（如 `http://localhost:8080`）
- **THEN** `SearXngProvider` 调用 `{instanceUrl}/search?q=QUERY&format=json` 端点
- **AND** 返回 JSON 格式结果

#### Scenario: 自定义 provider
- **WHEN** 用户配置 provider 为 `custom` 并填入端点 URL + 请求模板
- **THEN** `CustomProvider` 按用户配置的 URL + 参数发请求
- **AND** 响应需符合 `{ results: [{ title, snippet, url }] }` 结构

### Requirement: HTML 正文提取

系统 SHALL 提供 HTML 到纯文本的提取能力，用于 `fetchUrl` 工具。

#### Scenario: 提取网页正文
- **WHEN** `fetchUrl` 抓取一个 HTML 页面
- **THEN** `HtmlTextExtractor` 剥离 `<script>` / `<style>` / `<nav>` / `<header>` / `<footer>` 标签内容
- **AND** 解码 HTML 实体（`&amp;` / `&lt;` / `&nbsp;` 等）
- **AND** 压缩连续空白，保留段落换行
- **AND** 截断到 `maxLength`（默认 4000 字符），末尾追加 `...[truncated]`

#### Scenario: 非 HTML 内容处理
- **WHEN** 抓取的 URL 返回 JSON / 纯文本 / PDF 等非 HTML 内容
- **THEN** JSON / 纯文本直接返回（截断到 maxLength）
- **AND** PDF / 二进制内容返回摘要信息（`Binary content, size: N bytes`），不尝试解析

### Requirement: 搜索结果缓存与速率限制

系统 SHALL 对搜索请求进行缓存与速率限制，避免成本失控。

#### Scenario: 同 query 缓存复用
- **WHEN** 同一 agent 运行内，相同 query 在 5 分钟内再次搜索
- **THEN** 直接返回缓存结果，不调用 provider
- **AND** 缓存按 `query + provider` 维度隔离

#### Scenario: 速率限制
- **WHEN** 搜索请求间隔小于 3 秒
- **THEN** 等待至满足间隔后再发请求
- **AND** 单次 agent 运行搜索次数超过上限（默认 20）时返回 `Rate limit exceeded` 错误

### Requirement: 世界书编写智能体集成

系统 SHALL 在世界书编写智能体的 PLANNING 与 AUTHORING 阶段可选集成网络搜索。

#### Scenario: PLANNING 阶段搜索主题资料
- **WHEN** `enableWebSearch === true` 且智能体进入 PLANNING 阶段
- **THEN** 在调用 `planningService.analyzePrompt` 之前，先用用户初始提示派生搜索 query
- **AND** 调用 `webSearch` 获取 3-5 条相关资料，作为补充上下文传给 `analyzePrompt`
- **AND** 搜索结果通过 `onProgress` 事件推送（`{ phase: 'planning_researching', message: '正在搜索相关资料...' }`）

#### Scenario: AUTHORING 阶段按维度搜索
- **WHEN** `enableWebSearch === true` 且智能体在 AUTHORING 阶段处理某维度
- **THEN** 在调用 `entryGenerator.generateEntriesForDimension` 之前，按维度名称 + 主题派生搜索 query
- **AND** 调用 `webSearch` 获取资料，作为 `researchContext` 参数传给 `generateEntriesForDimension`
- **AND** 搜索结果仅作为 LLM 上下文，不直接写入世界书条目

#### Scenario: 搜索失败不阻断编写
- **WHEN** 网络搜索请求失败（网络错误 / API 限流 / 超时）
- **THEN** 记录 warning 日志，跳过搜索补充，继续基于 LLM 自身知识生成
- **AND** 在审计报告中标注"本次编写未使用网络搜索补充"（`AuditReport.metadata.webSearchUsed: false`）

### Requirement: 设置面板配置

系统 SHALL 在设置页面提供网络搜索配置面板。

#### Scenario: 配置 provider
- **WHEN** 用户打开设置 → 网络搜索面板
- **THEN** 可选择 provider（DuckDuckGo / Tavily / SearXNG / Custom）
- **AND** 根据所选 provider 显示对应配置字段（API key / endpoint URL / 请求模板）
- **AND** 提供"测试连接"按钮，发送测试搜索请求验证配置

#### Scenario: 全局开关
- **WHEN** 用户切换"启用网络搜索"开关
- **THEN** 保存到 `webSearch.enabled` 配置项
- **AND** 关闭时所有 Agent 模式的 webSearch/fetchUrl 工具不可见

## MODIFIED Requirements

### Requirement: IAuthoringTools 接口扩展

**原实现**：`IAuthoringTools` 接口仅包含 `readWorldBook` / `createEntry` / `generateKeywords` 三个方法。

**修改后**：新增可选方法 `webSearch`：

```typescript
export interface IAuthoringTools {
  readWorldBook(...): Promise<...>;
  createEntry(...): Promise<ToolExecutionResult>;
  generateKeywords(...): Promise<ToolExecutionResult>;
  /** 网络搜索（可选，enableWebSearch=true 时注入） */
  webSearch?(query: string, maxResults?: number): Promise<Array<{
    title: string;
    snippet: string;
    url: string;
  }>>;
}
```

`webSearch` 为可选方法（`?`），未配置时 `undefined`，编排服务调用前做存在性检查。这保证了：
- 既有测试无需 mock webSearch（向后兼容）
- 未启用网络搜索时零开销

### Requirement: WorldBookAuthoringConfig 扩展

**原实现**：`WorldBookAuthoringConfig` 包含 `qualityThreshold` / `maxEntriesPerDimension` 等字段。

**修改后**：新增：

```typescript
export interface WorldBookAuthoringConfig {
  // ...既有字段
  /** 是否启用网络搜索补充（默认 false） */
  enableWebSearch: boolean;
  /** 搜索结果最大条数（默认 5） */
  webSearchMaxResults: number;
}
```

### Requirement: AppSetting 配置扩展

**原实现**：`AppSetting.defaultSetting` 无网络搜索配置。

**修改后**：新增 `webSearch` 配置块：

```typescript
webSearch: {
  enabled: false,                    // 全局开关
  provider: 'duckduckgo',            // provider 选择
  apiKey: '',                        // Tavily 等 provider 的 API key
  endpoint: '',                      // SearXNG / Custom 的端点 URL
  maxResults: 5,                     // 默认结果数
  timeout: 10000,                    // 请求超时（ms）
  allowedDomains: [],                // 域名白名单（可选，借鉴 openclaw）
  enableInAuthoring: false,          // 世界书编写智能体集成开关
}
```
