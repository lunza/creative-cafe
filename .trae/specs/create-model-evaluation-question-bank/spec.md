# 模型测评题库规格

## Why

基于 [场景清单](g:\AI\creative-cafe\docs\ai-scenarios\场景清单.md) 的分析结果，需建立结构化的测评题库，用于系统性评估 20-35B 本地部署小模型在各核心场景下的表现。题库将结合项目实际角色卡、世界书素材进行出题，确保测试内容贴近真实使用场景。

## What Changes

- 基于场景清单的 P0-P1 核心场景，划分测评维度
- 每个维度按动态参数复杂度设计简单/中等/困难三级题目
- 题目内容结合 `B:\Desktop\新建文件夹 (2)` 下的角色卡和世界书素材
- 每道题包含：题目内容（实际提示词）、标准答案、评分标准
- 建立百分制六级评分体系（S/A/B/C/D/E）
- 输出 `docs/ai-scenarios/测评题库.md` 文档

## Impact

- 受影响文档：`docs/ai-scenarios/场景清单.md`（作为题库设计依据）
- 新增文件：`docs/ai-scenarios/测评题库.md`
- 不修改任何代码

### 难度分级标准

按**动态参数的复杂度**将题目分为三级，保持参数数量一致（避免通过增减参数数量来调节难度）：

| 难度 | 编码 | 标准 |
|------|------|------|
| 简单 | L1 | 动态参数为单一固定值或简单枚举值，无需上下文推理，提示词模板固定 |
| 中等 | L2 | 动态参数需结合上下文进行选择/组合，需一定的推理能力 |
| 困难 | L3 | 动态参数需多步推理/条件分支/综合多源信息，需较强的理解和推理能力 |

### 评分标准体系（百分制）

| 等级 | 分数范围 | 通用标准 |
|------|---------|---------|
| S | 90-100 | 完全符合标准答案要求，格式完美，无任何错误 |
| A | 80-89 | 基本符合要求，少量内容偏差或格式瑕疵 |
| B | 70-79 | 部分符合要求，存在明显偏差但核心意图正确 |
| C | 60-69 | 勉强符合，有较多错误或缺漏 |
| D | 50-59 | 大部分不符合要求，但部分内容相关 |
| E | <50 | 完全不相关或严重错误 |

每个维度将制定差异化的评分细则（详见各维度评分标准章节）。

## ADDED Requirements

### Requirement: 题库文档生成
The system SHALL generate a structured evaluation question bank document at `docs/ai-scenarios/测评题库.md`.

#### Scenario: 维度定义
- **WHEN** 文档创建
- **THEN** 每个维度包含明确的测评能力范围说明和评估重点

#### Scenario: 三级难度出题
- **WHEN** 每个维度下出题
- **THEN** 必须包含简单/中等/困难三级题目，难度区分基于动态参数复杂度

#### Scenario: 素材出题
- **WHEN** 使用素材出题
- **THEN** 优先使用 B:\Desktop\新建文件夹 (2) 下的角色卡和世界书内容，自动过滤 NSFW

#### Scenario: 标准答案
- **WHEN** 每道题完成后
- **THEN** 包含完整标准答案，含回复内容、格式要求和关键信息点

#### Scenario: 差异化评分标准
- **WHEN** 每个维度创建后
- **THEN** 制定适用于该维度的差异化六级评分细则
