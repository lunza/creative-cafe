## 第1章 快速入门

### 1.1 项目概述

**Creative Cafe（创想咖啡厅）** 是一款 AI 驱动的创意内容管理工具，专注于角色卡与世界书的创建、编辑、优化与导出。它为您提供以下核心功能：

| 功能模块 | 说明 |
|---------|------|
| **角色卡管理** | 完美支持 SillyTavern V2/V3 PNG 角色卡格式，支持可视化编辑、AI 辅助创作、角色测试对话和 PNG 导出 |
| **世界书管理** | 支持 SillyTavern 世界书 JSON 格式，提供条目管理、AI 智能生成和关系图谱 |
| **记忆插件系统** | Excel 模板管理、聊天记录管理、AI 自动整理归档 |
| **创意管理** | 基于 Milkdown 的专业 Markdown 编辑体验，支持 AI 智能生成角色卡/世界书内容 |
| **用户人设管理** | 创建和管理个人对话人设 |
| **知识库管理** | 多格式文档导入、向量化存储、语义检索 |
| **系统设置** | 多 AI 引擎配置、主题切换、统一存储路径管理 |

**技术基础**：Creative Cafe 基于 Electron + React + TypeScript 构建，支持 Windows 和 macOS 平台运行。

### 1.3 首次启动配置流程

首次启动 Creative Cafe 后，请按以下步骤完成初始配置：

**步骤 1：配置 AI 引擎**

1. 点击左侧导航栏的 **设置**（⚙️）
2. 找到 **AI引擎设置** 区域
3. 点击 **管理引擎** 按钮，添加您的 AI API 信息
4. 填写 API 地址、API 密钥和模型名称
5. 点击 **测试连通性** 验证连接是否成功
6. 点击 **保存设置**

> 详细配置步骤请参考 [第2章 设置](#第2章-设置)。

**步骤 2：配置存储路径（可选）**

在设置页面的 **路径设置** 区域，您可以为各模块指定自定义存储位置。系统已提供默认路径，通常无需修改。

**步骤 3：选择外观偏好**

在设置页面的 **外观设置** 区域，您可以选择亮色或暗色主题，开启/关闭动画效果，以及启用紧凑模式。

### 2.2 AI引擎配置（核心）

AI 引擎是 Creative Cafe 的核心组件，所有 AI 功能（角色生成、世界书生成、写作辅助等）都依赖于正确配置的 AI 引擎。

#### 2.2.1 引擎管理入口

在设置页面的 **AI引擎设置** 区域，您将看到：

- **引擎选择下拉框**：显示当前已配置的所有引擎，可切换活跃引擎
- **管理引擎按钮**：点击打开引擎管理对话框，可添加、编辑、删除、复制引擎

> **[此处需插入截图]** 截图说明：AI引擎设置区域的整体视图，标注"引擎选择下拉框"和"管理引擎"按钮。

#### 2.2.2 添加新引擎

**操作步骤**：

1. 点击 **管理引擎** 按钮，打开引擎管理对话框
2. 点击 **添加新引擎** 按钮
3. 在弹出的编辑表单中填写以下信息：

| 字段 | 是否必填 | 说明 | 示例值 |
|------|---------|------|--------|
| **引擎名称** | 是 | 自定义名称，用于区分不同引擎 | `我的本地模型` |
| **API地址** | 是 | AI 服务的基础 URL | `http://127.0.0.1:5000` |
| **API密钥** | 否 | 部分服务需要 API Key 认证 | `sk-xxxxxxx` |
| **模型名称** | 是 | 要使用的模型标识 | `qwen3.5-27b-heretic-v3` |
| **API模式** | 是 | 选择接口类型（见下方详细说明） | `聊天补全` |

> **[此处需插入截图]** 截图说明：添加新引擎的编辑表单，标注各填写字段。

#### 2.2.3 API 模式详解

Creative Cafe 支持两种 API 模式：

| 模式 | 适用场景 | 说明 |
|------|---------|------|
| **文本补全**（text_completion） | 传统的文本生成任务 | 向模型发送一段提示文本，模型续写后续内容。适用于写作模式等需要纯文本输出的场景 |
| **聊天补全**（chat_completion） | 对话交互场景 | 使用消息列表（角色+内容）与模型交互。适用于角色对话、群聊等需要上下文记忆的场景 |

**选择建议**：如果您的 AI 服务同时支持两种模式，推荐优先选择 **聊天补全**，因为它能更好地处理多轮对话。

#### 2.2.4 API 密钥传输方式

| 方式 | 说明 | 适用场景 |
|------|------|---------|
| **请求头（Authorization: Bearer）** | API Key 通过 HTTP 请求头发送 | 大多数 OpenAI 兼容的服务 |
| **请求体** | API Key 包含在请求体 JSON 中 | 部分本地部署的 API 服务 |

**选择建议**：如果您的服务是标准 OpenAI 兼容 API，选择 **请求头**；如果不确定，可以尝试两种方式分别测试。

#### 2.2.5 模型参数详解

| 参数 | 取值范围 | 默认值 | 说明 |
|------|---------|--------|------|
| **最大令牌数**（max_tokens） | 1 - 100000 | 10240 | AI 单次回复的最大长度。值越大回复越长，但可能增加响应时间和消耗 |
| **温度参数**（temperature） | 0 - 2 | 0.7 | 控制 AI 输出的随机性。**值越低（接近0）**：输出更确定、更保守；**值越高（接近2）**：输出更有创意、更多样化 |
| **Top P**（top_p） | 0 - 1 | 0.95 | 核采样参数。控制词汇选择的多样性。值越低，AI 只选择最可能的词；值越高，AI 会考虑更多可能性 |
| **Top K**（top_k） | 0 - 200 | 40 | 限制 AI 在每一步只考虑概率最高的 K 个词。设为 0 表示不限制 |
| **Min P**（min_p） | 0 - 1 | 0.1 | 最小概率阈值。只有概率高于此值的词才会被考虑 |
| **频率惩罚**（frequency_penalty） | -2 - 2 | 0 | 惩罚已经频繁出现的词。值越高，AI 越倾向于使用新词，减少重复 |
| **存在惩罚**（presence_penalty） | -2 - 2 | 0 | 惩罚已经出现过的话题。值越高，AI 越倾向于探索新话题 |
| **生成数量**（n） | 1 - 10 | 1 | 每次请求生成的回复数量。通常为 1 |

> **[此处需插入截图]** 截图说明：模型参数设置区域的完整视图。

**参数调优建议**：
- **创意写作**：temperature 0.7-0.9，top_p 0.9-0.95
- **角色对话**：temperature 0.6-0.8，top_p 0.85-0.95
- **精确任务**（如翻译）：temperature 0.2-0.4，top_p 0.8-0.9

#### 2.2.6 系统提示词（system_prompt）

系统提示词用于定义 AI 的行为和角色。它会在每次请求时自动发送给 AI 模型，影响 AI 的整体回复风格。

**作用**：
- 定义 AI 的角色定位（如"你是一个专业的小说编辑"）
- 设定回复的语言风格
- 指定格式要求
- 提供行为约束

**写法示例**：

```
你是一个专业的创意写作助手。请用生动的语言创作故事内容。
回复时使用中文，保持角色一致性。
```

> **[此处需插入截图]** 截图说明：系统提示词输入框，展示一段示例提示词。

**注意事项**：
- 全局 system_prompt 会自动拼接到所有 AI 功能模块中
- 各功能模块自身的提示词会拼接在 system_prompt 之后
- 提示词越长，消耗的 Token 越多，请保持精简有效

|------|------|

| **编辑** | 修改现有引擎的配置参数 |

#### 2.2.8 测试连通性

配置完引擎参数后，建议测试连通性以验证配置是否正确。

**操作步骤**：

1. 确保 **API地址**、**API密钥**、**模型名称** 已正确填写
2. 点击 **测试连通性** 按钮
3. 系统会显示测试结果：

| 结果 | 说明 |
|------|------|
| **连接成功** | 绿色提示框，显示响应时间。表示配置正确，AI 功能可正常使用 |
| **连接失败** | 红色提示框，显示错误信息。请检查 API 地址是否正确、API Key 是否有效、模型名称是否匹配 |

> **[此处需插入截图]** 截图说明：连通性测试成功的绿色提示框示例。

**常见错误**：
- `ECONNREFUSED`：API 地址无法访问，请检查服务是否启动
- `401 Unauthorized`：API Key 无效或过期
- `404 Not Found`：模型名称错误或 API 路径不正确

2. 点击 **向量化** 按钮
3. 系统调用嵌入模型生成该条目的向量表示

**全部向量化**：

1. 在知识列表顶部点击 **全部向量化** 按钮
2. 系统批量对所有未向量化的条目进行处理

**自动向量化**：

- 在 [设置 → 向量化设置](#26-向量化设置) 中开启 **自动向量化** 后，新创建的世界书和导入的文档会自动进行向量化

## 第11章 常见问题解答

### Q1：AI引擎连接失败怎么办？

**排查步骤**：

1. **检查 API 地址**：确认地址格式正确（如 `http://127.0.0.1:5000`）
2. **检查 API 服务是否运行**：在浏览器中访问 API 地址，确认服务正常
3. **检查 API Key**：确认 Key 未过期且格式正确
4. **检查模型名称**：确认模型名称与服务端支持的名称匹配
5. **检查网络**：如果是远程服务，检查网络连接是否正常
6. **测试连通性**：在设置页面点击"测试连通性"查看具体错误信息

### Q2：提示"未配置 AI 引擎"怎么办？

请前往 **设置 → AI引擎设置**，确保至少添加了一个引擎，并且已正确填写 API 地址和模型名称。

### Q3：存储路径修改后不生效？

修改路径后必须点击页面底部的 **保存设置** 按钮。保存后，系统会自动切换到新路径。

### Q4：文档上传失败怎么办？

1. 确认文件格式在支持范围内（PDF、DOCX、XLSX、TXT、MD）
2. 确认文件大小不超过 50MB
3. 检查文件内容是否为纯文本（扫描版 PDF 无法解析）
4. 查看日志面板中的错误信息

### Q5：向量化失败怎么办？

1. 确认 [向量化设置](#26-向量化设置) 中的嵌入模型配置正确
2. 如果使用远程模型，检查 API 地址和 Key 是否正确
3. 如果使用本地模型，确认模型文件已下载
4. 在仪表盘查看向量模型状态，确认已连接

### Q6：角色卡导出后在 SillyTavern 中无法识别？

1. 确保导出的 PNG 格式正确（不要修改文件扩展名）
2. 确认 SillyTavern 版本支持 V3 格式角色卡
3. 尝试在 SillyTavern 中重新导入

### Q7：如何查看系统日志？

点击界面右下角的 **浮动日志按钮**（📋 图标），可展开全局日志面板。日志分为四个级别：

| 级别 | 说明 |
|------|------|
| **错误**（红色） | 系统发生错误，功能可能无法正常使用 |
| **警告**（橙色） | 可能存在问题，建议关注 |
| **信息**（蓝色） | 正常操作记录 |
| **调试**（灰色） | 详细调试信息，排查问题时使用 |

### Q8：如何恢复默认设置？

在设置页面底部点击 **重置设置** 按钮即可。但请注意，此操作会清除所有自定义配置。

## 第12章 专业术语解释

### 向量 / 向量化（Vector / Vectorization）

**向量** 是一组数字，用于在数学空间中表示文本的语义信息。例如，"猫"和"狗"的向量在空间中会很接近，因为它们语义相似。

**向量化** 是将文本转换为向量的过程。Creative Cafe 使用嵌入模型（Embedding Model）来完成这一转换。向量化后的文本可以进行语义相似度比较，用于知识库检索。

### Token / 令牌

**Token** 是 AI 模型处理文本的基本单位。一个 Token 可能是一个完整的词、词的一部分或一个标点符号。

- 中文通常 1 个汉字 ≈ 1-2 个 Token
- 英文通常 1 个英文单词 ≈ 1-2 个 Token

**max_tokens** 参数控制 AI 单次回复的最大 Token 数量。

### Temperature / 温度参数

**Temperature** 控制 AI 输出的随机性和创造性：

- **0.0-0.3**：输出非常确定和保守，适合精确任务
- **0.4-0.7**：平衡创造力和准确性，适合一般对话
- **0.8-1.0**：输出更有创意和多样性
- **1.0-2.0**：输出非常随机，可能不够连贯

### API 模式

| 模式 | 说明 |
|------|------|
| **文本补全**（text_completion） | 给模型一段文本，模型续写后续内容。类似于"完成这句话" |
| **聊天补全**（chat_completion） | 给模型一组消息（角色+内容），模型以对话形式回复。类似于"多轮对话" |

### 世界书（World Book）

**世界书** 是 AI 角色对话中的知识库，包含世界观、地理、势力、角色关系等背景信息。在对话过程中，系统会根据对话内容自动检索相关的条目发送给 AI，使 AI 的回答更加准确和一致。

### 角色卡（Character Card）

**角色卡** 是定义 AI 角色的配置文件，包含角色的名称、外貌、性格、说话风格等信息。Creative Cafe 使用 SillyTavern V2/V3 标准格式，确保与其他工具兼容。

### System Prompt / 系统提示词

**System Prompt** 是发送给 AI 模型的系统级指令，用于定义 AI 的整体行为和角色。它不同于单次对话的消息，而是持续影响 AI 的所有回复。

### Embedding Model / 嵌入模型

**嵌入模型** 是一种专门用于将文本转换为向量的 AI 模型。与生成文本的大语言模型不同，嵌入模型只输出数字向量，用于语义相似度计算。
