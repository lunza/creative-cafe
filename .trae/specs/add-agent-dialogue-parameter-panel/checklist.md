# Checklist

## 人格自定义系统
- [x] 参数面板包含自定义人格 TextArea 输入框
- [x] 人格文本非空时注入 systemPrompt 的「人格风格」段落
- [x] 人格段落与智能体描述段落（角色定义）在 systemPrompt 中独立呈现
- [x] 人格为空时 systemPrompt 不包含人格风格段落
- [x] 人格设置仅影响交互风格，不影响智能体身份职责

## 辅助模式功能
- [x] 参数面板包含辅助模式 Switch 开关，默认关闭
- [x] 开启时 systemPrompt 末尾注入 <<<SUGGESTED_OPTIONS>>> 格式约束
- [x] AI 回复完成后自动解析并剥离选项块
- [x] 选项存入 DialogueMessage.suggestedOptions 字段
- [x] AI 消息气泡下方渲染 3 个选项卡片（绿/紫/橙红三色）
- [x] 用户点击选项后文本填入输入框
- [x] AI 未生成选项时静默处理，不影响回复展示
- [x] 关闭辅助模式后 AI 回复不包含选项，历史选项保留显示

## 辅助模式强度调节
- [x] 参数面板包含强度选择（低/中/高三档），默认"中"
- [x] 低强度：提示词要求生成保守选项，贴合当前话题
- [x] 中强度：提示词要求适度转换角度
- [x] 高强度：提示词要求大胆创新，引入新方向

## 折叠式参数面板
- [x] 参数面板默认折叠隐藏
- [x] 头部右侧有齿轮图标按钮控制展开/折叠
- [x] 展开时面板从右侧滑出，对话区宽度收窄
- [x] 折叠时对话区恢复全部宽度
- [x] 面板内各功能区块以独立折叠卡片展示

## 实时生效
- [x] 修改人格文本后下一次 AI 回复即使用新人格
- [x] 切换辅助模式开关后下一次 AI 回复即生效
- [x] 修改强度后下一次 AI 回复即使用新强度
- [x] 无需点击"保存"或"确认"按钮

## 重置为默认
- [x] 参数面板包含"重置为默认"按钮
- [x] 点击后人格清空、辅助模式关闭、强度重置为"中"
- [x] 重置结果立即持久化

## 数据持久化
- [x] 参数以 JSON 存储到 localStorage，key 为 `agent-params-{agentId}`
- [x] 存储内容包括 customPersonality、assistMode、assistModeIntensity
- [x] 切换智能体时自动加载对应配置
- [x] 新智能体无历史配置时使用默认值

## 功能标识
- [x] 头部显示人格标签（紫色胶囊），悬停显示摘要，空时不显示
- [x] 头部显示辅助模式标签（橙色胶囊），附带强度等级，关闭时不显示
- [x] 选项区域上方显示"AI 推荐了以下对话方向"提示文本
- [x] 选项卡片三色差异化设计（绿/紫/橙红）
