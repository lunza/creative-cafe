## 一、功能概述

### 1.1 背景

Creative Cafe 是一个基于 AI 的创意创作辅助工具，当前已支持聊天模式、群聊模式、角色卡管理和世界书管理等功能。写作模式作为创意中心的核心功能之一，旨在为用户提供专业的小说创作辅助能力。

### 1.2 产品定位

写作模式是 Creative Cafe 中面向小说创作者的 AI 辅助创作功能，通过整合用户选择的世界书、角色卡等资源，结合 AI 的理解和生成能力，帮助用户完成从大纲生成到小说内容创作的全流程。

### 1.3 核心价值

- **资源整合**: 无缝连接已有的世界书、角色卡等创作资源
- **智能大纲**: AI 根据输入自动生成符合小说类型范式的结构化大纲
- **连续创作**: 保持上下文连贯性，持续生成小说内容
- **类型适配**: 支持网文、言情、武侠、玄幻、奇幻、悬疑等多种小说类型

### 1.4 功能边界

**包含**:
- 创作资源选择与配置
- AI 大纲生成
- 小说内容连续生成
- 上下文连贯性管理
- 创作进度保存与恢复

**不包含**:
- 多人协作创作
- 版本对比与合并
- 付费内容管理
- 作品发布与分享

## 三、详细功能点描述

### 3.1 创作配置

#### 3.1.1 资源选择

| 功能点 | 描述 |
|--------|------|
| 世界书选择 | 从已有世界书中选择一个或多个，提供搜索和筛选功能 |
| 角色卡选择 | 从已有角色卡中选择一个或多个，支持按名称搜索 |
| 资源预览 | 点击资源可查看详细信息（描述、条目、标签等） |
| 已选资源管理 | 显示已选资源列表，支持移除 |

#### 3.1.2 基础参数输入

| 参数 | 类型 | 说明 | 默认值 | 约束 |
|------|------|------|--------|------|
| 创意描述 | 文本域 | 创作的核心创意、主题、背景等 | 空 | 10-2000字 |
| 小说类型 | 下拉选择 | 网文/言情/武侠/玄幻/奇幻/悬疑/科幻/历史/都市/其他 | 网文 | 必选 |
| 目标字数 | 数字输入 | 期望的总字数 | 10000 | 1000-1000000 |
| 章节数量 | 数字输入 | 计划的章节数 | 10 | 1-200 |
| 叙事视角 | 下拉选择 | 第一人称/第三人称/全知视角 | 第三人称 | 必选 |
| 写作风格 | 下拉选择 | 轻松/严肃/幽默/悬疑/浪漫/史诗 | 根据类型自动推荐 | 可选 |

### 3.2 AI 大纲生成

#### 3.2.1 生成触发

- 用户完成资源配置和参数输入后，点击"生成大纲"按钮
- 系统校验必填项，校验通过后调用 AI 生成

#### 3.2.2 大纲结构

生成的结构化大纲应包含:

| 层级 | 内容 |
|------|------|
| 作品信息 | 标题建议、类型、预估字数、章节数 |
| 故事主线 | 核心冲突、故事弧光（起承转合）、主题 |
| 章节大纲 | 每章的标题、主要内容、出场角色、场景、悬念点 |
| 角色关系 | 主要角色之间的关系图谱 |
| 世界观要点 | 关键的世界观设定和规则 |

#### 3.2.3 大纲交互

- **生成中**: 显示加载状态和进度提示
- **生成后**: 以可编辑的树形结构展示，支持折叠/展开
- **手动调整**: 用户可直接编辑大纲内容
- **重新生成**: 可调整参数后重新生成
- **确认大纲**: 确认后进入内容生成阶段

### 3.3 小说内容生成

#### 3.3.1 生成模式

| 模式 | 描述 | 触发方式 |
|------|------|----------|
| 按章生成 | 逐章生成，每章独立生成 | 点击"生成下一章" |
| 连续生成 | 持续生成多章，直到达到目标 | 点击"开始连续生成" |
| 指定章节 | 选择特定章节生成 | 在大纲中选择章节后点击生成 |

#### 3.3.2 生成过程

1. **准备上下文**: 加载世界书相关内容、角色卡信息、已生成章节内容
2. **构建 Prompt**: 根据大纲、上下文、类型范式构建生成提示
3. **流式生成**: 通过流式响应实时显示生成内容
4. **内容渲染**: 支持 Markdown 格式渲染显示
5. **自动保存**: 生成完成后自动保存

#### 3.3.3 上下文连贯性保证

- **短期上下文**: 当前章节及前 2-3 章的完整内容
- **中期上下文**: 大纲中所有章节的摘要
- **长期上下文**: 关键角色信息、世界观设定、伏笔记录
- **动态检索**: 根据当前情节动态检索相关世界书条目

#### 3.3.4 生成控制

- **暂停**: 暂停当前生成
- **继续**: 从中断处继续生成
- **停止**: 终止当前生成，保留已生成内容
- **重新生成**: 对当前章节重新生成

### 3.4 内容编辑

#### 3.4.1 编辑器功能

- 基于现有 MarkdownEditor 组件
- 支持实时预览
- AI 辅助编辑（扩写、精简、改写、润色）
- 章节导航
- 字数统计

#### 3.4.2 版本管理

- 自动生成内容保存为初稿
- 手动修改后保存为新版本
- 支持版本回退

### 3.5 创作管理

#### 3.5.1 项目列表

- 显示所有创作项目
- 按时间/名称排序
- 搜索和筛选
- 显示项目状态（大纲/创作中/已完成）

#### 3.5.2 项目操作

- 新建创作
- 继续创作
- 导出作品（TXT/Markdown/EPUB）
- 删除项目
- 复制项目（基于现有创作创建新项目）

```typescript
interface WritingResourceConfig {
```

#### 5.1.2 创作参数输入

```typescript
interface WritingParameters {
  // 创意描述（必填）
  creativeDescription: string;
  // 小说类型（必填）
  novelType: NovelType;
  // 目标字数（必填）
  targetWordCount: number;
  // 章节数量（必填）
  chapterCount: number;
  // 叙事视角（必填）
  narrativePerspective: NarrativePerspective;
  // 写作风格（可选）
  writingStyle?: WritingStyle;
  // 额外要求（可选）
  additionalRequirements?: string;
  // 禁止内容（可选）
  forbiddenContent?: string[];
}

enum NovelType {
  WEB_NOVEL = 'web_novel',      // 网文
  ROMANCE = 'romance',          // 言情
  MARTIAL_ARTS = 'martial_arts', // 武侠
  FANTASY = 'fantasy',          // 玄幻
  FANTASY_MAGIC = 'fantasy_magic', // 奇幻
  MYSTERY = 'mystery',          // 悬疑
  SCI_FI = 'sci_fi',           // 科幻
  HISTORICAL = 'historical',    // 历史
  URBAN = 'urban',             // 都市
  OTHER = 'other'              // 其他
}

enum NarrativePerspective {
  FIRST_PERSON = 'first_person',    // 第一人称
  THIRD_PERSON = 'third_person',    // 第三人称
  OMNISCIENT = 'omniscient'         // 全知视角

enum WritingStyle {
  RELAXED = 'relaxed',      // 轻松
  SERIOUS = 'serious',      // 严肃
  HUMOROUS = 'humorous',    // 幽默
  SUSPENSEFUL = 'suspenseful', // 悬疑
```

## 六、非功能性需求

### 6.1 性能需求

| 指标 | 要求 | 说明 |
|------|------|------|
| 大纲生成时间 | < 30 秒 | 从请求到大纲完全生成 |
| 内容生成首字时间 | < 5 秒 | 从请求到第一个字符显示 |
| 界面响应时间 | < 200ms | 用户操作到界面响应 |
| 保存操作时间 | < 1 秒 | 单次保存操作完成时间 |
| 内存占用 | < 500MB | 创作过程中的内存占用 |

### 6.2 可用性需求

| 指标 | 要求 | 说明 |
|------|------|------|
| 生成成功率 | > 95% | AI 生成请求成功率 |
| 自动保存 | 实时 | 内容变更时自动保存 |
| 断点恢复 | 支持 | 意外中断后可恢复进度 |
| 错误恢复 | 支持 | 网络异常后自动重试 |

### 6.3 安全性需求

| 要求 | 说明 |
|------|------|
| API Key 安全 | 不在前端明文存储，通过主进程代理请求 |
| 数据隐私 | 创作数据仅存储在本地，不上传服务器 |
| 输入校验 | 所有用户输入需进行格式和长度校验 |
| 错误处理 | 敏感错误信息不暴露给前端 |

### 6.4 可扩展性需求

| 方面 | 要求 |
|------|------|
| 模型兼容 | 支持多种 OpenAI 兼容的 AI 模型 |
| 类型扩展 | 小说类型可配置，支持未来新增类型 |
| 模板扩展 | 大纲模板可自定义，支持不同创作流派 |
| 导出格式 | 支持扩展新的导出格式 |

### 6.5 兼容性需求

| 方面 | 要求 |
