# 移动端 UI 全面重新设计（redesign-mobile-chat-ui）Spec

## Why
安卓客户端现有 UI 基于 Material 3 基础组件平铺实现，视觉较平淡：对话页顶部全宽立绘横幅占用大量空间、AI 消息无头像标识、图片在气泡内以 1:1 方形硬边展示、界面整体缺少现代视觉记忆点。用户要求进行全面 UI 重新设计，重点优化视觉美观度与图片展示位置、尺寸、边距及加载状态。

## What Changes
- **设计语言升级**：从平铺 Material 3 转向现代自定义风格——柔和渐变背景、玻璃态（半透明+模糊）卡片、大圆角（16-24dp）、细腻阴影分层、增强层级感知
- **主色调调整**：从现有紫色（#6750A4）转向中性暖色调基底 + 角色卡主题点缀色（角色 identity 色），亮/暗两套均重调
- **立绘重构（重点）**：废弃顶部全宽立绘横幅，改为 AI 消息气泡左侧的**圆形立绘头像**（含情绪表情图，失败回退角色头像，流式期间呼吸动画）；用户消息右侧可显示默认用户头像；显著提升消息列表信息密度
- **对话图片气泡重设计（重点）**：
  - 尺寸：按原始宽高比自适应，限宽（气泡最大宽度内）+ 限高（纵向长图压缩），弃用 1:1 方形
  - 位置/边距：图片与文本之间规范间距，圆角卡片式（16dp）内嵌阴影
  - 加载状态：加载中骨架屏 + 渐进加载（淡入）；生成中阶段进度条；失败重试占位统一风格
  - 历史版本：‹› 切换按钮改为浮层式胶囊控件（不占独立行，悬于图片底边）
- **消息视觉层级**：
  - AI 气泡：浅玻璃感卡片 + 情绪色点缀，附角色头像
  - 用户气泡：主色渐变 + 无头像/默认头像
  - 思考折叠面板、辅助模式推荐 chips、生成图片入口按钮全部按新视觉语言重绘
- **输入区升级**：圆角胶囊输入容器、发送按钮渐变、键盘弹出时背景模糊层级
- **响应式适配**：按屏宽分档优化立绘头像尺寸、气泡最大宽度、图片限高；横屏时消息区自动扩展
- **兼容性**：全部自绘样式继续走 `createStyles(palette)` 工厂 + PaperProvider 动态主题，亮/暗两套均覆盖

## Impact
- Affected specs: `fix-android-chat-parity-v3`（主题系统扩展）、`fix-android-chat-feature-parity`（对话页结构重构）
- Affected code:
  - `android-client/src/theme.ts` — 重设计调色板（新主色 + 玻璃态语义色 + 角色点缀色 + 图片加载骨架色）
  - `android-client/src/screens/ChatScreen.tsx` — 立绘区改造（横幅→头像）、气泡视觉、输入区、图片区域调用重写
  - `android-client/src/components/ImageBubble.tsx` — 图片尺寸/圆角/加载态/历史胶囊全面重写
  - `android-client/src/components/SessionConfigSheet.tsx`、`MemoryTableSheet.tsx` — 玻璃态弹层统一
  - `android-client/src/screens/CharacterListScreen.tsx`、`ConnectScreen.tsx`、`CharacterEditScreen.tsx` — 背景/卡片/按钮视觉统一
- 纯 UI 变更：不改服务端契约、不改数据模型、不改 API 字段

## ADDED Requirements

### Requirement: 现代自定义视觉语言
系统 SHALL 采用渐变背景 + 玻璃态卡片 + 大圆角 + 细腻阴影的现代移动端视觉语言，替换现有平铺 Material 3 观感；亮/暗两套主题均适配。

#### Scenario: 亮色模式视觉检查
- **WHEN** 用户在列表页/对话页/编辑页浏览
- **THEN** 背景为柔和渐变，卡片为半透明玻璃质感，所有元素圆角统一（卡片 20dp / 图片 16dp / 胶囊 24dp），阴影层级清晰

#### Scenario: 暗色模式视觉检查
- **WHEN** 切换暗色主题后浏览各页
- **THEN** 暗色调色板正确应用，玻璃态半透明层在暗色下不刺眼，文本对比度满足可读性

### Requirement: 立绘头像化
对话页 SHALL 移除顶部全宽立绘横幅，改为在 AI 消息气泡左侧渲染圆形立绘头像（情绪表情图渲染，失败回退角色头像），流式输出期间头像显示呼吸/打字动画；用户气泡右侧渲染默认用户头像。

#### Scenario: 情绪切换反馈
- **WHEN** 模型回复触发情绪变化
- **THEN** AI 气泡头像平滑切换到新情绪立绘，无需页面级重排，消息列表滚动位置保持稳定

### Requirement: 自适应卡片式图片展示
对话图片 SHALL 以自适应卡片展示：按原始宽高比缩放（限宽限高、不裁切、不变形），16dp 圆角 + 内阴影，与正文间距规范；加载中显示骨架屏+淡入过渡，生成中显示阶段进度，历史版本切换使用悬于图片底边的胶囊控件。

#### Scenario: 长图与方图适配
- **WHEN** 生成的图片为纵向长图（高＞宽）
- **THEN** 图片按限高压缩展示（最大高度不超气泡区域 60%），保持完整构图不裁切；方形图按气泡内可用宽展示

#### Scenario: 历史版本切换
- **WHEN** 用户切换图片历史版本
- **THEN** 胶囊控件（1/3 · ‹ ›）悬于图片底边半透明展示，不挤占消息布局，切换有淡入过渡

### Requirement: 主色迁移与角色点缀
主色调 SHALL 从紫色迁移为中性暖色基底；角色编辑页新增可选的「主题点缀色」仍遵循现有会话配置（不新增服务端字段，仅基于角色卡视觉差异化的客户端推导），确保不破坏服务端契约。

#### Scenario: 双端主题一致
- **WHEN** 切换亮/暗主题并进入任意页面
- **THEN** 主色与点缀色一致应用，与既有功能（思考面板/options chips/主题按钮）不冲突

## MODIFIED Requirements

### Requirement: 主题系统（原 fix-android-chat-parity-v3 V3）
调色板从紫色体系迁移到中性暖色体系，新增玻璃态辅助色调（glassBg、scrim、skeleton）、图片加载骨架色、气泡渐变起止色等语义字段；`Palette` 接口扩展但保持 `themeOf(mode)` 调用签名不变，全部自绘样式沿用 `createStyles(palette)` 工厂。

### Requirement: 记忆表格/会话配置弹层（原 V2）
弹层外观统一为玻璃态风格（半透明遮罩 + 圆角卡片 + 阴影），内容与交互逻辑不变。

## REMOVED Requirements

### Requirement: 顶部全宽立绘横幅（原 V1/L1）
**Reason**: 横幅占屏面积大（最高 210dp），与"立绘头像化"的新信息密度方向冲突
**Migration**: 立绘内容迁移至 AI 气泡头像（情绪立绘/角色头像回退逻辑保留）；表情徽章（emotionBadge）改为在角色对应消息时间戳旁或头像角标展示
