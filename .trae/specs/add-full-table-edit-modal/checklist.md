# Checklist

- [x] 表格整理面板操作区存在"查看全部数据"按钮，有数据时可用、无数据时禁用
- [x] 点击按钮后弹出模态框，展示完整表格数据（不限于20行）
- [x] 模态框顶部显示 sheet 切换标签，切换后显示对应 sheet 数据
- [x] 模态框内表格支持分页浏览，可切换每页10/20/50/100行
- [x] 模态框内提供搜索框，支持在所有列中搜索文字并实时过滤
- [x] 双击单元格可进入编辑模式，保存后同步到存储并显示提示
- [x] 点击"新增行"按钮可在表格末尾添加空白行
- [x] 删除行前有确认对话框，确认后删除并同步到存储
- [x] "保存全部"按钮将当前 sheet 所有数据保存到存储
- [x] "导出CSV"按钮导出当前 sheet 全部数据
- [x] "同步到存储"按钮批量同步所有行到存储
- [x] 模态框内数据修改后，关闭模态框时面板主区域数据保持一致
- [x] 模态框 UI 风格与现有系统一致（使用 Ant Design 组件和主题 token）
