# Worldbook Keywords

世界书关键词提取技能。分析世界书条目内容，自动提取核心关键词、主题标签和关联词，辅助条目分类与检索。

本技能为**服务委托型技能**（service-delegated skill），不通过 `command-tool` 分发到 ToolRegistry，而是由世界书智能体（worldbook-agent）委托专用服务执行关键词提取流程。技能本身仅用于注册到 `skillRegistry` 以支持 `skill:list` 查询与 `<available_skills>` 快照注入。

## 何时调用

- 世界书条目缺少关键词或标签，需要批量补充时
- 需要优化条目的检索命中率，提升关键词覆盖度时
- 条目分类不清晰，需要通过关键词分析辅助归档时
- 需要建立条目间的关联关系，通过关联词发现潜在联系时
- 新生成条目后，自动提取关键词完善条目元数据时

**不适用场景**：
- 用户想手动编辑条目关键词（应使用条目编辑器）
- Agent 模式关闭或模型不支持工具调用

## 提取内容类型

本技能从条目内容中提取以下类型的元数据：

- **核心关键词**：条目内容中的关键名词与概念（如地名、人名、物品名、事件名）
- **主题标签**：概括条目主题的分类标签（如「魔法」「战争」「政治」「日常」）
- **关联词**：与其他条目可能存在关联的词汇，用于建立交叉引用
- **分类建议**：基于内容分析推荐的条目分类

## 调用方式

本技能不通过 `skill:invoke` 的标准工具分发路径调用，而是由世界书智能体服务委托执行：

- `worldbookAgent:run` — 启动关键词提取任务（委托 worldbook-agent 服务）
- `worldbookAgent:cancel` — 取消运行中的提取任务
- `worldbookAgent:status` — 查询提取状态
- `worldbookAgent:progress`（事件） — 实时进度推送

用户命令面板输入 `/worldbook-keywords` 触发关键词提取流程。

## 提取流程

1. **条目扫描**：读取目标世界书条目的标题、内容与现有标签
2. **内容分析**：分析条目文本，识别核心概念与主题
3. **关键词提取**：提取核心关键词，过滤停用词与低信息量词汇
4. **标签生成**：基于关键词归纳主题标签
5. **关联词发现**：识别与其他条目的潜在关联词
6. **结果写入**：将提取结果写入条目的关键词与标签字段（草稿区，需审批）

## 注意事项

- 提取结果写入草稿区，需用户审批后才正式生效
- 关键词提取依赖条目内容的质量，内容过短时提取效果可能不佳
- 批量提取时建议按分类分组处理，避免单次处理过多条目
- 提取的主题标签为建议性质，用户可手动调整
- 需在设置中开启 Agent 模式且模型支持工具调用
