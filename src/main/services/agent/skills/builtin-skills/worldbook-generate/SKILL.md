# Worldbook Generate

世界书条目生成技能。根据现有故事背景、角色设定和剧情发展，智能生成符合世界观一致性的世界书条目。

本技能为**服务委托型技能**（service-delegated skill），不通过 `command-tool` 分发到 ToolRegistry，而是由世界书智能体（worldbook-agent）委托专用服务执行条目生成流程。技能本身仅用于注册到 `skillRegistry` 以支持 `skill:list` 查询与 `<available_skills>` 快照注入。

## 何时调用

- 用户希望基于现有故事背景**自动生成新的世界书条目**时
- 剧情发展引入了新地点、新人物、新物品，需要补充设定时
- 用户需要批量生成某一分类下的多个条目时
- 现有世界书覆盖不足，需要扩展设定维度时

**不适用场景**：
- 用户只想手动创建单个条目（应使用手动编辑器）
- 需要完整的自动化世界书构建流程（应使用 `worldbook-author` 技能）
- Agent 模式关闭或模型不支持工具调用

## 生成内容类型

本技能可生成以下类型的条目内容：

- **地点描述**：场景设定、地理环境、建筑布局、氛围描写
- **人物档案**：角色背景、性格特征、外貌描述、关系网络
- **物品属性**：功能描述、外观特征、获取方式、特殊效果
- **事件时间线**：事件经过、参与角色、影响范围、因果关系
- **设定规则**：世界观规则、魔法/科技体系、社会制度、文化习俗

## 调用方式

本技能不通过 `skill:invoke` 的标准工具分发路径调用，而是由世界书智能体服务委托执行：

- `worldbookAgent:run` — 启动生成会话（委托 worldbook-agent 服务）
- `worldbookAgent:cancel` — 取消运行中的生成任务
- `worldbookAgent:status` — 查询生成状态
- `worldbookAgent:progress`（事件） — 实时进度推送

用户命令面板输入 `/worldbook-generate` 触发条目生成流程。

## 生成流程

1. **上下文分析**：读取现有故事背景、角色卡设定与已有世界书条目
2. **需求识别**：根据用户提示或剧情发展，识别需要生成的条目类型与内容
3. **一致性校验**：生成前校验与现有设定的一致性，避免矛盾
4. **条目生成**：按识别需求生成结构化条目内容
5. **草稿写入**：生成的条目标记 `autoGenerated: true` 写入草稿区，需用户审批

## 注意事项

- 生成的条目进入草稿区，**不直接成为正式条目**，需用户审批
- 生成前会读取已有世界书条目，确保新条目与现有设定不矛盾
- 单次生成建议聚焦一个分类（如仅生成地点类条目），避免内容过于分散
- 生成依赖现有上下文的丰富度，故事背景过少时生成质量可能下降
- 需在设置中开启 Agent 模式且模型支持工具调用
