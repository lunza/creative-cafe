# Worldbook Sort

世界书条目整理技能。对世界书条目进行分类、排序和整理，优化条目结构与关联关系，确保世界书的组织结构清晰有序。

本技能为**服务委托型技能**（service-delegated skill），不通过 `command-tool` 分发到 ToolRegistry，而是由世界书智能体（worldbook-agent）委托专用服务执行条目整理流程。技能本身仅用于注册到 `skillRegistry` 以支持 `skill:list` 查询与 `<available_skills>` 快照注入。

## 何时调用

- 世界书条目数量增多，结构混乱需要整理时
- 发现存在内容重复或高度相似的条目，需要合并时
- 需要按分类、重要性或关联度重新组织条目顺序时
- 需要建立条目间的交叉引用，提升检索效率时
- 批量生成条目后，需要统一整理结构与元数据时

**不适用场景**：
- 用户想手动调整单个条目（应使用条目编辑器）
- 世界书条目数量很少，无需整理
- Agent 模式关闭或模型不支持工具调用

## 整理操作类型

本技能支持以下整理操作：

- **分类排序**：按分类（地点 / 人物 / 物品 / 事件等）对条目分组排序
- **重要性排序**：按条目在故事中的重要程度排序（核心 / 重要 / 辅助 / 背景）
- **关联度排序**：按条目间的关联强度排序，关联紧密的条目相邻排列
- **重复合并**：识别内容重复或高度相似的条目，合并为单一条目
- **交叉引用**：分析条目间的关联关系，建立双向交叉引用链接
- **结构优化**：调整条目层级结构，确保分类树清晰

## 调用方式

本技能不通过 `skill:invoke` 的标准工具分发路径调用，而是由世界书智能体服务委托执行：

- `worldbookAgent:run` — 启动条目整理任务（委托 worldbook-agent 服务）
- `worldbookAgent:cancel` — 取消运行中的整理任务
- `worldbookAgent:status` — 查询整理状态
- `worldbookAgent:progress`（事件） — 实时进度推送

用户命令面板输入 `/worldbook-sort` 触发条目整理流程。

## 整理流程

1. **全量扫描**：读取世界书中所有条目的标题、内容、标签与分类
2. **重复检测**：识别内容重复或高度相似的条目对，生成合并建议
3. **关联分析**：分析条目间的关联关系，计算关联度
4. **排序规划**：按指定维度（分类 / 重要性 / 关联度）生成排序方案
5. **交叉引用**：为关联条目建立双向引用链接
6. **结果写入**：将整理结果写入草稿区（需用户审批后才正式生效）

## 注意事项

- 整理结果写入草稿区，需用户审批后才正式生效
- 重复条目合并为建议操作，不会自动删除条目，需用户确认
- 整理操作不改变条目内容本身，仅调整结构、排序与关联关系
- 大量条目整理时可能耗时较长，建议分批处理
- 需在设置中开启 Agent 模式且模型支持工具调用
