# WorldBook Author

世界书编写智能体。通过流式对话模式自主编写世界书条目，复用现有智能体底座（worldbookTools 工具组）。智能体自主决定工作流程，无预设阶段限制。

## 何时调用

- 用户想**自动化构建世界书**（而非手动逐条创建条目）时
- 用户希望基于一个初始主题/方向，让智能体自主扩展设定维度并生成完整世界书时

**不适用场景**：
- 用户只想生成单个条目（应使用手动创建或 `WorldBookAIGenerateFlow`）
- 用户希望直接得到正式条目（本技能生成的条目需审批后才转正式）
- Agent 模式关闭或模型不支持工具调用（入口按钮会隐藏）

## 工作模式

- 智能体通过流式对话与用户交互
- 智能体自主决定信息收集、条目生成、质量检查等工作流程
- 不设预设工作路线，允许智能体灵活运作
- 智能体可在对话中向用户提问，用户直接在对话框回复

## 数据入库格式规范

智能体在生成世界书条目时，必须通过 `createEntry` 工具创建条目，遵守以下格式规范：

**条目结构**：

| 字段 | 必填 | 说明 |
|------|------|------|
| `worldBookPath` | 是 | 目标世界书文件路径 |
| `name` | 是 | 条目名称 |
| `content` | 是 | 条目内容（详细描述） |
| `keys` | 是 | 主关键词数组（用于触发） |
| `secondaryKeys` | 否 | 次关键词数组 |
| `comment` | 否 | 条目注释 |
| `dimensionId` | 否 | 维度 ID |

**autoGenerated 标记**：所有通过智能体生成的条目自动标记为 `autoGenerated: true`，进入草稿区，需用户审批后才转为正式条目。

**worldBookPath 传递**：智能体在调用 `createEntry` 工具时，必须传入正确的 `worldBookPath` 参数。该路径在对话上下文中提供。

**工具调用指引**：
- `createEntry`：创建世界书条目
- `generateKeywords`：为条目生成关键词
- `expandFromContext`：基于上下文扩展条目
- 智能体应先收集足够的上下文信息，再开始生成条目
- 智能体应确保条目之间的逻辑一致性

## 与手动编写的区别

| 维度 | 手动编写 | 本智能体 |
|------|----------|----------|
| 条目来源 | 用户逐条手动创建 / `WorldBookAIGenerateFlow` 单条 AI 生成 | 智能体通过流式对话自主批量生成 |
| 维度覆盖 | 用户自行决定 | 智能体分析提示 + 主动扩展必要维度 |
| 写入位置 | 直接成为正式条目 | `autoGenerated: true` 草稿区，需用户审批 |
| 一致性校验 | 无 | 智能体在生成过程中确保条目间逻辑一致性 |

## Agent 模式要求

- **硬约束**：需在设置中开启 Agent 模式（`useAgent === true`）且模型支持工具调用（`supportsToolCalling === true`）
- 关闭时入口按钮隐藏，IPC 处理器返回 `AGENT_MODE_DISABLED` 错误码
- 不影响非 Agent 模式下的手动编写逻辑（`WorldBookManager` 手动 CRUD / `WorldBookEntryEditor` / `WorldBookAIGenerateFlow` 全部保留）

## 注意事项

- 生成的条目全部进入草稿区，**不直接成为正式条目**，需用户审批
